# Chapter 6. Emit punch check, fitness orienteering

## 6 Emit punch check, fitness orienteering

HkKisaWin can
be connected to an Emit reader punch or other Emit devices.
At this stage the function has been developed especially for the needs of fitness
orienteering events. At least in large national orienteering competitions I recommend
using HkMaali for the actual punch check for the time being.
The following covers all fitness orienteering operating modes at once.
The appendix chapters of the instructions go through, one at a time, what has to be done in each
operating model.
