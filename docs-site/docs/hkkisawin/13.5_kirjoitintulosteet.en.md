# 13.5 Printer outputs

### 13.5 Printer outputs

Punch patterns can be viewed directly from the punch checking form,
so printing them is often unnecessary.

Course data and punching unit codes can be printed
on paper in text form. It is also possible to print punch patterns
in natural size together with an enlarged image explaining them.

The printer options often include options for
printing to a file. For example, you can print to pdf and xps files so that
the resulting file can be viewed on the screen.

Course outputs are made for the selected courses;
punching unit code outputs always contain all controls and punching unit codes.
