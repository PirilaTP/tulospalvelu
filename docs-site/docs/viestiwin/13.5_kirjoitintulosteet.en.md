# 13.5 Printer outputs

### 13.5 Printer outputs

Course data and punch codes can be printed
on paper in text form. It is also possible to print the pin patterns
at natural size together with an enlarged image explaining them.

At present the pin patterns cannot be viewed directly in the program,
but printer options often include options
for printing to a file. Among others, you can print to pdf and xps files so that
the resulting file can be viewed on screen.

Course printouts are made for the selected courses;
punch code printouts always contain all controls and punch codes.
