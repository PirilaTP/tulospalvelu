# Draw and start lists

The draw involves three steps

- Preparing the draw

  - Assigning start times

    - Numbering the competitors

All steps are reached through the menu item *Preparation /
Draw and numbering*, but the first one is done in the class data
table, which you can also open directly from the main menu.

When all these steps have been completed, the
competition data is ready for printing start lists and for the competition
itself.
