# 6.8 Utskrifter av kontrollmellantider

### 6.8 Utskrifter av kontrollmellantider

Från stämplingskontrollformuläret i programmet HkKisaWin kan du
starta utskrift av kontrollmellantiderna för den tävlande som visas med
knappen *Mellantidsutskrift* eller menyvalet *Skrivarutskrifter /
Mellantidsutskrift*. Menyvalet kan också göras med tangenterna *Alt-K,
Alt-V.* För att utskriften ska lyckas måste den skrivare som ska användas vara
vald, vilket kan göras med valet *Skrivarutskrifter / Välj
skrivare.*

Programmet kan också startas i ett läge där
avläsning av Emit-brickan startar utskrift av den aktuella tävlandes mellantider.
Detta görs genom att ge programmet parametern

rastivatuloste

När denna parameter har angetts och man sedan väljer
*Resultattjänst / Emit-avläsning* öppnar programmet ett förenklat
formulär där den tävlandes nummer kan matas in om avläsningen av brickan
av någon anledning inte lyckas. Normalt ger enbart avläsningen av brickan en utskrift.
Om användningen av skrivaren inte har aktiverats före avläsningen av den första brickan, antingen
med parametern lista
eller med valet *Skrivarutskrifter
/ Välj skrivare* på formuläret som används, kan du behöva välja skrivare
i samband med den första utskriften. Det gjorda valet gäller tills
det ändras via menyn.

För att mellantidsutskrifter ska kunna göras
någon annanstans än vid stämplingskontrollen måste dataöverföringen konfigureras så att
stämplingsuppgifterna kommer till utskriftsdatorn.

Övergången direkt till ett läge som tillåter utskrift kan automatiseras genom att ange
alla följande parametrar

```
lista
rastivatuloste     
ikkunat
```

genom att spara korrekt placerade fönsterpositioner
med valet *Filer / Spara fönster,* på huvudformuläret och genom att
med valet *Filer / Startinställningar* välja att programmet öppnas direkt i resultattjänstläget [(kapitel
2.6)](2.6_automaattinen_kaynnistyminen_tilaan.md)
.
