# 1.1 Installation

### 1.1 Installera programmet HkKisaWin

Programmet installeras med ett installationsprogram som under
installationen frågar efter den mapp där själva programmet installeras samt
den mapp där programmet installerar startfilen `init.cfg`. Programmet bör i regel installeras
i den föreslagna mappen, men den lämpligaste mappen för startfilen kan bero på
hur programmet ska användas. Det är väsentligt att programmet kan skriva
till startfilen. Startfilens mapp ska inte vara samma mapp som
programmet normalt installeras i, eftersom många Windows-versioner inte tillåter
skrivning i programfilernas katalogträd.

Programmet föreslår att mappen `kisa` skapas på skrivbordet. Den här mappen passar
som plats för filen `init.cfg`, som styr programmets start, men själva tävlingsdata
bör i regel placeras i en egen arbetsmapp för varje tävling, till exempel
en undermapp till mappen `kisa`. Den här
mappen kan skapas från programmet när en ny tävling skapas. Filen
`init.cfg` har som enda uppgift att ange vilken
tävling som behandlas och i vilket driftläge programmet ska öppnas
nästa gång det startas. Dessa val görs och sparas via programmets
menyval *Filer / Startinställningar*.
Om programmet har ställts in att starta på ett sätt som inte lyckas på grund av felaktiga
uppgifter, kan det vara nödvändigt att radera filen `init.cfg`, varefter startvalen
kan göras fritt.

Om du vill använda programmet WinKisaHk upprepade gånger
omväxlande för att hantera mer än en tävling, kan det vara klokt att använda
flera olika startfiler `init.cfg`,
var och en i sin egen mapp, och ange var och en av dessa mappar som startmapp för
en egen genväg.
