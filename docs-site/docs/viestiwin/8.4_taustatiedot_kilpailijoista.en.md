# 8.4 Background information on competitors

### 8.4 Background information on competitors

On the form for an individual competitor's data you can
request background information to be shown. This requires that the information is in a format
suitable for a web browser, either in a file on the computer in use, on the local network, or
on an internet server at an address that can be reached.

For this you must prepare a file `tietolista.txt`, which contains links to each person's
information. The file must be of the form:

```
tiedosto    tietoa.html
2345        #mattila_matti15657http://www.ssl.fi/SSL/sslwww.nsf/sp?Open&cid=UrheilijaProfiili-2&id=05C10B813E919FA8C22570B4003619E4
56789        file:///c:/hakemisto/ali/tiedosto.html#kohta
nor00001234  #norjalainen
```

The first line gives the file or URL of the page where
the later short links are found. The numbers at the beginning of the lines are
licence numbers or international (WRE or FIS) codes, which start with a
country code and must have eight digits. The other lines have either these
short links to the page of the first line or full links to the web or
to other files. A local HTML file can be very simple and of the
form:

```
<html>
<body>
<h2>Tietoa kilpailijoista</h2>
<hr>
<h3><a name="mattila_matti">Matti Mattila</h3>
<p>Tietoa Matti Mattilasta
<hr>
<h3><a name="norjalainen">Norjalainen</h3>
<p>Tietoa Norjalaisesta
</body>
</html>
```
