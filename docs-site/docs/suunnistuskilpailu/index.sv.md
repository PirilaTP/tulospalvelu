# Resultattjänst för orienteringstävlingar

Den ursprungliga handledningen för att ordna resultattjänsten vid din första orienteringstävling
med Pekka Piriläs programvara. Innehåller heltäckande anvisningar från starten
till publiceringen av resultaten.

I navigeringen till vänster finns de fullständiga anvisningarna kapitel för kapitel. Börja
från sidan [Beskrivning av exempeltävlingen](johdanto.md).
