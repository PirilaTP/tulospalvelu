# 5.6  Functions of the timing form

### 5.6  Functions of the timing form

#### 5.6.1  Contents of the form

The timing form contains

- two tables, either of which can also be
  hidden so that the other fills the space of both; the upper table can be
  scrolled and can also be used for editing data, the lower
  table always shows the latest times.- an area showing the data of the selected
    row more completely. Some of the data can also be edited, and the row shown
    can be deleted. Changes made are saved with the button Save change.
    The button Undo change cancels only unsaved changes.- the selection of the timing queue to be handled.
      Several timing tables can be opened on screen and they can show either
      the same or different queues- the possibility of choosing which data in the scrollable table
        can be changed- through the menu you can choose the key used
          for timing, change the heat in a competition where starts take place in heats, write
          the timing data to a text file and go to control some devices used
          for timing when they are connected- the button *Create new record for selected row* or the key
            F11 pressed in the timing table produces a time that is the same (strictly speaking 0.0001 s worse,
            but this only has an effect after 10 presses) as the time above the row
            on which the key is pressed.- the button *Refresh* causes the data in the tables to be refreshed
              when they are not otherwise refreshed as desired. Usually this
              button is not needed, but it can be used e.g. to cancel
              unsaved changes on the row being edited in the scrollable
              table.

#### 5.6.2  Timing with a key

Once the key to be used, and possibly also the point for which times are taken, has been selected from the menu, pressing this key
always gives the time according to the computer clock, provided that the active element is
a table or other field of the timing form that responds to
the key. The recommended key is one that does not produce any
character in a text area when pressed; for example the function key F12 is well suited
for this. The key § is also well suited for timing.

The function key F11 is reserved as a parallel way of adding times that
are identical to the time above the active row (adding 10
times in the same place increases the time by 0.001 s).

#### 5.6.3 Editing or selecting the competitor, timing point and clock time

This data can be edited in the scrollable table once you have chosen with the radio buttons
which data is handled. After editing each field, press
Enter. When the only or the second item of the row has thus been accepted, the
changes are saved to the table and the cursor moves to the next row.

The button *Save changes*) applies only to changes entered in the fields
above it. A single change may be easiest to make in this
area, repeated changes in the table.

When changing clock times, note that the Backspace key
clears the whole field, so the key *Delete* is usually
better suited for changing a time.

#### 5.6.4 Entering numbers in advance

When advance entry has been enabled with a menu
option, a box appears in the right-hand column of the form, in which the numbers entered on the row of the next
time are recorded. When a time is then received that
is tied to some point, the program picks the first of the numbers and attaches it to
that time. The box on the right can also be edited by
adding or deleting rows.

The program picks the next number only when
changes are allowed for numbers but not for points, because advance entry requires
the point to be fully determined. The point must therefore
be determined by the timing settings.

#### 5.6.5 Start time for a whole class or heat

When the key 'S' is pressed in the bib number field of the timing form of the program HkKisaWin or HkMaali,
the program asks for the class to which
the time of the row is given as start time.

In the same situation the key 'R' gives the start time
to a heat whose number is entered.

#### 5.6.6 Saving the timing form settings

Almost all settings of the timing form are saved when
the windows are saved through the menu of the program's main window while the timing form
is open. The settings are thus taken into use again when the window settings
are read either with a menu option or automatically at startup
(see [chapter 1.5](1.5_kaavakkeiden_asetusten_tallentaminen.md)).
