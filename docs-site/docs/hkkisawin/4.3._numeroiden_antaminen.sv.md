# 4.3 Tilldelning av nummer

### 4.3 Tilldelning av nummer

Lagringsordning avser den ordning i vilken uppgifterna har
matats in eller lästs från fil.

Startordningen skiljer sig från etapp till etapp. Därför är det
möjligt att välja vilken etapps startordning som används.

Numreringen kan gälla endast en vald etapp eller
alla etapper, och då gäller den även grundnumret (det permanenta numret). Det är bra att
först numrera alla etapper och sedan på nytt numrera de
etapper och klasser där det förekommer variation.

För sprinttävlingar i längdskidåkning finns ett alternativ
där alla etapper utom den första får startnumret ökat med
ett fast tal (standard 2000), så att numren hamnar i ett område som inte används
i tävlingen. De som går vidare till heatomgångarna får de nummer de använder när heaten bildas. Om nummerlapparna inte
byts vid övergången till heatomgångarna ska detta alternativ inte användas, utan alla etapper ska ges
samma nummer.

Numreringen kan gälla alla deltagare eller endast
dem som ännu inte har något nummer. I det senare fallet söker programmet
lediga nummer med början från klassens första nummer och använder dem i ordning.

Programmet delar inte ut nummer om de, att döma av
klassdata, skulle överlappa. Med knappen *Sök överlappande
nummerområden* kan du före numreringen kontrollera om det finns sådana överlappningar.
Vid kontrollen jämförs de klasser som valts för behandling med varandra och även med övriga
klasser, men inte överlappningar som enbart gäller andra klasser sinsemellan.

I föregående underavsnitt behandlades
hur klassernas lägsta nummer bestäms och de funktioner i programmet som stöder detta.
