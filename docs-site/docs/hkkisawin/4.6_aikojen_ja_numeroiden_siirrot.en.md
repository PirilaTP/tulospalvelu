# 4.6 Moving times and numbers

### 4.6 Moving times and numbers

With the option *Preparation / Moving times, numbers and stage*
you can shift the start times and numbers of competitors in selected classes.

All moves are made for the classes selected for processing.

Time moves can apply to

- only drawn start times, which can be shifted
  either by a constant amount or all set to the same mass start time.

  - actual start times produced by the start gate,
    which can be
    shifted either by a constant amount or restored to the drawn start time.

    - results, which can be increased or decreased by a chosen amount

When start times are shifted for competitors who
already have a result, you must choose whether the shift affects the result.

This form is also used to move all data of one stage of the selected class
to another stage. This feature may be needed in multi-stage
competitions where different classes take part in the stages differently.
For example, in cross-country sprint a class may skip either the quarterfinal or the
semifinal and take part in the final together with another class
that takes part in more stages. In that case it is advisable to skip
a stage during the competition, but for writing the final results the stages
must be made consecutive. This is done by moving later stages on top of
earlier ones.
