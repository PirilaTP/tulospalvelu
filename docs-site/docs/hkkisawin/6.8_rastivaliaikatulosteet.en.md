# 6.8 Control split time printouts

### 6.8 Control split time printouts

From the punch check form of HkKisaWin you can
start printing the control split times of the competitor shown using
the button *Split time printout* or the menu option *Printer output /
Split time printout*. The menu option can also be made with the keys *Alt-K,
Alt-V.* For printing to succeed, the printer to be used must be
selected, which can be done with the option *Printer output / Select
printer.*

The program can also be started in a mode where
reading an Emit card starts printing that competitor's split times.
This is done by giving the program the parameter

rastivatuloste

When this parameter has been given and you then select
*Results service / Emit reading*, the program opens a simplified
form on which you can enter the competitor's number if reading the card
fails for some reason. Normally just reading the card produces the printout.
If the printer has not been activated before the first card is read, either
with the parameter lista
or with the option *Printer output
/ Select printer* of the form used, you may have to select the printer
with the first printout. The selection made remains in effect until
it is changed from the menu.

To make split time printouts possible
elsewhere than at the punch check point, data transfer must be configured so that
the punch data reaches the printing computer.

Going directly into the mode that allows printing can be automated by giving
all of the following parameters

```
lista
rastivatuloste     
ikkunat
```

by saving correctly arranged window positions
with the main form option *Files / Save windows,* and by selecting
in the option *Files / Startup settings* that the program opens directly in results service mode [(chapter
2.6)](2.6_automaattinen_kaynnistyminen_tilaan.md)
.
