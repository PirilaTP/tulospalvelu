# Skrivar- och filutskrifter

På undersidan *Skrivarutskrifter* kan du begära fyra
olika typer av utskrifter av banuppgifterna. Av dessa är spindeldiagrammen en grafisk utskrift och de övriga
tabellutskrifter av banor och kontrollkoder.

Om datorn har stöd för att skapa pdf-filer som utskrift
är detta ett utmärkt sätt att spara de grafiska spindeldiagrammen för användning.
Vid sidan av pdf-filer kan det också finnas andra lika lämpliga
filformat, såsom *Microsoft XPS Document* eller *One Note*.
Om dessa möjligheter finns tillgängliga visas de bland
skrivaralternativen.
