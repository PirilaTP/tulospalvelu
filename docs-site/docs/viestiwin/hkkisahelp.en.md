# ViestiWin Help

## Relay results software ViestiWin and ViestiMaali

### Version 5.20

### Pekka Pirilä, 19.4.2015

ViestiWin, which uses a graphical Windows user interface,
is suitable for handling almost all functions related to
the results service of a competition. ViestiMaali is a simpler console program whose
reliability has been maximised by avoiding complex
user interface libraries and development tools. ViestiMaali is therefore better
suited to the most critical real-time tasks of major competition
events. The programs work together so that during the competition
each task can be handled with the program best suited to it.

These instructions
focus on ViestiWin, but also cover the most important aspects of using
ViestiMaali. Some additional information on using the console program ViestiMaali
can be found in the PDF instructions of the similar program HkMaali
and in the instructions of my earlier relay programs.

The program ViestiLuenta, included in earlier software versions,
is no longer included in program version 5.20, because ViestiWin handles its
tasks better.
