# 13.10 Control locations and map

### 13.10 Control locations and map

The program can display courses on a map read from an image
file and show on the map information about errors in a competitor's
punches. Use at the complaints desk is described in [chapter 6.12](6.12_kartan_kaytto_itkumuurilla.md)
. This chapter describes how the map is prepared
and how coordinate data is entered in the course data.

The program can handle image files in the form of a ready
uncompressed bitmap. A good file format is a 24-bit
\*.bmp file, but many other formats also work. The best image size depends
on the display used, and it is worth trying different options. A typical
suitable image width is about 2000 pixels. The program normally shows only
a small part of the image, and the image can be moved, among other ways, with the mouse while the left button
is held down, with the mouse on the scroll bars, and with the keys up, down,
PgUp, PgDn, left and right. The Ctrl key speeds up movement with the arrow keys
to steps 10 times
larger.

The coordinates of the map edges can be stored in the course data.
The program assumes that the map has been cropped so that the given
coordinates correspond to the edges of the image file, when the map edges are given
in the same units as the
control point coordinates.

Through the menu of the course data editing form
you can open a map file and ask for the active
course to be shown on the map. Both control and map coordinates can be edited
on a
tab of the form.

The program reads coordinate data from, among others, files conforming to
version 3.0 of the IOF XML standard, and almost completely also from files conforming to version 2.0.3.
The shortcoming may concern the map boundaries, which in that
case must be added
to the data.

Coordinate data can also be read from a csv file and
saved both to a csv file and to the program's own XML format, either separately or
as part of the course data. The smoothest use of the data at the complaints desk requires that it has been
saved as part of the course
data.

#### Aligning the map

The map is easiest to align
as follows:

- When the control coordinates have been defined in the course data
  and the map image has been prepared, open the map and show the controls on it (if
  the controls are not shown at once, this is not
  a problem).
- Open the alignment form from the menu of the map
  form.
- If no controls are shown, click the button "Coarse
  alignment". The program then aligns the map so that all controls are
  on the map and there is some free space at the
  edges.
- Select one control whose control point is easy to
  locate exactly on the map, near the left edge, and another
  control near the right edge (for this one only the horizontal position matters
  from here on, because the program does not rotate the map or change its
  proportions).
- Tick the box of the first control that allows
  pointing with the mouse and click the correct position of the selected control with the right
  mouse
  button.
- Tick the box of the second control that allows pointing
  with the mouse and click the correct position of the selected control with the right mouse
  button.
- If the alignment is not quite as desired, the
  first control can be moved horizontally and vertically and the second control
  horizontally. A vertical move affects all controls equally,
  a horizontal move keeps the other of the selected controls
  in place.
- Even finer adjustment can be made
  in the map coordinates area. There you must make several move steps before
  the controls move
  visibly.
- When the alignment is correct, transfer it to
  the coordinates sub-page of the course definition form, from where it can be
  saved
  to the course data file.
