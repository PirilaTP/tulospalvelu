### 13.11 Using course data in Reittihärveli

The course data file produced by the program (usually radat1.xml) is in a format that can be transferred to Reittihärveli.
For everything to work correctly, you should define a finish code (e.g. M)
and the coordinates of the finish point for the courses. If the punching unit of the last control included in the course
is at the finish, the same coordinates must be given for this last control and for the finish.
In many cases the program takes care of this automatically when the courses are
defined, but it is worth checking if the courses are to be transferred to
Reittihärveli.

Transferring results to Reittihärveli is described in [chapter 9.2](9.2_tiedostotulostus.md)
.
