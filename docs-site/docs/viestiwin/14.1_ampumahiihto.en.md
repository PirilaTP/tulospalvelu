# 14.1 Biathlon

### 14.1 Biathlon

Biathlon results service differs from skiing in the handling of
penalties. Information on the different penalties is given in [chapter 5.9](5.9_sakkojen_kasittely.md)
.

The number of shooting bouts and the penalty possibly
given for a miss are defined in the class data separately for each class. This
is done on the editing form for the data of a single class, where
the data of each leg contain fields
for entering these. For the whole class you can first select whether
shooting bouts are in use and whether penalty loops or time penalties are used.

Penalties are best entered in the ViestiWin form defined for this
purpose. This form can be opened
through the main form menu *Results service*.

On the penalty entry form you fetch a competitor by entering
the number and pressing *Enter*, after which the program
moves to the first shooting bout not yet handled. The program uses
a hyphen to indicate that the number of penalties has not been entered, and
clean performances must also be saved by entering the value 0. The *Enter* key moves from the penalty field to accepting the entry, and
accepting moves to entering a new bib number. If you want to enter
several penalties at once, use the Tab key to move from one field to another (and
the combination *Shift-Tab* to move back). When
the data are saved, they are also recorded in the list of entered data shown
at the top of the form.

For monitoring the completion of penalty loops there is the form
*Penalty tracking*. The table on the right side of the form shows the penalty loops not yet
recorded. When you enter the competitor's number
and leg on the form and press Enter, the program subtracts one from the
unrecorded loops of that leg.

The program also shows a list of the entries made.
An incorrect entry can be cancelled by moving to its row and
clicking *Undo selected entry*
.

Data on completed loops are transferred to other
computers as well, so opening the form shows the same data on all computers in this
respect. The list of recorded loops exists only on the computer where
the entry is made.
