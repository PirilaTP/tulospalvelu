# 9.6 Automatic printing

### 9.6 Automatic printing

The program
offers automatic printing of classes on the printer as
they receive an interesting number of new results. Automatic printing
is started from the output form option *File / Automatic
printing*, either according to the automatic printing choices made
earlier or so that the choices made on the output
control form before using this option take effect. In addition you give
a threshold value, which controls when printing starts, and a time interval which the program
uses together with the threshold value. Finally you select the finishes to which the automation
applies. Automatic file output cannot be used at the same time as
automatic printing to a printer.

Alternatively,
automatic printing can be started by placing in the configuration file
the parameter 

  AUTO=x/k/a/mmmm

where

x               gives
the scope of printing (usually L, i.e. finished; default value L; other

                 possible
values ‘I’: entered, ‘T’: those with a result and ‘Pnn’: the nn best)

k               is
the threshold value of the counter (typically between 10 ... 200, default value
10)

a               the time step
for increasing the counter (the default value 60 is usually used)

mmmm       the finish numbers
to which automatic printing applies (by default all finishes)

The latter part
of the parameters does not need to be given if the default values apply
to them.

In two-
and multi-stage competitions one of the following characters can be added
to the end of the parameter AUTO, separated by a slash:

     2                
printing in the order of the stage results

     V                
stage results only

     Y                
overall results only

     1                
also the stage 1 results in stage 2.

The default is printing of both the stage results and the overall results.
The order in the last stage is the overall result, otherwise the stage result. If some
classes have been defined in the class definitions as independent for the stage,
the program always prints
the stage-specific results, even if overall results, or both stage-specific and overall results,
have been requested with the parameters.

Two
examples: AUTO without parameters starts automatic printing with the scope
being finished competitors, threshold 10, time step 60 s and printing applying to
all finishes.

AUTO=P30/10/30/23
starts automatic printing that prints the 30 best of each class,
the threshold is 10, the time step 30 s, and printing applies only to competitors arriving at finishes 2 and 3.

The program
calculates a comparison value for each class arriving at the given finishes
as follows:

- each new
  result or correction increases the value by one,

  - writing the
    results resets the comparison value to zero,

    - every minute
      (the interval can be changed) all comparison values are multiplied by 1.5, rounding
      up.

      - when a class
        is completed so that the number of open results changes from one to zero,
        the comparison value increases by 1001.

The program checks the comparison values at short intervals. If
even one comparison value exceeds the threshold, the class whose comparison value
is highest is printed. The highest comparison value shown on the screen is not updated while
printing of some class is still in progress. If the threshold is given a value
above 16000, some class may permanently remain unprinted. If the threshold is above
24000, no classes are printed automatically. If printing is requested
only for the best, only results placing among the best are taken into account in the comparison value.
By choosing 1000 as the printing threshold and a very large time step,
printing can be made to work so that the program automatically prints
only the final results of completed classes.
