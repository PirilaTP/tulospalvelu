# Printing start lists

Start lists are written both to a printer and to a
file from the main menu item *Outputs*. There, select
the tab *Entry/start lists* and the desired one of the tabs
*Printer output* and *File output*. Alternatively,
you can start one of the most common outputs simply by selecting from the menu
*Standard outputs / All start times by class to html file*
.

If the ready-made standard output does not meet your needs, make
the desired changes to the selections on the form. Likewise, instead of all
classes, you can select only some of them. Of the available character sets,
ISO-8859-1 may still be less problematic at this stage, but the use of the UTF-8 character set
on web pages is becoming steadily more common.

For printers, the program offers the Windows
default printer, but lets you change to other printers known to Windows
on that computer, possibly including the option
to print to a pdf file using the printer output formatting.

If
the formatting of the outputs produced by the program differs from what you want, you can change it on the form opened
from the option Formatting. For start lists, there are separate tables
for formatting printer and file outputs. When a new format has been
defined, it must be taken into use with a button, and it can also be
saved to a file for later use. More information on defining formats
is given in other instructions.
