# 13.6 Checking the course definitions

### 13.6 Checking the course definitions

In this function the program goes through all courses and
compiles a list of situations where the same punching unit is repeated, reporting an error when
this happens on consecutive controls and giving a warning when there is more than
one control in between. When the function is used in results service mode, the program
also compares the course list with the entrant data and points out cases where
an entrant's course is not found in the course data.

During the check the program adds to the punching unit data all controls that are
used on some course but for which no punching unit code has been defined. The program then
gives the control code as the punching unit code. The program reports all these
additions, so the additions made can be changed before
you proceed to the final saving of the data.

The program
asks whether the course definitions should be checked every time the course data is written to the XML file
or put into use. At this point
it is also possible to cancel the saving.
