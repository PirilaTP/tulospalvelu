# 4.2.1 Förbereda lottningen

### 4.2.1 Förbereda lottningen

Obs: Främst för längdskidåkning finns ett mer automatiserat
alternativ ([kapitel 4.2.2](4.2.2_hiihdon_perusvaihtoehto.md)
).

Lottningen föregås av valet av de startnummerområden som ges
till de tävlande i olika klasser och av klassernas första starttider. Detta görs
bäst i klassuppgiftstabellen, som kan öppnas från lottningsformuläret eller
från huvudformulärets meny.

I klassuppgiftstabellen bör du

- Välja att visa uppgifterna för en etapp eller,
  när nummer tilldelas, alternativt *Grunduppgifter*, som ger
  den enklaste möjligheten att numrera med hänsyn till alla deltagare
  oberoende av närvaro per dag.

  - Välja *Första nummer* som ordning när numreringen planeras
    och *Start/starttid* när starttiderna planeras.

    - Första nummer och starttider anges i önskad
      ordning. Den storleksordning som anges i förväg bestämmer också den slutliga ordningen. I övrigt
      påverkar endast det första av de angivna värdena de värden som programmet beräknar.
      I menyn kan du välja att startplatsens nummer
      också påverkar ordningen.

      - Startens nummer samt köns nummer inom samma start påverkar klassernas ordning när starttider tilldelas.
        Programmet stöder placering av klasserna så att klasser
        i samma kö vid samma start placeras efter varandra. Därför bör till exempel i orienteringstävlingar
        åtminstone klasser som använder samma bana i regel placeras i samma
        kö. Köns nummer hjälper också till att hantera belastningen på startplatsen. Köns nummer
        påverkar inte de första numren.

När de förberedelser som beskrivs ovan har gjorts kan
klassernas första nummer tilldelas med minsta möjliga besvär via menyvalet *Automatiska ändringar* på följande sätt

- Välj *Första nummer* som ordning

  - Om du vill att numreringen av klasserna vid varje startplats
    ska börja från ett eget angivet värde, väljer du detta arbetssätt
    i menyn.

    - Definiera antalet oanvända nummer som ska lämnas mellan klasserna
      med respektive menyval

      - Välj *Bestäm
        klassernas första nummer* i menyn. Då redigerar programmet numren så att deras
        inbördes ordning bevaras, men så att klasserna kommer efter varandra med
        det begärda antalet nummer emellan. Om du har valt att starten påverkar
        genomförs detta separat för varje start. När grunduppgifterna behandlas används
        den första etappens start som start.

        - I tabellens kolumn Sista nr visas det största av de nummer
          som klassens deltagare får. Detta fält är till hjälp om du vill
          ändra numren på ett annat sätt än den automatiska funktionen.

          - Tabellen visar också klassens totala antal
            deltagare och antalet i den etapp som granskas. Den automatiska numreringen
            bygger på etappens uppgifter när
            en etapp har valts för behandling och på det totala antalet när
            grunduppgifterna har valts.

Klassernas första starttider bestäms
på motsvarande sätt

- Genom att välja *Start/starttid* som ordning. Som konstaterats ovan påverkar
  även köns nummer funktionen som komplement till startens nummer.

  - Den fria tiden mellan klasser som startar från samma start och kö
    anges i sekunder med respektive menyval. Observera
    att det är fråga om hela tiden mellan två tävlande, inte extra
    tid i förhållande till det normala startintervallet. Minst måste alltså
    ett antal sekunder lika med startintervallet anges.

    - Nu kan den automatiska funktionen startas
      från menyn.

      - I tabellen finns den sista startandes starttid i klassen
        för att underlätta manuell redigering av uppgifterna.
