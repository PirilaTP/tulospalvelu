# 5.9 Handling penalties

### 5.9 Handling penalties

The program can handle biathlon
misses and other time penalties separately. Biathlon relays usually use
penalty loops rather than time penalties, but time penalties related to misses
are also available in the program. Biathlon functions are discussed in [chapter 14](14.1_ampumahiihto.md) .

In the data of a single class, a separate
penalty field can be enabled by selecting the option
*In use* under *Penalties/handicaps*. The field
*Pen/Hcp unit* then appears in the leg-specific data. Here the size of one penalty is given in seconds.
When using the program, penalties are given as a count, which the program converts
into time using this multiplier. If the multiplier is 0, penalties are handled
in milliseconds, which is the program's internal storage precision for penalties. (For this
reason, changing the size of the penalty unit does not change the effect of previously recorded
penalties on the results, but rather the number of penalties shown in the user interface.)

When the penalty unit is selected for display in the class data table,
the program shows, separated by a slash, first the unit of the separate
time penalty and then the size of the penalty for one biathlon miss.

The default size of the penalty unit for the separate time penalty
can be defined in the competition's basic data. The program does not use this value directly;
it is used as the default when creating new classes and when enabling penalties
that were not previously in use. During operation the penalty unit saved separately
for each leg of each class is always used, so that it
can vary from class to class and from leg to leg.
