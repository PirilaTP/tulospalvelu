# 5.7  Handling heat start times

### 5.7  Handling heat start times

When the starts of a class take place according to a schedule that has not been
precisely fixed in advance, the desired number of start times can be determined from the start clock
signal. After this, the numbers of the teams participating in the heat must be entered
by hand for each time. The procedure is best handled so that the starts
are processed in a different timing queue from the finish times and split times. All queues can
most easily be handled in separate timing forms of ViestiWin or
in different instances of ViestiMaali. In timing you can use, for example,
the following parameters

```
// Timy on port 4
timy=4
// Timy START gives the start time, STOP the finish time and channel 2 split time 1
pisteet=MMMLM1
// queue 1: finish times, queue 2: start times, queue 3: split times
jonot=111213
// if the times are handled in several instances, they must be sent by giving
// the parameter LÄHAIKAx for the data transfer connections used
// when using ViestiMaali, it is worth giving the computers used for entering
// finish and start numbers the parameters
// piste=M
// piste=L
// heat size 6 teams
lähtöryhmä=6
```

When a start time is recorded for a team, the program marks
it as an individual start time. The start clock can also be used for individual starts
on later legs. On displays the start time is shown
as the point 'L'.
