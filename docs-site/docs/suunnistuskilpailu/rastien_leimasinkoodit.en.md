# Punch codes of the controls

The course data gives the control codes used on the courses, but these are
far from always the same as the codes of the punches used, which
the results software reads from the file LEIMAT.LST. This
file can be created, or viewed and edited, on the tab
*Control punching units.*

The punch codes are listed in a table on rows whose first
column contains the control code visible to the competitor and given in the course data, and
whose other columns contain the punch codes. In exceptional cases the punches may have
more than 6 codes, in which case two rows with the same
control code are used.
