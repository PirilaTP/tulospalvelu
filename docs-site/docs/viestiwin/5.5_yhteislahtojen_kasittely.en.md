# 5.6  Handling mass starts

### 5.6  Handling mass starts

Competitors can have a start time that differs from
the normal relay procedure. Chapter 4.1 deals with times given
in advance; this chapter deals with times given during the competition.

The most common procedure is that a relay organises a single
mass start for teams that have progressed more slowly than others, in which all those
competitors start who have not been able to start by the predetermined changeover
closing time. Some competitions have several such mass starts,
either for different classes at different times or for different legs at different times. In the program
option *Results service / Mass starts* you can, if desired, define
each of these start times separately. Likewise, more than one changeover closing time
can be defined.

The changeover closing time defined for each leg
means the time by which the previous leg must arrive at the changeover so that
the runner of the leg corresponding to that row can start in the normal relay manner.

When the entry has been made and put into use, the
program records the mass start time in the competitor data of those competitors whose
participation in the mass start has been confirmed by the arrival of the previous leg at the changeover.
The entry is not made while the previous leg is still in progress, because
it could also be a gap in recording the results.

Changes made to the mass start time or the changeover closing time
are also immediately applied to all competitors whose
participation in the mass start can be deduced from the new data or could
be deduced from the earlier data. Entries that have become unfounded
are thus removed immediately.

Through data transfer the program sends other computers
information on the mass start and also on the competitors whose data changed
in this connection.

The function described above applies to cases where
the competitor's start time has been defined to be determined automatically. The start time type
can also be defined as individual with the letter Y, after which
the start time is entered. Such start times do not change when mass start time marking
is put into use or its properties are changed.
