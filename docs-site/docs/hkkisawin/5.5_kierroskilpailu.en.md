# 5.5  Lap race

### 5.5  Lap race

A lap race means a competition in which
the ranking is determined primarily by the sequence number of the last split time
taken for the competitor and secondarily by the time at that last
point.

It is advisable to handle a competition
as a lap race also when the winner's number of laps
is known in advance, but those more than a lap behind finish
the race after completing fewer laps than the winner.

A competition is defined as a lap race with the sport specification
made on the form *Basic data definition*.

In a lap race all times are taken
as split times, for which you should reserve at least one more slot than any competitor
can get, so that the program can handle the results in the best
possible way. The competitor's finish time field is used as a second storage field
for the last split time taken, and the number of laps is stored
in the daily points field. Both items are shown on the status display,
and the number of laps can be included in the results by selecting
the points display in the formatting. In the formatting you can also change the heading
*Points* for example to *Laps*
, if
column headings are wanted to clarify the results list.

The program shows the number of laps completed unless
the output control form requests showing the number of missing laps, which the program calculates
by comparing with the number of laps of the class winner.

**Note. Since the competitor's final result is determined
from the split times, all changes must be made to the split times, not
to the finish time.**
