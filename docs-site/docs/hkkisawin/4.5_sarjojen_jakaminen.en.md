# 4.5 Splitting classes

### 4.5 Splitting classes

On the sub-page *Splitting classes* you can split a class into several classes. This
is typically needed when forming qualification classes when the competitors have been
entered in a single class. In a competition where classes vary, the split can
apply to one stage only, for example only the qualification stage. The split can
be based on a draw or on ranking. It is also possible to split a class by
club, either spreading each club over different subclasses or keeping the whole
club in the same subclass as far as possible.

The split is performed by first selecting the class to be split
and then the classes to be formed. The program shows numerical
information about the split and lets you modify
it before finally confirming the split.
