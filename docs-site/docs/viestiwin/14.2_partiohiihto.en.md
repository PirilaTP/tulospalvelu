# 14.2 Patrol skiing

### 14.2 Patrol skiing

Patrol skiing is a competition format in which a four-person patrol moves together and
shoots at one shooting bout, which yields penalties both for misses and
additionally for targets left standing.

The sport of the competition is defined as biathlon and the sub-discipline as patrol competition.
The penalty unit is normally 180 s, which should be included in the
basic settings, but you must also make sure that the value is correct
in every class.

In the class data, select for each class

- Shooting ranges (or equiv.): *Time penalties in use*- In the anchor leg data: *Penalty places*: 2 and *Shooting penalty*.: 180 (unless
    the value is different)- If you also want to prepare for penalties other than
      those from misses, you must also enable
      *Penalties/handicaps* and define a suitable unit (see [chapter 5.9](5.9_sakkojen_kasittely.md))
    - A start interval is also entered for each leg (normally 120)

Competitors are saved as in a normal relay. A value can also be
entered for competitors, which can be brought up in the table *Teams*.

Penalties are entered in the option *Shooting penalties*. The program allows
9 as the maximum number in each field, so two shooting bouts can be used
so that misses up to 9 are recorded in the first bout and
penalties exceeding 9 in the second bout. (When there are 9 misses and
one target is left standing, the second gets 1; with 2 targets left standing, 3, etc.)

Times can be taken as in normal timing when the team reaches the finish. The time
is recorded for the anchor leg. ViestiWin by default offers saving
for the anchor leg; in ViestiMaali you must select the default leg yourself.

Results are normally written using the options *Legs to
print: All legs* and *Legs compactly one after another*. If
you want the number of penalties in the results, the penalty field length must be defined
as at least 4 in the settings of the all-legs output. If desired, the value can be
included in the formatting of the compact output.
