# 6.3 Handling control route penalties

### 6.3 Handling control route penalties

Control route penalties are handled in ViestiWin
by entering their number either in the function *Emit reading* [(chapter 6.1)](6.1_leimantarkastuskaavake.md) in the field *Penalties (RR)* or on the competitor data
editing form [(chapter
7)](hkluku7.md)
 in the column *Penalty* of the table area.
The corresponding options are also available in the program ViestiMaali.

The size of the penalty in seconds must be given in the
data of each control route class. To make this as easy as possible, the
default penalty unit defined in the competition's basic properties [(chapter
2.1)](2.1_uuden_kilpailun_luominen.md) must be the desired penalty size.
When this value is as desired and you then select, on the form for defining
the data of an individual class [(chapter
2.2)](2.2_sarjatietojen_maarittely.md), the option *Time penalties* under Penalties, the program changes the value of the field *Penalty
per error* to that number of seconds (normally 600). This value can be changed
per class, but visiting the field *Penalties* again
takes the default value back into use.

The program stores the size of the penalties in seconds.
The number of seconds can be made visible by changing the size of one penalty
to 1 s in the class data. The number of penalties is also shown as a count in the results lists,
provided that the size of one penalty has been defined normally.
