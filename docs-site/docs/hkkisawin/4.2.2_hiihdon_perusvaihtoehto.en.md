# 4.2.2 Basic option for cross-country skiing

### 4.2.2 Basic option for cross-country skiing

Mainly for cross-country skiing competitions, an option is offered
that combines three functions:

- Determining the first bib numbers
  of the classes

  - Determining the first start times
    of the classes

    - Adding vacancies at the beginning of each
      class

The function is otherwise a combination of two
functions described in the previous chapter, but in addition
vacant entrants are created at the same time. The function is also restricted
to the following model:

- The classes start one after another

  - The same number of vacancies is added at the beginning
    of each class

    - The classes are numbered as one continuous sequence, so that
      the first vacant place of the next class immediately follows the last starter
      of the previous class in terms of both number and start time.

When this solution is suitable, the function is carried out
as follows:

- Show the class data of one stage on the screen.

  - For the class starting first, enter as the lowest
    bib number and first start time the values that you want
    for the first vacant place in start order.

    - For the other classes, enter values in the bib number field
      that indicate the start order of the classes (only the order of magnitude
      matters).

      - Enter the start intervals for all classes.

        - Select *First number* as the
          table order.

          - Select from the menu the number of vacancies to be added
            at the beginning of the classes.

            - Select from the menu to carry out
               *Ski competition base model* .

After this you can move on to the draw, where the checkbox
*Skip vacants in both draw and
numbering* must be ticked. The program should tick this box automatically when
the function described above has been carried out first and when there are no vacancies
in the competition classes other than those created by the program.

If you want to create vacant place
"competitors" at the beginning of the classes in the same way as described above, but give them
different numbers per class, the first numbers and start times of the actual
entrants of each class must be entered manually and then the menu option for filling
the places used. The program adds
the competitors, calculating their number from the bib numbers, so start times may overlap or the interval between them
may grow unless the data has been entered correctly.
