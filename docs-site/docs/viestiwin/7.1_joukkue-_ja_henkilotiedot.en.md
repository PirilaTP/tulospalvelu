# 7.1 Team and personal data

### 7.1 Team and personal data

Participant data can be viewed and edited both
in the table *Teams* and on the form showing the data of
one team. The participant table is particularly suited to viewing several
teams and making changes to them, while viewing and editing the data of an individual
team is clearest on the form *Team data*, which is opened by selecting *One team* from the menu or by clicking a row
in the team table.

Both in the table and on the form, making changes
requires that they are allowed with the button *Allow
changes*.

The competitor to view can be selected while the form *Team data* is in search and view mode
by typing the competitor's number in the relevant field, by selecting a class and browsing,
or by using the name search, which can also be completed by browsing.

When the form is in edit mode, the search functions are not
available. The button *Allow editing* is hidden so that it cannot be used to
leave edit mode. The button *Cancel changes* discards the changes and
the button *Save* saves the data. Edit mode is left with these
buttons or by closing the form, except in repeated additions mode:
there *Cancel* discards the changes but leaves edit mode on, just as
*Save* opens the next addition.

On the form *Team data*
you can also add and delete one team through a menu selection, and switch to
repeated additions mode, in which saving moves on to the next
addition.

On both forms you can select from the menu which
data is shown.

Filtering is also available in the team table, which
affects which teams are shown.

On the one-team form you can
search through the menu either by chip code or by the name of a leg's
runner.

To make editing running orders easier, an
auxiliary form is available; it opens with a button on the one-team form,
available while the form is in edit mode. Changes made on this auxiliary form
must be saved with the button
*Save* of the one-team data
.
