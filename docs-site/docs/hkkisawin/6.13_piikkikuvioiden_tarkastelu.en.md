# 6.13 Examining pin patterns

### 6.13 Examining pin patterns

Using a button on the punch check form you can
open the pin pattern window. The window opens showing the pin pattern of the selected
competitor. After opening, you can select another
competitor or the course to be examined.

When the course has been selected based on the competitor and
the competitor's punch data has been read, the program shows with red circles
the points corresponding to missing punches (all punching units of the missing controls); in other cases
all pin positions are shown with black circles.

The adjacent table shows the sequence numbers of the controls
corresponding to each pin position. If not all numbers fit on the screen,
widening the form helps. The program also lists in a text window the cases where
the same punching unit code occurs at more than one control.

On the form you can highlight the pin marks produced by the punching units
of a particular control. This makes checking easier when several
controls have alternative punching units and when many
controls must be checked, for example because of a dead card.
