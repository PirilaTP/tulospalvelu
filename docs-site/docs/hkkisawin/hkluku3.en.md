# Chapter 3. Recording entries

## 3 Recording entries

Entries can be recorded either by entering them
on the entry form or by reading them from a text file.

In orienteering and skiing competitions the most common practice is
to read the entries from data produced by the IRMA or Kilmo system
with *Entries / Get from file*
.

The entry form
can be used in two different modes:

- In **add mode**
  every new entry
  creates a new record
- In **edit mode**
  previously created vacancy records are used as a basis,
  and the competitor's data are recorded in them

The mode is selected on the tab *Selection of functions
and data to process*. The choices made there also affect
data entry in many other ways, determining the fields that
are available and the ways in which
the program helps you find the data being entered.

Edit mode is particularly useful in
mass events where participants are handed bib numbers. When a record
already exists for every number handed out, the result can be recorded
even if the recording of personal data has been incomplete. The program also works
more smoothly in edit mode whenever participants are added simultaneously
from several different points. It is therefore recommended to create enough
vacancy records in advance and
to edit them whenever work is done
in results service mode with data transfer in use.
