# 6.15 Calculating results from control splits

### 6.15 Calculating results from control splits

Some competition formats use Emit chips
for timing so that some "control legs" are included in the result and some are skipped
as transfer or waiting phases. Such result determination can be implemented
as follows:

1. Define the course data so that each point
   affecting timing is handled as a control. Control codes and
   the use of punching units at controls are defined in the usual way.

   - The clearing lead time is used as in orienteering.
     If timing starts from clearing, the clearing lead time is 0.

     - For the finish the definition is usually: No punching unit on finish line. A punching unit on the finish line
       is then handled like other punching units and not as in normal
       timing.

       - In the class data, define for all classes
         enough split points to store all the desired results.
         The total result is stored as the finish time.

         - From the menu of the punch check screen go to the option
           *Functions / Calculating online times from control splits*. On this form
           you can define the timing rules either one class at a time or uniformly for all
           classes.

           - In the table, define for each timing interval the start and end points
             according to the sequence numbers of the "controls".
             The time calculated in this way is stored in the split point whose sequence number
             is given in the column *Point*. Point = 0 means the final result.
             The time of the point given in the column *Base point* is added to the calculated
             time. If desired, the same interval can be stored in one point as such
             and in another point with the preceding split time added to it. The rows are processed
             in the order of definition, so a time to be added must be defined before it
             is used.

             - You can choose that the times are calculated whenever
               a card is read. Alternatively the times can be calculated all at once using
               the buttons on the form.

The time calculation uses the points as
the "punch check function" has recorded them for the various controls. Of the times recorded
for the same control, only the first is used.
