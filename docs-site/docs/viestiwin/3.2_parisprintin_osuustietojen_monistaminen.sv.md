# 3.3 Duplicera sträckuppgifter i parsprint

### 3.3 Duplicera sträckuppgifter i parsprint

I formuläret *Kopiering av sträckdata* kan deltagaruppgifter som registrerats för en
sträcka kopieras till en eller flera andra sträckor.
Den sträcka vars uppgifter kopieras är källsträckan. De sträckor som uppgifterna
kopieras till anges i fältet *Målsträckor* genom att skriva numren på alla
önskade sträckor åtskilda med mellanslag. Till exempel i en stafett där
båda deltagarna åker tre sträckor väljer du först sträcka 1 som källsträcka
och "3 5" som målsträckor, och sedan sträcka 2 som källsträcka och
"4 6" som målsträckor.

Överföringen kan göras på en gång för alla klasser eller endast för valda
klasser. Om antalet sträckor varierar kan målsträckorna väljas enligt det största
antalet sträckor, eftersom programmet hoppar över begäranden som överstiger antalet sträckor i den tävlandes
klass.

I allmänhet kan alla personuppgifter om den tävlande kopieras,
även om inte alla uppgifter används, så som är förvalt i formuläret. Däremot
kopieras bankoden i allmänhet inte.
