# 9.5  Automatisk utskrift

### 9.5  Automatisk utskrift

Både skrivar- och filutskrift kan startas
automatiskt. Detta kan ske antingen med parametrar eller
via utskriftsfunktionernas menyer medan programmet körs.

#### 9.5.1 Automatisk utskrift av html-filer

I en stafett genomförs automatisk utskrift oftast
så att resultaten för varje sträcka skrivs till en egen fil
och eventuella mellantidspunkter också var och en till en egen fil. Detta kan
genomföras med hjälp av filen autofile.lst,
där alla punkter som ska skrivas ut räknas upp. Varje rad i filen
har formen

```
sarja osuus  piste
```

där växling/mål anges med punktnumret 0.

Programmet lägger till preciseringen \_sarja\_osuus\_piste.html i namnstammen
för de html-filer som skapas.

Filens namnstam tied.nimi kan anges med parametern

```
html=tied.nimi/tulostusväli
```

där tied.nimi också kan innehålla en katalogsökväg och tulostusväli
anges i sekunder. Denna parameter
startar också den automatiska utskriften genast när programmet har startat.
Ett förfarande där de automatiska utskrifterna med hjälp av katalogsökvägen styrs till en egen
mapp gör arbetet tydligare.

#### 9.5.2  Överföring av filer till servern

När en html-fil har skrivits kan den skickas automatiskt
till en www-server med hjälp av en extern kommandofil. Programmet startar
efter utskriften det kommando som definierats med parametern

```
KOMENTO=komentotiedosto
```

Kommandot måste fungera utan att användaren ingriper
och det får inte skriva på skärmen (stdout styrs automatiskt
så att den inte syns).

I tidigare versioner hade programmet också en inbyggd FTP-/SFTP-överföring,
som definierades på formuläret *Inställningar för filserver* och
sparades i filen `AutoJakelu.xml`, samt en motsvarande
startparameter `AUTOJAKELU`. Funktionen har tagits bort (den krävde
ett kommersiellt tillägg) och ersätts nu av denna `KOMENTO=`-väg.

##### Rekommenderad lösning: rsync + SSH

Ett modernt och säkert sätt att överföra resultatfilerna är `rsync`
över en SSH-anslutning. `rsync` överför endast ändrade filer, och
flaggan `--delay-updates` byter de enskilda filerna från tillfälliga namn
till slutliga namn först i slutet av överföringen. På så sätt ser åskådarna normalt inte
en halvfärdig html-fil. Autentisering med en offentlig SSH-nyckel ersätter
lösenordet, så överföringen lämpar sig för automatisk körning.

Förutsättningar: Windows 10/11, WSL2 + Ubuntu (installation med `wsl --install`
i PowerShell som administratör) och SSH-åtkomst till målservern.

Skapa en nyckel och kopiera den till servern från WSL-terminalen:

```bash
ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519_kisa
ssh-copy-id -i ~/.ssh/id_ed25519_kisa.pub user@kisapalvelin.fi
```

Lösenfrasen måste lämnas tom, så att överföringen lyckas utan
åtgärder från användaren.

Skapa den kommandofil som resultatprogrammet startar. Spara den
någon annanstans än i den html-katalog som publiceras, t.ex. med namnet
`C:\kisa\siirto\siirto.cmd`:

```cmd
@echo off
set LOG=C:\kisa\siirto\siirto.log

wsl -- rsync -a --delete-after --delay-updates ^
  -e "ssh -i /home/KÄYTTÄJÄ/.ssh/id_ed25519_kisa -o StrictHostKeyChecking=accept-new -o ConnectTimeout=10" ^
  /mnt/c/kisa/www/ ^
  user@kisapalvelin.fi:/var/www/html/kisa/ ^
  >> "%LOG%" 2>&1

exit /b %ERRORLEVEL%
```

Windows-sökvägen `C:\kisa\www\` syns i WSL i formen `/mnt/c/kisa/www/`.
`ConnectTimeout=10` förhindrar att kommandot blir hängande vid ett
nätverksavbrott. Håll `siirto.cmd` och `siirto.log` i en annan katalog än
de html-filer som publiceras, så att de inte speglas till servern.

Koppla kommandot till resultatprogrammet i konfigurationsfilen:

```
HTML=c:\kisa\www\tulokset.htm/60/S
KOMENTO=c:\kisa\siirto\siirto.cmd
```

Om WSL inte kan installeras kan samma sak göras med Windows egen OpenSSH-klient
och ett separat installerat rsync-paket (cwRsync, MSYS2). Då
anropas `rsync.exe` direkt och sökvägarna är i Windows-format.
