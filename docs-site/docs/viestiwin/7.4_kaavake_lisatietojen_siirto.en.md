# 7.4 Form: Transfer of additional data

### 7.4 Form: Transfer of additional data

With the selection *Transfer additional data* you can transfer
many different kinds of data from a file to the competitors, as well as initialise or
clear fields. In most cases the competitors to be processed are identified
by a numeric code, which can be the bib number or another ID number stored
in the data. Identification can also be based on fields
that have the same value in the data of several teams. The value is then recorded for all those meeting this condition.

Where applicable, you can select the leg to which
the transfer applies. When the transfer is made for all legs, all legs get
the same value, except with the selection *All course codes*, which transfers
to each leg its own code from a file whose lines consist of the team number followed on the same line by the forking codes.
