# 7.1 Lag- och personuppgifter

### 7.1 Lag- och personuppgifter

Deltagaruppgifterna kan granskas och redigeras både
i tabellen *Lag* och på formuläret som visar ett lags
uppgifter. Deltagartabellen lämpar sig särskilt för att granska flera
lag och göra ändringar som gäller dem, medan granskning och redigering av ett enskilt
lags uppgifter är tydligast på formuläret *Lagdata*, som öppnas genom att välja *Ett lag* i menyn eller genom att klicka på en rad
i lagtabellen.

Både i tabellen och på formuläret förutsätter
ändringar att de tillåts med knappen *Tillåt
ändringar* .

Den tävlande som ska granskas kan väljas när formuläret *Lagdata* är i sök- och visningsläge
genom att skriva den tävlandes nummer i fältet för det, genom att välja klass och bläddra
eller genom att använda namnsökning, som också kan kompletteras med bläddring.

När formuläret är i redigeringsläge är sökfunktionerna inte
tillgängliga. Knappen *Tillåt redigering* döljs, så att man inte kan
lämna redigeringsläget med den. Knappen *Ångra ändringar* förkastar ändringarna och
knappen *Spara* sparar uppgifterna. Redigeringsläget lämnas med dessa
knappar eller genom att stänga formuläret, utom i läget för upprepade tillägg:
där förkastar *Avbryt* ändringarna men låter redigeringsläget vara på, liksom
*Spara* öppnar nästa tillägg.

På formuläret *Lagdata*
kan du också lägga till och ta bort ett lag via ett menyval samt gå
till läget för upprepade tillägg, där programmet efter sparandet går till nästa
tillägg.

På båda formulären kan du i menyn välja vilka
uppgifter som visas.

I lagtabellen finns också filtrering, som
påverkar vilka lag som visas.

På formuläret för ett lag är det möjligt att via
menyn söka antingen på brickkod eller på namnet på sträckans löpare.

För att underlätta redigeringen av löpordningar finns
ett hjälpformulär, som öppnas med en knapp på formuläret för ett lag,
som är tillgänglig när formuläret är i redigeringsläge. Ändringar som görs på detta hjälpformulär
måste sparas med knappen
*Spara* på formuläret med ett lags uppgifter
.
