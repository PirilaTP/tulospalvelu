# 8.1 Allmänt

### 8.1 Allmänt

Programmet ViestiWin bygger delvis på det tidigare programmet
WinKuulutus och innehåller alla dess funktioner. Det finns flera olika
uppföljningsvyer, av vilka många kan användas i flera
fönster samtidigt (i allmänhet 6). På så sätt kan du till exempel följa flera klasser eller
tävlande i egna fönster.
