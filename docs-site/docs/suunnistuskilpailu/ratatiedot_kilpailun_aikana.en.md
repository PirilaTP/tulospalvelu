# Course data during the competition

Course data can also be viewed and handled during the competition. This lets you,
for example, make changes needed when punches fail.
During the competition, the button *Apply changed
data* is available, which activates the changes made on this
form. Note that the data must first be saved
to a file and only then can it be applied. The changes made do not affect
the results service until they have been applied in this way.
