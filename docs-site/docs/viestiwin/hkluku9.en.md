# Chapter 9. Output to printer and file

## 9 Output to printer and file

In the selection *Outputs* printouts and files are produced for both start lists and results
lists. For now, however, automatic output cannot be handled with HkKisaWin; it must be
done with HkMaali.

There are very many output options, but not all selectable outputs work as intended yet.

The formatting of the output can be edited by selecting formatting from the menu. The formatting settings (chapter 9.3) are for now similar
to those in my earlier programs. The formatting of start lists and results lists is saved separately. The results list formatting
is compatible with HkMaali.

Printing course and punch unit data is covered in chapter 13.
