# 8.1 Allmänt

### 8.1 Allmänt

Programmet HkKisaWin bygger delvis på det tidigare programmet
WinKuulutus och innehåller alla dess funktioner. Det finns flera olika
uppföljningsvyer, och för många av dem kan flera fönster användas samtidigt
(i regel 6). Därmed kan man följa till exempel flera klasser eller
tävlande i egna fönster.
