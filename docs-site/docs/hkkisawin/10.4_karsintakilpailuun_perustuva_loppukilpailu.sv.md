### 10.4 Final baserad på kvaltävling

Att bilda en final motsvarar i många avseenden det
förfarande som beskrivits ovan för sprint i längdskidåkning. Att överlappande
nummer undviks måste dock säkerställas genom att finaletappens
nummer flyttas till ett lämpligt område med numreringsformuläret, om inte klasserna
redan har definierats så att överlappning inte kan uppstå.

Själva finalen bildas sedan i formuläret *Skapa final*. Formuläret är utformat
med tanke på att det finns två etapper, först kvalet och sedan finalen.
Formuläret används i kvaltävlingens resultattjänstläge.

Som hjälp för att bilda finalerna kan du skriva en
skriptfil (standardnamn `finsaannot.txt`),
som
består av rader av följande slag:

```
A-FINAALI:; sarja;lkm/kars.sarja;kaikkiloput;annalähtöajat;ens.lähtö;lähtöväli;aalto;numeroalku;rajaus;takaa-ajo
karsintasarja
LOPPU
```

Eller som exempel

```
A-FINAALI:; H21A; 10; 0; 1; 15:00:00; 60; 1; 1; 1; 0
B-FINAALI:; H21B; 10; 0; 1; ; ; 1; 201; 1; 0
C-FINAALI:; H21C; 0; 1; 1; 13:20:00; 60; 4; 0; 3; 0
H21K1
H21K2
H21K3
H21K4
LOPPU
A-FINAALI:; D21A; 10
B-FINAALI:; D21B; 0; 1; 1; 13:00:00; 60; 4; 0; 3; 0
D21K1
D21K2
LOPPU
```

Filens struktur påminner mycket om hur uppgifterna är placerade i själva formuläret.
Kolon efter ordet FINAALI är obligatoriskt. Mellan fälten
ska det finnas ett skiljetecken, som kan vara antingen semikolon eller tabulator;
mellanslag är tillåtna men fungerar inte som skiljetecken.

En rad som börjar med
`A-FINAALI:` innehåller samma fält i samma
ordning som formuläret. Uppgifter som kryssas i anges med siffervärdena 0 eller
1, övriga uppgifter på samma sätt som i formuläret. I början kan det i stället för bokstaven
`A` stå
 `B, C, D` eller `E`.

För finalklasserna ska minst klassens namn och
antalet som ska tas ut till den anges, eller i nästa kolumn ett tecken för att alla
återstående tas med. Övriga fält kan utelämnas, varvid programmet använder antingen
uppgifter från klassuppgifterna (starttid, startintervall och numreringens början) eller
standardvärden (starttider tilldelas, startvågens storlek är 1, endast
godkända tas med, jaktstart används inte).

Två skiljetecken med högst
mellanslag emellan betyder att det ovan beskrivna standardvärdet används för
fältet i fråga. På så sätt kan du till exempel använda starttid och startintervall
enligt klassuppgifterna men ange numreringens början, så som gjorts ovan för B-finalen H21B.
Uppgifterna för damernas A-final representerar det minsta som
måste definieras.

Tecknet `takaa-ajo` kan
vara 0 eller 1 (1 betyder jaktstart) och `rajaus` 1, 2 eller 3, där 1 betyder endast
godkända, 2 godkända, diskvalificerade och utgångna och 3 alla
anmälda inklusive ej startade.

Efter finalklasserna följer kvalklassernas namn,
vart och ett på en egen rad utan andra uppgifter.

Efter varje bildningsfas kommer raden `LOPPU`, varefter en grupp rader som beskriver
nästa fas kan börja. Programmet läser alltid en fas i taget, varefter
fasens uppgifter vid behov kan redigeras och fasen sedan genomföras
innan nästa fas läses. När alla faser har gåtts igenom eller formuläret
har stängts och öppnats på nytt kan samma eller en annan skriptfil väljas
för behandling. En fas kan hoppas över genom att genomförandet utelämnas och
nästa fas läses.

Skriptet kan skapas med programmet genom att formuläret för
varje fas
fylls i och dess innehåll skrivs till skriptet via ett menyval. Skrivningen sker
i slutet av den valda filen, så den kan göras i flera omgångar. Å andra sidan
måste det gamla skriptet raderas eller ett nytt skapas med ett annat namn om du vill utelämna
det tidigare innehållet. Om starttid, startintervall,
vågstorlek och/eller numreringens startvärde töms innan skrivningen till skriptet, bestäms de raderade uppgifterna utifrån klassuppgifterna
när skriptet används.
