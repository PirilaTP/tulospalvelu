# Pekka Piriläs resultatprogram

Användarhandböcker för de resultatprogram som Pekka Pirilä (1945–2015) ursprungligen påbörjade
år 1986. Denna webbplats samlar anvisningarna från den ursprungliga webbplatsen [tulospalvelu.fi/pirila](https://www.tulospalvelu.fi/pirila/ohjeet/)
på ett ställe och håller dem lättillgängliga.

## Programfamiljen

**HkKisaWin** och **HkMaali** — programvaran för individuella tävlingar (hk =
henkilökilpailu, individuell tävling). Används för tidtagning i orientering, längdskidåkning, skidskytte och
andra individuella grenar.

**ViestiWin** och **JukMaali** — programvaran för stafett- och lagtävlingar.
Används i stafetter i löpning och längdskidåkning, Jukolakavlen och liknande
evenemang.

Programmen släpptes under GPLv3-licensen av Pekkas familj år 2016.
Källkoden finns i [repositoriet PirilaTP/tulospalvelu](https://github.com/PirilaTP/tulospalvelu).

## Om dokumentationen

- Anvisningarna har överförts från den ursprungliga HTML-webbplatsen genom automatisk konvertering.
  Formateringen kan på sina ställen vara ofullständig. Om du hittar problem kan du
  redigera sidan direkt på Github med knappen "Edit this page" överst på
  varje sida.
- Anvisningarna är ursprungligen skrivna på finska; denna svenska version är en översättning.
  Programmens användargränssnitt kan växlas mellan finska, svenska och engelska.
  Konfigurationsparametrar, filformat och den interna namngivningen är fortfarande finskspråkiga.
- Anvisningarna härstammar från åren 2012–2015 och gäller funktionen i HkKisaWin
  version 5.x. Vissa detaljer, särskilt filformat
  och utrustningsanslutningar, kan ha ändrats i nyare versioner.
