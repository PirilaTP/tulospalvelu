# 9.3.1 Additional HTML settings

#### 9.3.1 Additional HTML settings

On the formatting form page *Html settings*
you can adjust many features related to the appearance of HTML outputs, such as
font sizes, the use of table borders and the use of colours. All
settings are made separately for the normal HTML output and the mobile output.

Most of the options apply only to outputs using the table format,
but e.g. the basic colours also apply to the plain text format.

The selected font type is used for all text
except the result rows of plain text output, whose font type cannot
be changed because it must be monospaced.

- **Use table column widths** means that the column widths
  are determined by the formatting settings, not by the length of the text output.

  - **Links to classes** can be shown
    only at the beginning of the output or before each class

    - **css formatting settings** are
      easier to use as the program's internal ones. This page affects exactly those
      settings. Your own file gives some further possibilities

      - **Background colour change step** gives
        how many consecutive rows always have the same colour when two
        row colourings are in use

        - **Cell borders.** By default the program does not use table cell
          borders, but they can be enabled. It is usually
          advisable to use 1px lines then. The line colour can be selected below
          in the colour selections. E.g. light grey can be a good choice. The line width of control split time outputs is selected separately.

          - **Cell margins**. Inside the table cell
            borders there is a little empty space to keep the texts apart. The default
            is 5px horizontally and 1px vertically.

            - **Relative sizes of titles**.
              The program adjusts the size of the titles relative to the base font size. The ratio
              is given as a percentage. The default values are 150% and 120%.

              - **Font size of control split time output**
                . By default 80% of the base font size.

                - **Column headers**, Column headers
                  are enabled on the basic settings page. Here you can choose whether the headers are bold.

**Responsive HTML output**

The option **Responsive** of the css formatting settings produces
a results page that scales according to the screen width. This option is
the default for the mobile output, and it can also be selected for the normal HTML output.
A responsive page is always written in the UTF-8 character set.

- On a narrow screen (less than about 640 px) the bib number,
  club, country and other secondary columns are hidden. The club is then shown below the name
  in smaller text.
- In split time and stage outputs the table can be scrolled horizontally, and the name column stays in place.
- Links to classes are not written at the top of the page and rows are not coloured alternately; rows are separated by a thin line.
- When classes are output to separate files, the program writes, instead of a frame structure,
  a main page with links to the classes, and each class page has a link back to the main page.
- Characters significant in HTML (&amp;, &lt;, &gt;) are encoded correctly in names and clubs.

Colours, font type, font size, title sizes and cell margins
are taken into the responsive output from the same settings as for other table-format outputs.
The columns have CSS classes of the form `c-sj`, `c-nimi`, `c-sra`, `c-tls` etc., so
the appearance can be adjusted with your own CSS file if needed.

The page header and footer files (`HTMLALKY.TXT`, `HTMLALKM.TXT`, `HTMLLOPY.TXT` and
`HTMLLOPM.TXT`) are not used when **Responsive** has been selected in the css formatting settings
(the default for the mobile output); instead the program writes the beginning and end of the page itself.

**Colour selections**

Both the background colour and the text colour can be selected
for the following elements:

- **Results window**. This means
  the area outside the tables containing results, i.e. e.g. the titles.

  - **Table rows 1 and
    2**. Two different colourings are used alternately for the table rows. The change happens at the selected step. The 2nd colouring
    of control split time outputs can be selected separately.

    - **Column headers**.
      Available when column headers have been selected to be shown.
      For control split time outputs the selection is made separately.

      - **Frame areas**. This applies to the case
        where classes are output to separate files, in which case the main title and the links
        to classes are in the frame area.

In addition you can select the colour of the table borders.
(It is selected in the same place as the text colour.)

The background colour and text colour are selected from their own
drop-down menus. If you want to use more colours, click the top
option **New colour**. This opens the colour definition form.
When the colour selected with it has been accepted, you may have to select this colour
again before it can be used. (The colour is available when
it is shown in the colour sample box.)

When the selections made on the page are applied, the
user-defined colour is saved at the bottom of the colour menu.

All selections made can be saved
in a formatting file. User-defined colours
that are the colour of some element at the time of saving appear on the bottom
rows of the colour menu when the formatting is taken into use again. Unused user-defined
colours are not saved.
