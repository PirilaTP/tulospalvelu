# 6.10 Viewing pin patterns

### 6.10 Viewing pin patterns

Using a button on the punch checking form you can
open the pin pattern viewing window. The window opens showing the pin pattern of the
currently selected competitor. After opening, you can select another
competitor or the course to be viewed.

When the course has been selected based on the competitor and
the competitor's punch data have been read, the program shows with a red circle
the points corresponding to missing punches (all punching units of the missing
controls); in other cases all pin positions are shown with a black circle.

The adjacent table shows the control sequence numbers corresponding
to each pin position. If not all numbers fit on the display,
widening the form helps. The program also reports in a text window the cases
where the same punch code occurs at more than one control.

On the form you can highlight the pin marks produced by
the punching units of a particular control. This makes checking easier when several
controls have alternative punching units and when many controls have to be checked,
for example because of a dead card.
