# Tidtagning

### Tidtagning

Även tidtagningen sköts numera enklast med programmet
*HkKisaWin*, men *HkMaali* kan vara smidigare att använda när
man har vant sig vid
det.

Om en målklocka används lönar det sig att ställa in den så att den ger tider enligt lokal tid,
om det på något sätt är möjligt. På så sätt undviker du behovet att definiera
en differens mellan tiderna. Även om det vore möjligt att mata in
de tävlandes nummer från klockan lönar det sig i allmänhet att undvika detta. Undantag är tävlingar
där det är besvärligt att på annat sätt omedelbart få målgångsordningen till datorn
och där målgångstakten är sådan att inmatning från målklockan
fungerar.

Det normala förfarandet vid tidtagningen är att den tävlandes nummer knappas in på datorn antingen
strax före hans målgång eller så snart som möjligt efter den.
Det väsentliga är att numren matas in i målgångsordning eller att man på annat sätt
säkerställer att varje nummer hamnar vid rätt tid.

När *Val / Tillåt förutseende
nummerinmatning* har valts
kan
flera startnummer matas in i förväg för att vänta på de tider som tidtagningen ger.

När de parametrar som beskrivs i kapitlet om konfigurering av
resultattjänsten används härleder programmet den startandes nummer
från tiden från startgrinden, om starten har skett inom 3 s från
starttiden enligt startlistan. Starter utanför detta intervall
måste vid behov hanteras manuellt (en försenad start kräver i allmänhet inga
åtgärder, utan den lottade starttiden får
stå kvar).

När parametern lähaika1 har angetts både på datorn i målet och på kontorets dator
, är det möjligt att
se och hantera tidtagningsuppgifterna även på kontorets dator.

**Tidtagning utan målklocka**

Klockslagen kan tas enligt datorns klocka
genom att trycka på en tangent som reserverats för detta på datorns tangentbord. I programmet
HkKisaWin väljs tangenten i tidtagningsformulärets val *Val /
Tidtagningstangent och punkt.* Alltid när tider tas från endast en punkt
(t.ex. målet) lönar det sig att välja denna punkt samtidigt som
tidtagningstangenten.
