# 4.1 Start times and bib numbers

### 4.1 Team numbers and start times

Numbers and start times are assigned
in the program option *Preparation / Numbering* .

Every team
must have a number, which is usually the bib number. The start time
is usually determined by the class and does not need to be recorded
in the entrant data when it is the same for the whole class. Thus start times are
usually given only in team orienteering and some other team competitions.

Numbering can be done in alphabetical order, in the order in which the data were entered
into the program, or by drawing.

Start times can only be given in number order using a constant start interval. Assigning start times is based on
the leg mass start time and start interval given in the class data. The time is calculated from the team number so that the start time
defined for the leg is given to the team whose number is the first number defined for the class. If a team has a smaller
number than this, the team also gets an earlier start time. Start times are not given for legs that have no mass start time, except
in team orienteering, where the start time of the first leg is used for the whole team; this is the class start time unless
a time has been entered in the data of the first leg.

Editing start times individually and reading them from a file is,
however, possible without restrictions on their connection to the number.

Start lists on paper and to a file are produced
in the program option *Outputs*
.

#### 4.1.1 Externally assigned numbers

If you want to change numbers already assigned to externally
assigned numbers, this can be done, for example, as follows:

1. Prepare a file whose 1st column contains
   the teams' current numbers and the 2nd column the new numbers.

   - Transfer the new numbers to the field *Team
     id no.* in the function *Transfer additional data*. (Identifying field
     *bib number* and target *Team id no.*.

     - Copy the team id numbers as bib numbers
       as they are. (This requires the program to be
       in preparation mode.)

This procedure is useful, for example, in
skiing competitions where reading the data from Kilmo gives the teams the
numbers Kilmo reports for them, and where the final numbers are assigned
on some basis that the program does not support.

#### 4.1.2 Ranking-based numbering, use of FIS points

Bib numbers can be assigned based on the ranking points
recorded for the entrants. The function was developed primarily to use
FIS points, but other points can also be used when they are given so
that lower points are better than higher points. (In the opposite case this can
be achieved, for example, by
subtracting the points from their maximum value before saving them in the program.)

When using FIS points, the procedure is
as follows:

- When the entries are read from Kilmo entry data
  in the correct format, the FIS codes recorded in them are transferred
  automatically to the competitors' leg-specific field
  *Leg points-1.*

  - From the FIS points file (zip file), extract
    the files CC???pts.csv and CC???pts.csv (??? refers to the
    list's identification number) to a directory from which they can be
    read.

    - Enter the numbering
      start values for the classes.

      - In the program, go to the form *Preparation /
        Numbering and start times.*

        - Select *Assign numbers in order of ranking point
          sum*
          .

          - Press *Read FIS points* and there
            carry out the reading of the FIS points from the above-mentioned
            files.

            - The FIS points multiplied by 1000 can now be found
              in the field *Leg points-3.* For competitors who have no FIS code or
              whose points are not found, 9999999 is entered as points, so that their
              "points" are worse than anyone's actual
              points.

              - When you now carry out the numbering, it is
                based on the sum of the FIS points of all legs of the
                team.

The FIS points and FIS codes saved for competitors
can be viewed on the form *Teams* when the points field concerned
has been selected for display (only one leg-specific points field or
the licence number can be shown
at a time.

Data can be transferred from a file to points fields and
from points fields to files in the function *Transfer additional data* and by using
reading data from a csv file in the option *Get from file*
.
