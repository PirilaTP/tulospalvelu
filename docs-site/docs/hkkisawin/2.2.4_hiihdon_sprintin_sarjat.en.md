# 2.2.4 Cross-country sprint classes

#### 2.2.4 Cross-country sprint classes

The program handles each heat of a cross-country sprint as a class
of its own. The classes can be defined so that first only one
class is defined, which is both the class in which the competitors are originally entered and
the qualification stage class. The overall results are also
made for this class. For this class you must also enter the first class number used in the qualification stage,
both for the base numbering and for the qualification stage. For this base class,
the first stage is set to 1 and the last stage to the stage of the final.

Once the base class has been defined, you can select on the single-class
data form that the class is a ski sprint base class. When this
selection is made, a new form opens on which you specify the number of stages
and the number and size of the heats in each stage. If classes have already been defined
for the heats, select them. If the classes do not yet exist, ask the program to create them.
Each heat takes part in only one stage. For the first-round heats,
the starting value of the bib numbers used in them is entered; for the other heats the program enters the value
0 to indicate that the numbers are no longer changed. The value 0 must also be
entered for a first-round heat if it uses the qualification bib numbers.

For each heat you should enter the distance and the time of the heat,
which should be set to the earliest time that can occur.

More information on cross-country sprint is given in [chapter 10.2](10.2_hiihdon_sprintti.md)
.
