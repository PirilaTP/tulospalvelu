# 5.2  Tidtagning baserad på brickor

### 5.2  Tidtagning baserad på brickor

Tidtagning baserad på brickor används mest
i orientering, där brickan kan vara en Emit-bricka eller en emiTag. emiTag lämpar sig
också för längdskidåkning och andra grenar. Brickan kan också vara
en RFID-tagg, när lämplig RFID-utrustning finns tillgänglig. I det följande
behandlas främst tidtagning baserad på Emit-brickor; programmet används i stort sett på samma sätt
med emiTag-enheter (se [bilaga 9](liite_9._emitag-laitteiden_kaytto.md)).

Att använda Emit-brickan för tidtagning förutsätter en så kallad
online-läsarstämplare, som registrerar stämplingen men inte får brickans klocka
att stanna, så som läsarstämplaren vid stämplingskontrollen gör. Uppgiften
från läsarstämplaren till resultatprogrammet kan gå många olika vägar:

1. direkt via serieport

   - som alternativet ovan, men med seriekommunikationen
     förmedlad trådlöst med radiomodem

     - med TCP- eller UDP-protokoll från en terminalserver
       till vars serieport läsarstämplaren är ansluten

       - med Sune Johanssons SjBoxar, mellan vilka
         seriekommunikationen sker med strömslinga

         - med samma överföringsprotokoll som
           kommunikationen mellan programinstanser. Detta sker i regel
           med UDP-protokollet, men även TCP-protokollet kan användas
           (meddelandeformatet är definierat för kommunikation med mitt program SendECodes)

           - med emiTag-enheter kan uppgiften också gå via Emits webbserver

I de fyra första fallen antas
överföringen vara snabb och tiden tas från datorns klocka när den identifierande
uppgiften har tagits emot. Vanligen är den enda uppgift som erhålls den lästa brickans Emit-kod, men
med SjBox fås också den källkod som definierats för den serieport till vilken
den läsarstämplare som gjorde avläsningen är ansluten. I alternativ 5 och 6 fås förutom koden
även avläsningsögonblicket och en källkod som anger avläsningspunkten. I alternativ 1-3
kan en källkod kopplas till uppgiften utifrån den serieport eller annan
anslutning som uppgiften kommer till; för en terminalserver kan
terminalserverns portnummer användas här.

I alternativ 1-4 måste parametern LUKIJA läggas till
i programmets konfigurationsfil för varje direkt
serieportsanslutning och för varje serieport på terminalservern vars uppgifter tas
emot. När anslutningen görs till datorns serieport har parametern formen

LUKIJAx=y

där x är anslutningens nummer och
y anger att serieporten som används är COMy. En SjBox
ansluts i detta avseende på exakt samma sätt som en enskild läsare.

För en terminalserver som använder TCP-protokollet är motsvarande parameter

LUKIJAx=TCP:ip-osoite:portti

där ip-osoite är
terminalserverns ip-adress och portti är den ip-port som motsvarar
den serieport som används (i terminalservrar motsvaras varje serieport av en egen ip-port).

Vid tidtagning ska varje parameter LUKIJA åtföljas av parametern

AIKALUKIJAx=VAINz

eller

AIKALUKIJAx=LÄHDEw

I båda fallen ska värdet x vara detsamma som i parametern LUKIJA.
x kan dock utelämnas, och då gäller parametern alla LUKIJAx-parametrar.

Det z som följer ordet VAIN kan vara

- ett numeriskt värde 0, 1, 2, ..
  upp till det högsta ordningsnumret för de mellantidspunkter som används. Värdet 0 avser målet. En parameter som anges på detta sätt bestämmer den punkt som tiden registreras för

  - bokstaven A, och då
    söker programmet den första mellantidspunkt som ännu saknar tid och registrerar tiden för denna punkt

    - tecknet z kan saknas,
      och då använder programmet filen lahdepisteet1.lst
      för att välja punkt. Detta lämpar sig främst för fall där SjBox används

I det senare alternativet är w
ett numeriskt värde som ges som källkod för denna anslutning. Därefter
söker programmet punkten med hjälp av filen lahdepisteet1.lst.

Alternativ 5 tas i bruk genom att den aktuella
dataförbindelsen definieras på samma sätt som andra dataförbindelser. Förbindelsen ska definieras
endast som inkommande. Dessutom måste parametern (utan
denna parameter hoppar programmet över meddelanden från tidtagningen)

YHTEYSAJAT

anges. I detta fall försöker programmet använda filen
lahdepisteet1.lst för att bestämma punkten med hjälp av den
källkod som kommer som en del av tidtagningsmeddelandet.

Alternativ 6 behandlas inte närmare här. Anvisningar
för det finns i [bilaga 9](liite_9._emitag-laitteiden_kaytto.md).
Det kan dock konstateras att även här används filen
lahdepisteet1.lst för att härleda punkten.

#### RFID-taggar

Programmet kan också hantera uppgifter från vissa
enheter som bygger på RFID-taggar. För närvarande används
aktivt endast stödet för Sirits enheter och de därmed kompatibla
Motorola-enheterna. Detaljer om detta system
behandlas inte i dessa anvisningar.
