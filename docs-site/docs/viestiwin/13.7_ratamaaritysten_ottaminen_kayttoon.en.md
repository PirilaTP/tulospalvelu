# 13.7 Putting course definitions into use

### 13.7 Putting course definitions into use

In this function the program goes through all courses and
compiles a list of situations where the same punching unit is repeated, reporting an error when
this happens at consecutive controls and giving a warning when there is more than
one control in between. When the function is used in results service mode, the program also compares
the list of courses with the entrant data and points out cases where
an entrant's course is not found in the course data.
