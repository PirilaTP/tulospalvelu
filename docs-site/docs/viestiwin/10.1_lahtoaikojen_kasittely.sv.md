# 10.1 Hantering av starttider

### 10.1 Hantering av starttider

I patrullorientering startar hela patrullen
samtidigt, så alla sträckor får alltid en tid enligt definitionerna för första
sträckan. Startintervallet anges i sekunder och kan också vara noll. Starttiden som tilldelas beräknas
utifrån den definierade första starten, startintervallet, det definierade startnumret för lagens numrering och
lagets nummer. Om beräkningen leder till pauser eller tidigare starttider, registrerar programmet de
tider som beräknats på detta sätt.
