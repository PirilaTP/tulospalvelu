# 6.8 Använda kartan vid klagomuren

### 6.8 Använda kartan vid klagomuren

Programmet kan visa den tävlandes bana på kartan och markera på kartan
de kontroller vars stämplingar saknas samt de kontroller som har sådana stämplare
vars stämplingar den tävlande har som extra stämplingar.

Kartan öppnas med en knapp på stämplingskontrollformuläret. Kartan öppnas
normalt så att den första kontrollen som saknar korrekt stämpling syns
i mitten av kartbilden eller mellan kartbildens mittpunkt och kartans kant, när
kontrollen i fråga ligger nära kartans kant.

Programmet markerar saknade stämplingar med röd färg och ett kryss över
kontrollen. Extra stämplingar visas också med rött och bredvid dem
visas stämplarens kontrollkod (alltså inte kontrollens kod, när den skiljer sig från
stämplarens kod.)

Funktionen förutsätter att kartan och banuppgifterna har
förberetts enligt [kapitel 13.10](13.10_rastien_sijainnit_ja_kartta.md) och att kartfilen anges med parametern

KARTTA=tiedostonimi

där tiedostonimi antingen är ett absolut namn
med fullständig katalogsökväg eller ett (relativt) namn i tävlingens
arbetsfil.
