# 1.5  Spara formulärens inställningar

### 1.5  Spara formulärens inställningar

När de formulär som ska användas har öppnats på datorns skärm
och placerats på det sätt som du vill använda även i fortsättningen, kan detta
läge sparas med huvudformulärets val *Spara
fönster*
. Denna möjlighet gäller endast sådana
formulär som används ofta och upprepade gånger:

- Uppföljning av klassens ställning- Senaste händelser- Tävlingens status- Anmälningsformulär (används bland annat
        vid löpevenemang)- Emit-stämplingskontroll och anmälan till t.ex.
          motionsorientering- Tidtagning

Samtidigt som programmet sparar formulärens placering sparar
det även de flesta val som kan göras på formulären. Även bredderna på tabellkolumnerna i de två
först nämnda formulären sparas, förutsatt att de först har sparats
i minnet via respektive formulärs meny.

De sparade placeringarna och
inställningarna kan läsas in antingen via menyn eller automatiskt, när
detta har begärts med konfigurationsfilens parameter

ikkunat=xxxx

där xxxx är namnet på filen som innehåller
uppgifterna. Om inget namn anges används namnet ikkunat.xml.
