# 13.8 Optional punching order

### 13.8 Optional punching order

Courses can include sections within which
the punching order of the controls is free. In this case the program
checks that every control has been visited but accepts any
punching order. Such a section is started by adding to the course data a "point" whose control code
is 'V' before the controls whose order is free, and
a point whose code is 'J' after the free-order section. The letter 'V' can be right at
the start of the course. The letter 'J' can be at the end of the course only when there is
no punching unit at the finish.

Every free-order section started with the letter 'V'
must be ended with the letter 'J'.

The finish control must not be included among the freely chosen
controls; the letter 'J' must appear before it.

There can be several free-order sections, in which case
the free choice applies to each of them separately. The program does not accept a punch
moving from one section to another.
