# Location of program files

The installer tries to place the program files
in the subfolder
*Pirila\HkKisaWin\*
of the Windows directory tree intended for program files.

Windows 7 uses
two alternative directory trees for programs: one for programs
intended for all users and another for those
installed for a single user only. Installing for all users
requires administrator rights. For using the programs,
both alternatives are equally good, and you can
also choose some other folder as the location.

You need to know where the programs are if you
want to update them without reinstalling, and possibly also when creating
shortcuts for starting the programs. It is also still common for
the program *HkMaali* to be installed on another computer simply by
copying *HkMaali.exe*
, in which case you naturally have to find the program. The easiest way to find the locations
is from the properties of a shortcut created by the installer.
