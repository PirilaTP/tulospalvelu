# 9.5 Start lists

### 9.5 Start lists

Start lists can be written both
in preparation mode and in the results service mode of the stage the start list
concerns. Operation may be incomplete if output is done, for example,
in the results service mode of the previous stage.

The content and formatting of start lists can be changed
with the option *Formatting*
([chapter 9.3](9.3_tulosten_muotoilumaaritykset.md)).

There are four basic types of start lists:

- start list by class

  - start list by club

    - start list containing all competitors as a single
      whole

      - start list by start

For some of these several different orders can be selected,
such as number order, start order and alphabetical order. Start order is
available only when a non-zero start interval has been defined for the class for that
stage, because the program does not create a start-order
index at all if the start interval in the class data is 0.

In multi-stage competitions both
stage-specific start lists and start lists containing all stages can be produced.

A start list containing all stages must be produced
in preparation mode. Competitors are then always placed in their base class, which is not
necessarily the same as the class of a particular stage in a competition where the class can
vary, so printing all stages can be problematic
in such competitions. It does work, however, when the variation is due to
the stages being divided into a qualification and finals and when the finals
classes of those taking part in the qualification are not wanted on the list. In that case the qualification classes
must be marked as single-stage and you must make sure that the competitor's base class is the same as the class
in those stages that are to be included in the start list.

Competitors marked as absent are left
out of start lists, but those marked as not started are included.
Competitors are also left out when, according to the class data, their class does not
take part in the stage in question. When start lists of all stages are made,
the start time of a stage is left out when the competitor's class in that stage is not the same as
the base class and when the base class does not take part in that stage.

The form has a field **Additional text**, in which you can write an additional line of at most 200
characters. The text is printed after the competition title on its own
line in a smaller font size than the title. The field is one-off: it
is cleared when the form is closed and is not saved in the competition data.

The lists can be written both to a printer and
to a file.

Formatting is defined separately for the different start list types
([chapter
9.3](9.3_tulosten_muotoilumaaritykset.md) ).
The content of the club field is however selected on the form *Outputs*.
The default is the abbreviation if the abbreviation has been selected as primary in the competition's basic
properties, otherwise the long
club name.

The long class name is written in the title of the start list by class
if one has been defined for the class. The program adds the distance after the short
class name if this has been requested in the formatting. The distance is not added
after the long class name; it is assumed to be included in the class
name.

The program also writes start lists in a file format suitable for the WebScorer service
when this file format is selected, start lists are selected for writing
and the classes to be included are selected. Other start list
options then have no effect.

The start times of a pursuit competition for transfer to the finish clock
can be obtained, if desired, as a simplified file containing only the bib numbers and
times. The classes to be included can be selected either by class name or by start number.
The order is always the start order, so that
all selected classes are in the same queue. Division into start queues
must be done, for example, with my program ASC3Control.
