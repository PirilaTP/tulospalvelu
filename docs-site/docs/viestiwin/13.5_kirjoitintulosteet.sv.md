# 13.5 Skrivarutskrifter

### 13.5 Skrivarutskrifter

Banuppgifter och stämpelkoder kan skrivas ut
i textform på papper. Likaså är det möjligt att skriva ut stiftmönstren
i naturlig storlek tillsammans med en förstorad bild som förklarar dem.

I programmet kan du för närvarande inte direkt visa
stiftmönster, men skrivarvalen innehåller ofta alternativ för
utskrift till fil. Bland annat till pdf- och xps-filer kan du skriva ut så att
den skapade filen kan visas på skärmen.

Utskrifter som gäller banor görs för valda banor;
utskrifter av stämpelkoder innehåller alltid alla kontroller och stämpelkoder.
