# 6.12 Using the map at the complaints desk

### 6.12 Using the map at the complaints desk

The program can show the competitor's course on a map and
mark on the map the controls whose punches are missing, as well as the controls that have
punching units whose punches the competitor has as extra punches.

The map is opened with a button on the punch check form.
The map normally opens so that the first control without a correct
punch is shown in the middle of the map image, or between the centre of the map image and the edge of the map
when that control is close to the edge of the map.

The program marks missing punches in red with
a cross over the control. Extra punches are also shown in red, and next to them
the punching unit code is shown (i.e. not the control code, when it differs from the punching unit code.)

This requires that the map and course data have been
prepared as described in [chapter 13.10](13.10_rastien_sijainnit_ja_kartta.md) and that the map file is given with the parameter

KARTTA=tiedostonimi

where tiedostonimi is either an absolute name with the full
directory path or a (relative) name in the competition's working directory. The map
can also be loaded for display when it is first needed, in which case
the parameter KARTTA
is not needed.
