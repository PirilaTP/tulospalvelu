# 10.4 Final based on a qualification

### 10.4 Final based on a qualification

Forming a final corresponds in many respects to the
procedure described above for cross-country sprint. Avoiding overlapping
numbers must, however, be ensured by moving the numbers of the final stage
to a suitable range on the numbering form, unless the classes
have already been defined so that no overlap can occur.

The final itself is then formed on the form *Form final from qualification*. The form has been designed
on the assumption that there are two stages, first the qualification and second the final.
The form is used in the results service mode of the qualification.

To help form the finals, you can write a
script file (default name `finsaannot.txt`),
which
consists of lines like the following:

```
A-FINAALI:; sarja;lkm/kars.sarja;kaikkiloput;annalähtöajat;ens.lähtö;lähtöväli;aalto;numeroalku;rajaus;takaa-ajo
karsintasarja
LOPPU
```

Or, as an example

```
A-FINAALI:; H21A; 10; 0; 1; 15:00:00; 60; 1; 1; 1; 0
B-FINAALI:; H21B; 10; 0; 1; ; ; 1; 201; 1; 0
C-FINAALI:; H21C; 0; 1; 1; 13:20:00; 60; 4; 0; 3; 0
H21K1
H21K2
H21K3
H21K4
LOPPU
A-FINAALI:; D21A; 10
B-FINAALI:; D21B; 0; 1; 1; 13:00:00; 60; 4; 0; 3; 0
D21K1
D21K2
LOPPU
```

The structure of the file closely resembles the layout of the data on the form itself.
The colons after the word FINAALI are mandatory. There
must be a separator between fields, which can be either a semicolon or a tab;
spaces are allowed but do not act as separators.

A line beginning with
`A-FINAALI:` contains the same fields in the same
order as the form. Checkbox data is expressed with the numeric values 0 or
1, other data in the same way as on the form. At the beginning, the letter
`A` can be
replaced by  `B, C, D` or `E`.

For the final classes you must give at least the class name and
the number of competitors to be picked into it, or in the next column a mark that all the rest
are taken. The remaining fields can be left out, in which case the program uses either
data from the class data (start time, start interval and first number) or
default values (start times are given, start wave size is 1, only
approved competitors are taken, pursuit is not used).

Two separators with at most
spaces between them mean that the default value described above is used for that
field. This way you can, for example, use the start time
and start interval from the class data but give the first number, as has been done above for the B final H21B.
The women's A final data represents the minimum that must
be defined.

The mark `takaa-ajo` (pursuit) can
be 0 or 1 (1 means pursuit) and `rajaus` (filter) 1, 2 or 3, where 1 means only
approved competitors, 2 approved, disqualified and did not finish, and 3 all
entrants including those who did not start.

The final classes are followed by the names of the qualification classes,
each on its own line without other data.

Each formation step ends with the line `LOPPU`, after which a group of lines describing
the next step can begin. The program always reads one step at a time, after
which the data of the step can be edited if necessary and the step then carried out
before the next step is read. When all steps have been gone through, or the form
has been closed and reopened, the same or another script file can be selected
for processing. A step can be skipped by not carrying it out and reading
the next step.

A script can be created with the program by filling in
the form for each
step and writing its content to the script via a menu command. Writing is done
at the end of the selected file, so it can be done in several steps. On the other hand,
the old script must be deleted or a new one created with a different name if you want to leave
out the earlier content. If the start time, start interval,
wave size and/or first number are cleared before writing to the script, the removed data is determined from the class data
when the script is used.
