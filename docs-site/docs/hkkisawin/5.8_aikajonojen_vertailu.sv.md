# 5.8  Jämförelse av tidtagningsköer

### 5.8  Jämförelse av tidtagningsköer

[I kapitel
5.1](5.1_maalikellon_kaytto.md) beskrivs hur tider kan styras till flera olika köer. Dessa köer
kan också innehålla tider från den primära tidtagningen och reservtidtagningen som
ska jämföras. För detta ändamål finns formuläret *Jämförelse av
tidtagningsköer*
.

Via tidtagningsformulärets meny kan du gå till jämförelse av två
tidtagningsköer. Köerna kan väljas bland dem som används
för tidtagning. Programmet visar avvikelser mellan köerna med färgkodning. Urvalskriterierna för kodningen kan ändras med ett
menyval.

Tidtagningsuppgifterna kan bläddras så att bläddring i den vänstra
tabellen flyttar båda tabellerna lika mycket, medan bläddring i den
högra endast flyttar den tabellen. Tangenterna för bläddring
är Upp, Ned, PgUp, PgDn, Ctrl-PgUp och Ctrl-PgDn. Även inmatning av numeriska värden och rullningslisten kan användas
för bläddring.

Tangentkombinationen Ctrl-PgUp återställer båda tabellerna till rad
1.

På formuläret kan du ta bort och lägga till rader, men den fortsatta hanteringen av en tillagd rad måste göras på det vanliga
tidtagningsformuläret.
