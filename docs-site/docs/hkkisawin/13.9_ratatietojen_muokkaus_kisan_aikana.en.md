# 13.9 Editing course data during the competition

### 13.9 Editing course data during the competition

When the competition is in progress, the program
automatically loads the data in use for editing.

Editing courses does not affect the results service until
the courses have first been written to a file and then separately put into use,
which can be done
both from the course data form and from the menu of the punch checking form.

Course data can also be read from another file and
saved under a name other than the one used by the results service. In that case
editing the courses does not affect the results service in any way.

When courses are saved while the results service network is
in use, the program sends the changed file to the other computers if file
transfer has been enabled (see [appendix 2](hkliite2.md).

Putting edited data into use has been described
above in [section 13.7](13.7_ratamaaritysten_ottaminen_kayttoon.md).
