# Course data

A competition based on the Emit punching system needs data on the courses
and the punches used on them. These are defined in the program's menu item
*Preparation / Course data*. Unlike other data, the course data can
be handled even before the whole competition has been set up, or on a computer that has
no other data on the competition available, if this is considered
useful.

On the course data form, the
data is first stored in the computer's memory, where its consistency
can also be checked, and only when separately requested
saved to a file.
