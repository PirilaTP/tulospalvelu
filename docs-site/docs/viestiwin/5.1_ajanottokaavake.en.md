# 5.1  Timing form

### 5.1  Timing form

On the timing form you

- monitor the times received from the timing device and
  make changes to them when necessary
- enter or correct the competitor numbers
  associated with the times
- can also take times based on the computer clock
  using a selected key

The timing form has one or two tables. When
there are two tables, the upper one can be scrolled and used for changes,
while the lower one shows the newest times coming from the timing device. The form also has
an area showing more information related to the selected row.

The data of the selected row can be changed either
in the separate single-row fields or in the scrollable table.
Routine data entry takes place in the table. The
mode of operation used here can be selected:

- when only numbers are entered, the program deduces
  the leg and timing point according to the rules in force
- the other option is to enter the number, leg and point,
  in which case everything can be selected. In this mode every item can also be corrected
- if the program has been set to recognise some
  chip, either in the competition's basic data or by a parameter, it is possible
  also to select identification of the competitor by chip code. This
  option can also be used to enter competitors with a single
  code that identifies both the competitor's team and the leg, when such
  codes have been recorded in the leg-specific data.

Entering competitor numbers can also be allowed
in advance, in which case each number entered goes to the area on the right side of the form
and is picked from there in order for the following times. This works
only when the entry concerns the competitor number alone, and it requires that
the timing point is determined by a fixed selection.

Timing using the keyboard is activated through the form's
menu.
