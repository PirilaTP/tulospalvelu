# Kapitel 2. Skapa och definiera en tävling

## 2 Skapa och definiera en tävling

Att skapa en tävling omfattar

- val och eventuellt skapande av den mapp som används för tävlingsuppgifterna

  - definition av tävlingens grunduppgifter

    - definition av klassuppgifterna, där du anger alla
      klassers namn, antal sträckor
      och eventuellt andra uppgifter

      - start av programmet i förberedelseläge, varvid programmet skapar en ny fil för uppgifterna om de tävlande.
