# 6.11 Registrering av Emit-koder för tävlande, registrering av startande

### 6.11 Registrering av Emit-koder för tävlande

#### 6.11.1 Inmatning och redigering av koder från tangentbordet

Valet *Deltagare / Mata in Emit-koder* i programmet HkKisaWin
öppnar ett formulär där koderna enklast matas in. I formulärets
tabell matas endast den tävlandes nummer och den nya koden in. När en omgång koder har
matats in sparas de med knappen *Utför markeringar*.
I en tävling med flera etapper kan du välja den etapp vars kod ändras. Som standard
gäller ändringen den pågående etappen (vid förberedelserna etapp 1)
samt alla senare
etapper, om sådana finns. Med en rullgardinsmeny kan du välja om markeringen också gäller senare etapper eller endast
en vald etapp. Samtidigt kan markeringar om hyrbricka göras eller tas bort.

Förutom den vanligast använda primära koden kan även en andra brickkod hanteras.

#### 6.11.2 Läsning av koder från brickor

Till exempel koderna för hyrbrickor kan läsas in
för deltagarna i programmets förberedelseläge. Detta förutsätter att programmet ges parametern

LUKIJA=xx

där xx anger serieporten eller annan kanal som uppgifterna kommer från.

När denna parameter har angetts finns i tabellen
*Deltagare* valet *Funktioner/Läs emitkoder*.
I detta val kan du vidare välja om de lästa
brickorna markeras som hyrbrickor. Valet är möjligt endast när tabellen är i läget
*Redigering tillåten* .

Innan läsningen påbörjas lönar det sig i regel att aktivera
filtrering som kräver att brickkoden är 0. Då visas endast de rader
som ännu saknar kod. När en bricka läses går dess kod till den markerade
raden för alla tävlingens etapper.

En förteckning över de lästa brickorna kan fås om de har
markerats som hyrbrickor, eftersom startlistor kan göras så att de endast omfattar innehavarna av hyrbrickor.

#### 6.11.3 Läsning av koder från fil

Emit-koder kan läsas från en fil av csv-typ
med valet *Deltagare / Överföring av tilläggsuppgifter*
enligt detta formulärs arbetssätt.

#### 6.11.4 Registrering av startande och kontroll av att koderna stämmer

När programmet förutom läsardefinitionen ges parametern

ESILUENTA

utför programmet ingen stämplingskontroll, utan sätter endast
kontrollkoden för en tävlande som tidigare markerats som ej startad till *Öppen*,
dvs. tecknet '-'. Om alla tävlande före tävlingen har markerats som
ej startade vet man att alla tävlande som är öppna verkligen har
startat. Samtidigt kan man försäkra sig om att den tävlandes Emit-bricka fungerar
åtminstone fram till starten och att den tävlandes Emit-kod motsvarar den bricka som används.

Denna funktion sköts på stämplingskontrollskärmen, där
programmet dock visar endast den del som behövs och utelämnar onödiga uppgifter.

Motsvarande funktion kan alternativt skötas
på tidtagningsskärmen, när tidtagningspunkten definieras som start men tävlingen inte
tillåter att starttiden ändras utifrån den tagna tiden (startgrinden har alltså inte
tagits i bruk i tävlingens grundinställningar). Tidtagningspunkten kan definieras som start med parametern

AIKALUKIJAx=VAINL

eller med punktdefinitionen L
i filen lahdepisteet1.lst .
