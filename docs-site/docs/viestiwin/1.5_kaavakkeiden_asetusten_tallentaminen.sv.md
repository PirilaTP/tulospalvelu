# 1.5  Spara formulärens inställningar

### 1.5 Spara formulärens inställningar

När du har öppnat de formulär du använder på datorns
skärm och placerat dem på ett sätt som du vill använda även i fortsättningen, kan
läget sparas med huvudformulärets val *Spara
fönster*
. Den här möjligheten gäller bara sådana
formulär som används ofta och upprepade gånger:

- Uppföljning av ställningen i klassen- Senaste händelser- Tävlingens
      status- Emit-stämplingskontroll- Inläsning- Tidtagning

Samtidigt som programmet sparar formulärens placering
sparar det också de flesta val som kan göras på formulären. Även kolumnbredderna i tabellerna på de två
förstnämnda formulären sparas, förutsatt att de först har sparats
i minnet via respektive formulärs meny.

De sparade placeringarna och
inställningarna kan läsas in antingen via menyn eller automatiskt, när
detta har begärts med konfigurationsfilens parameter

ikkunat=xxxx

där xxxx är namnet på filen som innehåller
uppgifterna. Om inget namn anges används namnet ikkunat.xml.
