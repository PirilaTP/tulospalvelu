# Kontrollernas stämplingskoder

Av banuppgifterna framgår de kontrollkoder som används på banorna, men dessa är
långt ifrån alltid desamma som koderna för de stämplingsenheter som används, vilka
resultatprogrammet läser från filen LEIMAT.LST. Denna
fil kan upprättas, eller granskas och redigeras, på undersidan
*Stämplingsenheter vid kontroller.*

Stämplingskoderna listas i tabellen på rader där den första
kolumnen innehåller kontrollens kod så som den syns för den tävlande och enligt banuppgifterna, och
de övriga kolumnerna stämplingsenheternas koder. I undantagsfall kan stämplingsenheterna ha
fler än 6 koder, och då används två rader med samma
kontrollkod.
