# ViestiWin Help

## Resultatprogrammen ViestiWin och ViestiMaali för stafetter

### Version 5.20

### Pekka Pirilä, 19.4.2015

Programmet ViestiWin, som använder ett grafiskt
Windows-användargränssnitt, lämpar sig för nästan alla uppgifter som hör till
resultattjänsten vid en tävling. ViestiMaali är ett mer avskalat kommandofönsterprogram, vars
tillförlitlighet har maximerats genom att undvika användning av komplicerade
gränssnittsbibliotek och utvecklingsverktyg. Därför lämpar sig ViestiMaali
bättre för de mest kritiska realtidsuppgifterna vid betydande
tävlingsevenemang. Programmen fungerar tillsammans så att varje uppgift
under tävlingen kan skötas med det program som passar bäst för ändamålet.

I dessa anvisningar ligger
tyngdpunkten på programmet ViestiWin, men de viktigaste sakerna om användningen av programmet
ViestiMaali finns också med. Om användningen av kommandofönsterprogrammet ViestiMaali
finns en del ytterligare information i pdf-anvisningarna för det liknande programmet HkMaali
och i anvisningarna för mina tidigare stafettprogram.

Programmet ViestiLuenta, som ingick i tidigare programversioner,
ingår inte längre i programversion 5.20, eftersom ViestiWin sköter dess
uppgifter bättre.
