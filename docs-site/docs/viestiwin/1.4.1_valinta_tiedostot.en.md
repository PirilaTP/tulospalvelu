# 1.3.1 Menu: Files

The menu *Files* opens the following
submenu.

![](../images/ValikkoTiedosto.png)

The options lead to the following functions:

- **Startup settings**. Defines how the program
  starts the next time it is used. This lets you make the program
  open directly in the desired competition.

  - **Save windows.** Saves
    the windows in use at the time of saving, which makes it possible
    to open the program later in largely the same state.

    - **Load windows.** Restore the operating state
      saved with the option *Save windows*.

      - **Write to transfer file.**Writes the competition data
        to text files (csv or xml), to a MySQL database or to an up-to-date copy
        of the file KILP.DAT in use.

        - **Settings.** The most important function
          at the moment is the ability to read, during the competition, the file korostus1.lst that controls
          colour highlighting of VIP entrants (korostus2.lst etc. in multi-day competitions, see chapter 8.3).

          - **Reference times.** Defines the parameters
            that control the analysis of Emit split times.

            - **Data transfer settings.**

              - **Settings and
                restart.**Closing and reopening connections, resending
                previously sent messages.

                - **View data transfer file.**
                  View the content of the file COMFILE.DAT. This makes it possible to find out
                  what has happened in the results service at different stages.- **MySQL.** Defines the database
                connection and optionally opens it for continuous operation. A one-off transfer
                is started with the option *Write to transfer file.*. Not yet implemented in the relay program.

                - **Message window.** Opens a separate
                  window containing the same messages as the window in the lower right corner
                  of the main form.

                  - **Exit.** Close the program. (Same
                    effect as the close box in the upper right corner of
                    the form.)
