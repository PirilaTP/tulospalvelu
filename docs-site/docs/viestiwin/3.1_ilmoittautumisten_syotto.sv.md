# 3.1 Mata in anmälningar

### 3.1 Mata in anmälningar

I formuläret för lagets uppgifter, som öppnas med valet *Deltagare / Ett lag*,
väljer du *Fil / Läge för upprepade
tillägg*.

Mata därefter in uppgifterna och spara dem.
Programmet tömmer formuläret för ett nytt tillägg.

Avsluta genom att ta bort krysset från valet *Läge för upprepade
tillägg.*

Mer information om hur formuläret används finns i [kapitel 7.1](7.1_joukkue-_ja_henkilotiedot.md).
