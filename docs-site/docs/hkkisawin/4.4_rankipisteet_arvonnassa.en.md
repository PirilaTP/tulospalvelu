# 4.4 Using ranking points in the draw

### 4.4 Using ranking points in the draw

If required, the program sets the start order and divides
competitors into heats based on ranking points. The order of merit used can follow
descending ranking points, as in orienteering, or ascending points,
as with FIS points in skiing.

Before the draw, the points must be stored
in the competitor data, in the third of the fields reserved for various points. This
is done with the program option *Entries / Transfer additional data*, where
*Ranking points* is selected as the data to transfer. The identifying field is
*Competitor id (licence no)* in orienteering and normally *Intl. id* in FIS
skiing competitions. The points are stored
multiplied by one thousand as integers. For a FIS competition, competitors without
FIS points are given the value 999999, which is higher than any real points, so that
competitors without points are handled after all those with points.

From the orienteering IRMA system you must use a file in which each
competitor appears only once and has as points the best points he or she
has in any class. In the current file format the licence number is in column 1
and the ranking points in column 7. The separator is a semicolon. These three
choices must be made before reading the file.

The FIS software produces a CSV file containing the FIS points for both
distance and sprint competitions in their own columns. Before using the file,
examine it, for example in Excel, to make sure you use the correct
columns.

Once the points have been transferred to the file, you can view them on the form of an individual
competitor to make sure that the data has really
been transferred as expected.

In the *Draw* function, in orienteering you use the
option *Start times by ranking, lowest first* when you want
the best to start last. In FIS skiing competitions you choose in the corresponding situation
to start from the highest.

If classes are to be divided into
qualification classes by ranking, use the option
*Balanced by ranking*. The option
*Order of merit by ranking* results in the best forming one
class, the next ones another, etc.

The program also allows you to use a second
points column in a ranking-based draw. This option can be used,
for example, when some classes are organised by FIS points and some by national
ranking points.

The corresponding options are also available
in numbering when it is not based on start times.
