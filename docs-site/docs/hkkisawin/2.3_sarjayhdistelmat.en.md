# 2.3 Class combinations and subclasses

### 2.3 Class combinations and subclasses

In some competitions, such as
running events where results are produced both for age classes and for everyone
who ran the same distance, it is necessary to produce results not only for individual
classes but also for combinations of several classes. HkKisaWin can
handle several such class combinations (12 combinations at a time
in the basic version). Class combinations are defined using the file `SARJAYHD.LST`,
which consists of lines like the following

`YHD1 SRJ1 SRJ2 .. SRJN`

where the first item is the name given to the combination, followed
by a list of the classes to be included in the combination. The number of classes
included is not limited.

It is also possible to define a combined class that includes
all classes of the competition, by writing the word `KAIKKI` instead of the list of classes
to be included in the combination.
This makes it easier, for example, to use the program
as a start clock ([chapter 5.9](5.9_kaytto_lahtokellona.md)) when
all classes start from the same point.

The results of a class combination defined in this way can be followed
and printed in the same way as the results of normal classes. Points can also
be calculated for class combinations, and they can be used in team competitions.

If you want to use a long class name for a combined class,
it must be given after the name of the combined class, separated by a colon,
with all spaces replaced by underscores, for example as follows:

`YHD1:Yhdistelmäsarja_ykkönen SRJ1 SRJ2 .. SRJN`

**Subclasses**
mean a division based on gender or age group within one class or
class combination. Subclasses affect only results lists and
results monitoring, but not the draw or the grouping of start
lists. Subclass information can, however, be printed in the start list
by selecting it to be shown in the formatting

The subclass identifier consists of
a gender identifier, which can be any letter, and
an age group identifier, which can be a two-digit number, YL or AV. The identifier
YL is stored as age group 1 and the identifier AV as age group 2. In some situations
this numeric value is shown rather than the letter identifier.

The entrants shown on the monitoring display
and written to the results list can be filtered by the gender
identifier alone, by the age group alone, or by both. On the monitoring display
only one gender identifier can be used in the filter; in results lists
several, which allows the identifier to be used for some other purposes as well.
In both cases several age groups can be accepted by listing them
one after another.

For each competitor,
the gender can be stored separately as a letter and the age group
as a number.
