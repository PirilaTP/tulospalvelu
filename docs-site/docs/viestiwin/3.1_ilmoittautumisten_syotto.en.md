# 3.1 Entering entries

### 3.1 Entering entries

On the team data form opened with the option *Entries / One team*
select *File / Repeated
additions mode*.

Then enter the data and save them.
The program clears the form for a new addition.

Finally, remove the tick from the option *Repeated
additions mode.*

More information on using the form is given in [chapter 7.1](7.1_joukkue-_ja_henkilotiedot.md).
