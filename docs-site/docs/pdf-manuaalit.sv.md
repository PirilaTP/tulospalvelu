# PDF-handböcker

Dessa handböcker finns tillgängliga i PDF-format på de ursprungliga sidorna och
har tills vidare inte konverterats till Markdown.

- **[HkMaali 5.0 anvisningar](https://www.tulospalvelu.fi/pirila/ohjeet/pdfs/HkMaali50.pdf)**
  — användarhandbok för konsolprogrammet HkMaali. HkMaali är programmets DOS-/textlägesversion
  för tidtagning utan Windows-gränssnitt.
- **[Emit-stämplingskontroll 5.0](https://www.tulospalvelu.fi/pirila/ohjeet/pdfs/EmitLeim50.pdf)**
  — användarhandbok för stämplingskontroll med Emit-bricka.
- **[TCP-stöd](https://www.tulospalvelu.fi/pirila/ohjeet/pdfs/TCP-tuki.pdf)**
  — användarhandbok för dataöverföring vid distribuerad tidtagning och TCP-förbindelser.
