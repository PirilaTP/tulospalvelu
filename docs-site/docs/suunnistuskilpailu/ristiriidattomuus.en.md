# Consistency

The form's button *Check definitions* makes the program go through
the course and control punch data stored in the computer's memory. The program then
primarily checks that the same punch does not appear on consecutive
controls on any course. Such a situation would mean that no punch at all is obtained from the latter
control. The program also points out somewhat
milder errors that do not make punch checking entirely impossible
but may make it more difficult.

The results of the check can be read on the tab *Result of
checking*.
