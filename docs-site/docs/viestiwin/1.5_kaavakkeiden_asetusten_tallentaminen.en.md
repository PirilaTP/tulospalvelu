# 1.5  Saving form settings

### 1.5 Saving form settings

When you have opened the forms you use on the computer screen
and arranged them in a way you want to keep using, you can
save this state with the main form option *Save
windows*
. This option applies only to
forms that are used frequently and repeatedly:

- Class standings monitoring- Latest events- Competition
      status- Emit punch checking- Card readout- Timing

When the program saves the placement of the forms,
it also saves most of the selections that can be made on the forms. The table
column widths of the first two forms are also saved, provided that they have first been stored
in memory through the menu of that form.

The saved positions and
settings can be read either through the menu or automatically, when
this has been requested with the configuration file parameter

ikkunat=xxxx

where xxxx is the name of the file containing
the data. If no name is given, the name ikkunat.xml is used.
