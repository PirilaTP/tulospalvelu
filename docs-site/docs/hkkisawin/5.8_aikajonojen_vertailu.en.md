# 5.8  Comparing timing queues

### 5.8  Comparing timing queues

[Chapter
5.1](5.1_maalikellon_kaytto.md) describes how times can be directed to several different queues. These queues
can also contain times from the primary timing and the backup timing, which
you want to compare. The form *Timing queue
comparison*
is available for this purpose.

Through the timing form menu you can go to the comparison of two
timing queues. The queues can be chosen from those used
for timing. The program shows the differences between the queues with colour coding. The criteria of the coding can be changed with a menu
option.

Timing data can be scrolled so that scrolling the left
table moves both tables by the same amount, whereas
scrolling the right-hand one moves only that table. The keys used for scrolling
are Up, Down, PgUp, PgDn, Ctrl-PgUp and Ctrl-PgDn. Typing numeric values and the scroll bar can also be used
for scrolling.

The key combination Ctrl-PgUp returns both tables to row
1.

Rows can be deleted and added on the form, but further handling of an added row must be done on the normal
timing form.
