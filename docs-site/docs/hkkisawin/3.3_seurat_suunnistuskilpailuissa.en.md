# 3.3 Handling clubs in orienteering competitions

### 3.3 Handling clubs in orienteering competitions

The program primarily handles full club names,
except in orienteering competitions, where the established club abbreviations
confirmed by the Finnish Orienteering Federation (SSL) are primarily used. Accordingly, abbreviations are read from the entry file
produced by IRMA, and a few other functions are also
based on the use of abbreviations. Abbreviations are also written in results lists by
default. If you want to use long club names in orienteering, they must be
transferred to the entrant data before use. The transfer is normally made
using a file `Seurat.csv` similar to
the one described in section 3.1.

In orienteering you can choose, before reading
the data, whether the long club names are transferred to the entrant data
at the same time from the file `Seurat.csv`,
provided that the necessary data is available on the computer used. If
the club file with this name is in the competition directory, it is used without
further questions; otherwise the file must be selected after
the file containing the entries has first been selected.

Long club names can also be transferred to the entrant data
later in the function *Entries / Copying club names and
classes* or *Entries / Transfer
additional data*, the latter of which also lets you use a club list
in another format.
