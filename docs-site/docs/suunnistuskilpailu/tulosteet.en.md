# Printer and file outputs

On the tab *Printer output* you can request four
different types of outputs from the course data; of these, the spike patterns are a graphical output and the others
table outputs of the courses and punch codes.

If support for creating pdf files as output has been installed on the computer,
this is an excellent way to save the graphical spike patterns for use.
Besides pdf files, other equally suitable
file formats may be available, such as *Microsoft XPS Document* or *One Note*.
If these options are available, they are shown among the printer
choices.
