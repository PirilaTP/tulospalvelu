# Övriga filer

Programleveransen innehåller också många andra filer

- orienteringens klubbförteckning *seurat.csv*, som ger de fullständiga klubbnamnen som motsvarar förkortningarna

  - flera textfiler som kan användas
    som grund för vissa funktioner, till exempel när en extern databas tas i bruk

    - exempelmaterial som kan användas när du
      bekantar dig med programmen och där det också finns en användbar mall för orienteringens klassuppgifter
