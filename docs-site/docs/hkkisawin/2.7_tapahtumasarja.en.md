# 2.7 Defining and using an event series

### 2.7 Defining and using an event series

Fitness orienteering events in particular often form
an event series, which is created in advance for the whole season or at least for several events.
The program lets you define such an event series to make it easier to select the right event when it is used.

The event series is defined in the function *Files /
Competition list*. The following data is given for each event:

- event code (currently has no effect
  and can contain both letters and digits)

  - event date in the format yyyy-mm-dd, for example
    2012-08-24

    - event name

      - directory path to the folder used for the event,
        e.g. c:/kisat/kunto2012/kisa2

        - configuration file used during the competition, e.g. laskenta.cfg

When the data is saved, the program writes the file
KilpailuLuettelo.xml to the startup directory of *HkKisaWin*,
which is the same directory in which the program also places the file
init.cfg it uses, and which is specified in the properties of the shortcut used to start
the program. The program
stores the data in date order.

The file KilpailuLuettelo.xml
has a simple structure, and competitions can also be added to it or removed from it
with a text editor, using as a model one block delimited by the tags <Race> and </Race>.
Excel 2010 can also handle this file and save it
in the correct format (open as an XML table and save as XML data; Excel adds
a parameter concerning the schema, which does not affect the operation of the program).

The event series is put into use by ticking the corresponding
checkbox in the option *Files / Startup settings*. The next time the program
is used and a competition is opened in either preparation or results service mode,
the program shows a form on which the next or, in some
cases, the previous competition is preselected. The selection can be changed if desired and then
accepted with *Go to competition below*.

If both *Select
competition from list*
and
opening directly in either preparation or results service mode are selected in the startup settings, the program goes directly
to that day's competition.

New directory folders used by the competition series can be
defined in the competition list, after which the software, when requested, creates all
the defined folders and optionally also
copies
files from a selected folder into them. The copying can cover the class data, the entrant file
and one configuration file.
