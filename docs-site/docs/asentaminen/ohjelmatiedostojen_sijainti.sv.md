# Programfilernas placering

Installationsprogrammet försöker placera programfilerna
i undermappen *Pirila\HkKisaWin\* i det katalogträd som Windows
har avsett för programfiler
.

Windows 7 använder
två alternativa katalogträd för program, ett för program som
är avsedda för alla användare och ett annat för program
som installeras för endast en användare. Installation för alla användare
kräver administratörsbehörighet. För användningen av programmen är
båda alternativen lika bra, och användaren kan
också välja någon annan mapp som installationsplats.

Programmens placering måste vara känd om du
vill uppdatera dem utan ominstallation och eventuellt också när du skapar
genvägar för att starta programmen. Det är fortfarande vanligt att
programmet *HkMaali* installeras på en annan dator helt enkelt genom att
kopiera *HkMaali.exe*
, och då måste programmet naturligtvis hittas. Placeringarna
framgår enklast av egenskaperna för den genväg som installationsprogrammet skapat.
