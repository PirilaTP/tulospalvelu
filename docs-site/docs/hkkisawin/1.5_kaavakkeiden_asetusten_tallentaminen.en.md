# 1.5  Saving form settings

### 1.5  Saving form settings

Once you have opened the forms you use on the computer screen
and arranged them the way you want to use them in the future, this
arrangement can be saved with the main form option *Save
windows*
. This applies only to
forms that are used repeatedly:

- Class standings monitoring- Latest events- Competition status- Entry form (used e.g. in
        running events)- Emit punch checking and entry, e.g. for
          fitness orienteering- Timing

When the program saves the layout of the forms, it
also saves most of the selections made on the forms. The column widths of the tables of the first two forms
are also saved, provided that they have first been stored
in memory via the menu of that form.

The stored positions and
settings can be loaded either via the menu or automatically, when
this has been requested with the configuration file parameter

ikkunat=xxxx

where xxxx is the name of the file containing
the data. If no name is given, the name ikkunat.xml is used.
