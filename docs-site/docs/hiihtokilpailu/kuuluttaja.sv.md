# Speaker

Formulären för speakern väljs via valet
*Uppföljning* i programmets huvudmeny. De mest intressanta valen är

- **Ställning**, där du kan granska
  ställningen i en klass vid en vald punkt, till exempel i målet eller vid någon
  mellantidspunkt. Högst sex ställningsformulär kan öppnas.

  - **Senaste händelser**, som visar
    de senaste händelserna vid en viss punkt, till exempel målet, för alla
    klasser. Om ingen punkt har valts visas tiderna från målet och mellantidspunkterna
    blandat, och punkten framgår då av kolumnen *Punkt.* Även av dessa
    formulär kan högst sex öppnas.

På båda formulären ovan kan du öppna
den tävlandes uppgifter genom att dubbelklicka på raden. I det fönster som då öppnas kan du
välja ytterligare en tävlande, och i dessa fönster kan du följa en tävlande
och jämföra med resultaten för klassens övriga deltagare. Detta sker
genom att kryssa i *Visa uppföljningsfönster.*

Valet *Status* visar antalsuppgifter
om hur tävlingen framskrider.

Eftersom samma fönster ofta öppnas för speakern
kan starten av programmet i tävlingssituationen effektiviseras genom att spara en lämplig
fönsterplacering med valet *Filer / Spara fönster* och ange parametern ikkunat i konfigurationen så att den sparade
situationen öppnas automatiskt när programmet startas.
