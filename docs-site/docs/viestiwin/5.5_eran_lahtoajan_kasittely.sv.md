### 5.7  Hantering av heatets starttid

När klassens starter sker enligt ett tidsschema som inte är
noggrant bestämt i förväg, kan önskat antal starttider bestämmas från startklockans
signal. Därefter måste numren på de lag som deltar i heatet matas in
manuellt vid respektive tid. Förfarandet sköts bäst så att starterna
hanteras som en annan tidtagningskö än sluttider och mellantider. Alla köer kan
enklast hanteras i separata tidtagningsformulär i programmet ViestiWin eller
i olika instanser av programmet ViestiMaali. Vid tidtagningen kan till exempel
följande parametrar användas

```
// Timy i port 4
timy=4
// Timys START ger starttid, STOP måltid och kanal 2 mellantid 1
pisteet=MMMLM1
// kö 1: måltider, kö 2: starttider, kö 3: mellantider
jonot=111213
// om tiderna hanteras i flera instanser måste de skickas genom att ange
// parametern LÄHAIKAx för de dataöverföringsförbindelser som används
// när programmet ViestiMaali används bör de datorer som används för inmatning av
// mål- och startnummer ges parametrarna
// piste=M
// piste=L
// heatets storlek 6 lag
lähtöryhmä=6
```

När starttiden registreras för ett lag markerar programmet
den som individuell starttid. Startklockan kan också användas vid individuella
starter på senare sträckor. Starttiden visas i vyerna
som punkten 'L'.
