# 6.12 Handling disqualification proposals

### 6.12 Handling disqualification proposals

From the menu or a button of the punch check form you can
open a form for handling, saving and printing disqualification
reports. On this form you can record the basic details of a disqualification proposal
as well as the decisions made and the competitor's response to the proposal.

All the most important selections and entries made on the form,
except for the timestamps, are saved in the competitor data, but the text fields
have room for only 9 characters in the competitor data. When the data is saved,
it is stored as fully as possible in the competitor data and at the same time also
in an XML file whose name shows the team and leg numbers.

The XML files are saved in a
directory that can be selected from the form's menu or with the parameter

RAPORTTIHAK=hakemistopolku

If the directory path does not contain the character '\', ':' or '/' within its first three characters,
the program interprets it as relative to the competition data directory; otherwise it is an absolute path. The character '.' as the first
character also leads to interpretation as a relative path regardless of the following characters. The path
can also point to an accessible directory on the local network, which allows
the same directory to be used from several computers. When all check reports
are saved in the same directory, it is easy to verify there whether a disqualification
proposal has been handled for a given competitor's performance. Two timestamps
are also saved in the XML file: the moment the disqualification proposal was first
handled and the time of the most recent save.

When the report directory also contains a file hylkrap.xsl with the correct content,
the disqualification reports can be viewed not only on the program's
form but also in web browsers.
