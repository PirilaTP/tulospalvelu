# A very small competition step by step

### A very small competition step by step

This chapter gives a detailed list of the actions
needed to run a very small competition, starting from scratch. Before this you only need to install
the program and have its start icon available. It is assumed here
that no draw is carried out; instead, competitors are given start times at the same time as their names are entered.

1. **Setting up the competition**

1. Start the program HkKisaWin from its icon
2. Click *Competition creation and
   basic properties*
3. Click *Select competition folder* and
   select an unused folder, or create a new folder and select it
4. On the top line, type the name of the competition, which will appear in the results lists
5. Select the sport and its variant (here
   *Skiing* and *Normal* )
6. Tick *Create new class data* and enter
   the number of classes to use (this can be increased later)
7. Click *Accept selections and exit*

2. **Naming the classes**

1. Select *Preparation* and
   *Class data* from the menu
2. Click *Allow editing
   in table*
3. Change the class names to the desired form
4. When no draw is used, nothing else needs to be
   done, but if you like you can also change the first number, which is the smallest
   bib number for each class, and enter the start interval of the class
   in seconds and the start time of the first starter. If you want the distance in the results,
   you can enter it in the column *Distance* in kilometres, with decimals if needed.
5. Finally, save the data with the button
   *Save edited data*. You can then close the form.
   (Forms often have a Close or Exit button, as this one does. There is also
   Close in the menu. If a form has none of these, you can close it with the cross in the top corner.)

3. **Creating the competition
   file**

1. Click the large button *Open competition
   for preparation* and select the suggested file ilmoitt.cfg. The program then creates an empty
   competitor file. (There is not always a configuration file in the folder.
   In that case you can accept the selection of a non-existent file. The important thing here is to end up in the right folder.)
2. When the competition has no draw, you do not necessarily need to do anything
   else in preparation mode. If
   some entries are already known, you can enter them here, but I describe entering them below.
3. Close the program from the menu or with the cross in the top corner.

4. **Recording competitors
   by typing**

1. Start the program and click *Open competition
   for results service*. Now you can accept the suggested
   configuration file laskenta.cfg .
2. Select *Entries* and
   *Entries* .
3. Go to the tab *Selection of functions and
   data to process* .
4. In the top right corner, select *Add new
   records* .
5. Tick *Number added ones
   automatically,* unless you specifically want to assign numbers yourself.
6. Ticking Give start time automatically
   may help in assigning start times, but the program may not be able to
   know the times, so it may be better not to tick it.
7. You can untick *Id code* and
   *Identifier codes*. They are not used in this competition.
8. Go back to the originally shown
   tab *Usage* .
9. Start recording a new competitor in the field
   Last name if you have requested automatic numbering; otherwise start by entering the number.
10. Move to the next field with the Enter key and fill in the data to be saved
11. Select at least the class, either with the mouse,
    the up and down arrow keys, or by typing the class name until the correct class is shown.
12. Also enter the start time (or correct the start time offered by the program if needed.
13. When Enter has moved the focus to the button
    *Save*, pressing it again saves the competitor.
    Automatic numbering takes place at this point.
14. The data appears in the table area above,
    where you can check that it went in correctly.
15. If an error is found in the data, you have to switch
    from *Add mode* back to *Edit mode*. In that case it is
    usually a good idea to tick *Use bib number to find record
    to edit* .
16. You can bring a competitor up for correction either by clicking
    the corresponding row of the table or by entering the bib number and pressing Enter.
17. When the corrections have been made and saved, adding
    new competitors again requires switching to
    *Add mode* .
18. The form can be closed when the competitors have been
    recorded, but it can also be left open if more entries are expected.

5. **Timing** (here only
   finish times are taken, assuming the start times have been entered correctly) Times are taken
   with a keyboard key, according to the computer clock.

1. Select *Results service, Timing* and
   *Timing-1* .
2. Under *Recording changes in
   browse table*, select the option *Number only* .
3. Select *Timing devices* and
   *Timing key and point*
4. Press the key to be used for timing. The key
   ½/§ in the top left corner is a good choice.
5. Select *Finish* under *Point for which
   times are taken* and close the form.
6. In the table, click the cell of the column CompNo
   on the first free row, which initially contains 0.
7. The program is now ready to take times and attach them to competitors.
8. When a competitor finishes, press the key reserved
   for timing; the time should
   appear in the column *Time* .
9. Make sure the cursor is in the CompNo field
   of the row corresponding to the time, type the competitor's number and press Enter.
10. Once you have confirmed the saving, the
    competitor's name and final result should appear to show that the result has been recorded.
11. You can take several times before starting
    to enter numbers. Always make sure that each number goes to the correct row.
12. The timing form does not need to be closed until
    the competition is over, even if other forms are also used.

6. **Viewing the results**

1. To view the results you can select
   *Monitoring, Standings* and *New* .
2. On this form you can view the results of different classes
   by changing the class. Several similar forms can be open
   at once if they fit on the screen. The form is normally updated whenever a new result arrives.
3. You can also view start times on the form.

7. **Recording disqualifications and
   non-finishers**

1. These can be recorded either by opening
   the competitor data form via *Entries / One
   entry,* where you can also change other competitor data, or
   with the dedicated form *Entries / Mark check codes* .

8. **Producing the results
   lists**

1. Select *Outputs* and *Printer and
   file output* .
2. Select either

1. Printer output and the printer to use, or
2. File output, the file type and the file name

3. Select the classes to output
4. Click Print
