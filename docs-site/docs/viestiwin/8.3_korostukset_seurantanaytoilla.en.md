# 8.3 Highlighting on monitoring displays

### 8.3 Highlighting on monitoring displays

#### 8.3.1 Latest events display

On the announcer's latest events displays the program
highlights the following information using colours

- On the latest events display, results reaching
  the top places are highlighted with two highlight colours

  - By default, results reaching places 1-3 are
    highlighted with a green background colour

    - By default, results reaching places 4-5 are
      highlighted with a yellow background colour- Disqualified and did-not-finish results are highlighted with a purple
    background colour

    - On the latest events display,
      VIP competitors are highlighted using three background colours, which for the VIP classes
      are by default 1: violet, 2: blue and 3: olive green.

The competitors belonging to the VIP classes are read from the file
korostus1.lst when the program starts. In multi-day competitions
the number of the file corresponds to the competition day: korostus1.lst on the first day,
korostus2.lst on the second and so on. The day number is determined by the parameter PÄIVÄ;
if the parameter has not been given, the file korostus1.lst is used. The file can
also be read while the program is running with the main form selection *Files /
Settings / Display / Read highlight data.* Reading the file again always cancels
the data read earlier.

From the file korostus1.lst (or the corresponding day-specific file)
you can at the same time also read new place limits for highlighting the top places
and change all the colours used for highlighting. The file can contain
three types of lines:

```
OLETUS  2  6
```

gives the place limits for highlighting the top places. This example
changes the limits to places 2 and 6.

```
VÄRI  6  000180255
```

gives a new colour for one highlight class.
The highlight classes are

1. top places

   - following places

     - disqualified and did not finish

       - VIP class 1

         - VIP class 2

           - VIP class 3

The colour code consists of three three-digit numbers,
each between 0-255. Each number gives the brightness of one colour
component. The components are in the order blue, green and red. The
example above says that the colour of VIP class 3 consists of the full amount of
red and 180 units of green. Of other colours, bright yellow is 000255555
and bright turquoise 255255000.

The competitors placed in the different VIP classes are given
on lines of the type

```
VIP  45  1  
VIP  50  2
```

These lines say that competitor 45
belongs to VIP class 1 and competitor 50 to VIP class 2.

#### 8.3.2 Standings display

On the class standings display, fresh results are highlighted
with colour codes. The very freshest and slightly older results are highlighted
with the same two colours that are used for highlighting the top places on the latest
events display. By default, time limits of 60 s and 180 s from the moment the result
was created are used. The colouring is removed only when the display is updated because of some
event or by clicking *Refresh,*; otherwise it
may remain visible unchanged indefinitely.

The time limits can be changed with the standings display selection
*Options / Highlight time limits.*
