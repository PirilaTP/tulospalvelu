# 10.2 Team orienteering

### 10.2 Team orienteering

Before the competition, start times must be assigned as described in the previous section or otherwise transferred to the competitors.

The courses must be defined so that the data show which
controls everyone must visit and which only one member. The common controls
may additionally require punching in the correct order or allow
deviations. This is marked using letters that are entered in the course
in place of an ordinary control code (see also [chapter 13.8](13.8_valinnainen_leimausjarjestys.md)
):

- J: the controls
  following this are compulsory for everyone and
  must be punched in the order given in the course data. All controls from the start of the course up to the first other letter belong to this group, even if the letter J is not at the beginning.

  - P: the controls following this are compulsory for everyone, but the punching order is free.

    - V: the controls following this are required from only one team member.

The results service normally takes place at punch checking.
When the team members' data are read, the result and approval are determined only when
all cards have been read. On the punch checking display the program shows the punches in the same
way as in an ordinary relay, so the colour codes shown do not correspond to
team orienteering, but alongside it the program shows another form on which
the data are compiled so that the team's overall performance is easy to review.
The program also concludes approval or a proposed disqualification only when all cards have been read.

**Warning**
: The program may make
unfounded disqualification proposals in situations where, among the controls to be run in the defined order,
there is an extra punch from some other control belonging to the course.
Before final disqualification you must therefore make sure that the punching order really is against the rules.

Data on the result and approval are recorded primarily for the last member.

In results lists the
best option is to select the final result, all legs and compact display of leg data on one line.
