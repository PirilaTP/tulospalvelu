# Vacancy records

In some situations it is useful to add a few
competitors (for example 10 vacancies, unless other use is expected) to the competitor file
in the preparation phase. I suggest defining a class of its own for these vacancies,
with all its "competitors" defined as vacancies.
Defining a record as a vacancy means in many respects the same as
marking it as not started, but the program knows that records defined as vacancies
may be used when that helps in handling a problem situation.
Possible uses come up mainly in punch checking.

Vacancy records can also be added for competitors to be recorded
later. It is often less problematic to change the data of an already created vacancy than
to add completely new records during the competition. If such additional competitors
are expected, increase the number of vacancy records created so
that there are sure to be enough.

Vacancy records are created on a form opened with the menu item
*Entries / Add vacants*. If you follow my recommendation,
the vacancies are added to a vacancy class, which can be named, for example, VAKANTTI.
Choose the starting number outside the number range otherwise in use.
Last name and club can be left empty; the first name is always
the bib number. It is good to give a start time, and it can sometimes be before the start of the
competition. The most important thing is that the records created are marked as vacancies.
