# PDF manuals

These manuals are available from the original website in PDF format and
have not yet been converted to Markdown. They are in Finnish.

- **[HkMaali 5.0 instructions](https://www.tulospalvelu.fi/pirila/ohjeet/pdfs/HkMaali50.pdf)**
  — user manual for the HkMaali console program. HkMaali is the DOS/text-mode version of the program
  for timing without a Windows user interface.
- **[Emit punch checking 5.0](https://www.tulospalvelu.fi/pirila/ohjeet/pdfs/EmitLeim50.pdf)**
  — user manual for Emit chip punch checking.
- **[TCP support](https://www.tulospalvelu.fi/pirila/ohjeet/pdfs/TCP-tuki.pdf)**
  — user manual for data transfer in distributed timing and for TCP connections.
