# 5.9  Användning som startklocka

### 5.9 Användning som startklocka

Programmet kan användas som startklocka på följande sätt

- Öppna formuläret för uppföljning av ställningen

  - Välj den klass som ska visas och som punkt att visa
    *Start*

    - Välj vilka kolumner som ska visas, teckenstorlek (den
      lämpligaste kan finnas via valet *Annan teckenstorlek*) samt kolumnbredder.

      - Välj *Följ starter* i menyn samt
        vid behov antalet ljudsignaler (t.ex. 1: endast vid startögonblicket, 4: tre
        korta signaler med en sekunds mellanrum och en längre vid startögonblicket)

Programmet visar alltid endast de startande i den valda klassen eller
klasskombinationen och ger ljudsignaler endast för sådana
startande. Alla klasser på startplatsen kan tas med genom att definiera
en klasskombination som innehåller alla dessa klasser (se [kapitel 2.3](2.3_sarjayhdistelmat.md)
).
