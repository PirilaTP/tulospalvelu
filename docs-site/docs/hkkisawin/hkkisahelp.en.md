# HkKisa Help

## Results software for individual competitions: HkKisaWin and HkMaali

### Version 5.20

### Pekka Pirilä, 19.4.2015

HkKisaWin, a program with a graphical Windows user interface,
is suited to handling almost all functions related to the
results service of a competition. HkMaali is a more streamlined console program whose
reliability has been maximised by avoiding complex
user interface libraries and development tools. HkMaali is therefore
better suited to handling the most critical real-time
tasks of major competition events. The programs work together so that during the competition
each task can be handled with the program best suited to it.

These instructions focus mainly on HkKisaWin.
The use of HkMaali is described, among other places, in a separate document
supplied as a PDF file. Features that are found only in
HkMaali are often covered only in the HkMaali PDF instructions.

More instructions on using the programs
can be found on my website. There you will find, among other things, instructions for installing the programs
and sport-specific instructions for running a results service with the programs.
