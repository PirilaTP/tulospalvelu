# Programs

The software consists of two programs:

- ***HkKisaWin***
  is a Windows program in the
  sense we are used to today. It covers all functions
  related to the results service and therefore consists of many different forms,
  which are opened through menus.

  - ***HkMaali*** is more limited
    in scope and contains very few functions that are not also included in
    *HkKisaWin*, but because of its simplicity
    it is efficient to use in the tasks it is suited for, and
    because of its simplicity it is also reliable. In the more complex
    program *HkKisaWin*
    there is
    a greater risk that not all available functions work as expected,
    and also of other disturbances.

The program *HkKisaWin* is essential for all users,
because a competition can only be set up with it. *HkMaali*
can be left out entirely, for example
in fitness orienteering events, but at least for now it is better for many
tasks in national competitions, especially timing, and possibly
also orienteering punch checking.

The program *HkKisaWin*
needs several library files (dll and bpl files) to run; they
are normally installed together with the program in the same
folder.
