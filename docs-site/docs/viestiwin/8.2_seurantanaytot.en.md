# 8.2 Monitoring displays

### 8.2 Monitoring displays

#### 8.2.1 Class standings display

On the standings display
you can follow the situation of a class at a selected point (split, changeover or finish) and
also view the start list.

The display options allow you to change how the country abbreviation is shown and the font size. You can
also view the list of disqualified and did-not-finish teams.

Clicking a competitor's data on the standings display opens more detailed information about that team in a separate
window. Clicking another row changes the team shown.

Clicking a leg in the team data opens more information
about the leg.

#### 8.2.2 Latest events display

On this display you can view the latest data received
during the session at a selected point. One possible use is
following an approach control and selecting competitors for tracking by clicking
the corresponding row. The competitor display that then opens is always linked to
the latest events display from which it was opened.

#### 8.2.3 One team's data

This is the same view that you get by clicking
a competitor's data on the standings display or on the latest events display. The display opened
from the menu is separate in the sense that clicking
data affects the window that was opened by clicking, not
the form opened from the main form's menu.

The competitor to follow can be selected e.g. by bib number
and by using the name search.

The form also has a button *Info*, which opens background information about the competitor
in a browser window, if their data and the link have been prepared before the event.

#### 8.2.4 One leg's data

In this window you can view the competitor's
Emit split times after the punch check has been done, if they are forwarded to that
computer.

#### 8.2.5 Competition progress

This selection brings up a graphical display showing
the development of the time differences between teams according to the changeovers and online split times.

#### 8.2.6 Emit graphics

In this window you can view and graphically compare
the Emit split times of the competitors in a class after the punch check has been done, if they
are forwarded to that computer.

#### 8.2.7 Emit summary

On this form you can view summary information
about the Emit split times.
