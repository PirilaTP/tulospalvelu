# Description of the example competition

## Organising the results service for an orienteering competition

#### 2.5.2013

#### A fairly small example competition

This guide goes through the steps involved in the results service of a typical national
orienteering competition.

Before starting these steps, the software must be installed, and this
is assumed to have been done according to the installation instructions.

The example competition is expected to have a few hundred competitors. There is no separate
timing; instead, the times are obtained from punch checking. The punch-checking
computer also handles some other tasks in the background. The results service
itself also uses a second computer for recording various changes,
for the complaints desk ("wailing wall") and for all miscellaneous results-service
tasks. A third computer is with the announcer for following the competition.
