# 2.5 Starting automatically in the desired mode

### 2.5 Starting automatically in the desired mode

You can make the program start directly in a predefined
mode, i.e. either preparation or results service mode, by making
the corresponding selection in the main form option
*Files / Startup settings*. In this window you can edit the configuration file,
select the configuration file to be opened at automatic startup and
select the mode in which the program starts automatically.

The selections are saved in the file init.cfg , which is located in the startup folder
defined for HkKisaWin; this is usually not the same as the competition folder and does not
change when another competition is selected from within the program.

The selectable data are:

- whether the program starts in the main form, from which you can proceed to the desired competition,
  or directly in preparation or results service mode of the selected competition- the configuration file used at automatic startup

The configuration file can also be edited on the form.

With the option *Files / Save windows* you can
save much of the state of the forms in use, i.e. the open
forms and their positions as well as some other form-related
selections. The state saved in this way can be restored with the option
*Files / Load windows* and automatically by giving
the parameter

ikkunat

or

ikkunat=<tiedosto>

in the configuration file, where <tiedosto> is the name of the
file in which the state has been saved. If no file name is given,
the default name oletus.ikk is used.

Saving the layout is particularly useful for the announcer's
station, which uses many forms, but automatic
startup in a predefined mode is also practical in all
functions where the mode does not vary and where the user may not know
the program well.
