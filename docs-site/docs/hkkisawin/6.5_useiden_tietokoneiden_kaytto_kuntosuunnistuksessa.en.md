# 6.5 Using several computers in recreational orienteering

### 6.5 Using several computers in recreational orienteering

Using several computers requires that the computers are
connected in a local network, which can be wired or wireless, but
requires that the IP address of at least one computer is known and that the other computers
can connect using this IP address. Use further requires that
firewalls do not prevent connections and allow the program to act also as
a UDP server.

The competition is normally prepared on one computer, and
the competition data created is copied to the corresponding directories on the other computers. The data of the different
computers can otherwise be identical, but the parameters describing data transfer
in the configuration file differ from each other. (See the
instructions on data transfer elsewhere.)
