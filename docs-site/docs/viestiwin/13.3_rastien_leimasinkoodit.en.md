# 13.3 Control punch codes

### 13.3 Control punch codes

On this sub-page you change the codes of the punching
units at the controls. The punching units of each control are on the same row. Up to six codes
can be defined for one control.

The data are saved by first storing them in memory and
then to a file. The consistency of the definitions can be checked once the data
have been stored in memory.

The punch codes can be included
in the same XML file as the course data. In the program's results service mode they must be found in the same
file, unless an old-style text file is also used for the courses.

All punch codes can be removed with the button
*Clear table*, after which new codes can be read
from a simple text file in which each row has first the control code
and then one punch code. The same control code can be repeated on several
rows.
