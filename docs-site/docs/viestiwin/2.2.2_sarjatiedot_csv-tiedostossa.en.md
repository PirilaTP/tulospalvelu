# 2.2.2 Handling class data in a csv file

#### 2.2.2 Handling class data in a csv file

The class data can be
written to a csv file, which is easy to view and also to edit in Excel.
The edited file can be read back into the program. In that case,
however, the format of the file written by the program must be carefully preserved. The program
uses the semicolon as the separator. Not absolutely all data are necessarily
written and read, so this function is mainly intended for editing
data with other tools, such as Excel
