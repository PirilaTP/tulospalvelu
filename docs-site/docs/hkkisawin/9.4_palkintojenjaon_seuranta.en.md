# 9.4 Tracking prize-giving

### 9.4 Tracking prize-giving

The program option *Monitoring / Status*  provides tracking of the best possible placing
of each class and the possibility to record
that the prizes of a class have been awarded. In a multi-stage competition
you can choose whether to track the placing of an individual stage or the overall placing,
which is calculated taking into account the results of earlier stages. The best possible
placing is determined assuming that timing is in real time.

The above functions are enabled through the form's menu.

The marking that the prize-giving has been held is made by double-clicking the relevant
cell of the table. Double-clicking again removes the marking. The program saves the information
immediately to a file, which is read when the function is enabled after the program has been
restarted.

Provided that the printer has been enabled, the
program asks, when the marking is made, whether the results of the class are printed and how many
of the best are printed. This way printing does not have to be handled separately through the normal
options. The limitations here are, however, that the printing always concerns
only those with an accepted result, each class is always printed
on a separate sheet, and that
in a multi-stage competition printing automatically concerns the day's results, except in the last stage of
a multi-stage class, in which case it concerns only those with an overall result, in order of the
overall result.
