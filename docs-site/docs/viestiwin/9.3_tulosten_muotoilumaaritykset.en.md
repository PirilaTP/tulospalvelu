# 9.3 Output formatting settings

### 9.3 Output formatting settings

The program handles the formatting of start lists and
results lists separately, based on the solutions used
in the earlier separate programs (Arvonta and Maali). Both kinds of formatting
are, however, edited using the same form component. Of the data itself, only
the font selections are shared; other features are defined separately
for start lists and results lists.

The general principle of formatting is that for each data item
its position on the line, the field length and whether the field is aligned
left or right are defined. For printer output the position on the line is expressed
in thousandths of the line length and the field length in characters.
File output uses fixed-width characters and the position is given
in characters.

The start list
formatting definitions can be hard
to interpret because of the large amount of data and the resulting lack of space
on the form. The program defines 7 different start list types,
each of which has its own columns. The columns also consist
of three groups, each of which has a column for each
list type. The first group gives the positions, the second the field
widths and the third the alignments. Each row has one data type; the lowest
rows, however, have other definitions, described further below.

The start list types are

- Start list by class (alphabetical, number or
  start order)- Alphabetical start list of all competitors- Start list by club- Start list by start- Of the first three there are separate versions
          with the start times of either only one stage or all stages. A column
          name ending in "-2" refers to the latter start lists

Below the rows for the different data types there are
rows defining the following parameters, each in its own column group.
Thus, for example, on the row *Dy/Tm/Dst* the first 7 columns
concern writing the date, the next 7 writing the time of day, and the rest
writing the distance on the heading rows. The value 1 requests the item and 0 leaves it out. The time step and the margin
size are given in the same way as field positions.

- Ap (time step): Offset between the time positions of different stages, in position units (only
  in multi-stage competitions)- Mrg: Left margin in position units- Sv: Each class on a new page (1) or continue
      on the same page (0)- Pv: Write the date in the heading (1: yes, 0: no)- Klo: Write the time of day in the heading (1: yes, 0: no)- Mtk: Write the distance in the heading (1: yes, 0: no)- Seura: Write the full club name, not the abbreviation (1: yes, 0: no)- Etunm: Write the name in the order "first name last name" (1: yes, 0:
                no)

The class name is written in the heading
generally so that the long class name is written if it has been given;
otherwise the short class name is written followed by the distance, if
a distance has been given. In some lists, mainly those concerning a single leg,
the short class name is however always used, and in some the distance is
left out. No distance is added after the long class name, because the format
chosen automatically by the program does not necessarily meet the needs and because the distance
can be included in the long class name.

HTML output can be written either as plain text
using fixed-width fonts or using a table structure, which is now
the default. Additional formatting can be done using the CSS formatting file
tuloslue.css
.
The available classes can be seen from the source code of the output.
