# Definition av banor

Banorna definieras på undersidan
*Banor* i formuläret *Banuppgifter*.

Mycket ofta har banorna planerats på dator med programmet Ocad eller Condes.
De uppgifter som dessa skapar kan läsas in för resultatprogrammets användning
på undersidan *Överföringsfiler*, där du ska ange vilken slags fil det
gäller och sedan öppna den för inläsning via knappen *Läs fil*.
I samband med inläsningen kan du också göra de val som gäller resultattjänsten
när det gäller nollställningsförskott och tidtagningssätt. Vidare kan du i samband
med inläsningen lägga till målkontrollens kontrollkod till banorna, om målet inte har tagits med
som kontroll i banuppgifterna. För att säkra tidtagningen bör målets stämplingsenhet
tas med som kontroll i banuppgifterna även när tiderna tas med online-tidtagning
på mållinjen.

Normal praxis vid nationella tävlingar är att brickorna nollställs före
starten, som sker vid den lottade tidpunkten. Då är det fråga om ett
varierande nollställningsförskott. Vid motionsorienteringar är det vanligaste förfarandet att
brickan nollställs i nollställningsenheten vid starttidpunkten, och då är nollställningsförskottet
noll.

Vid nationella tävlingar används allmänt två tidtagningssätt.
I det enklare, som i första hand behandlas i dessa anvisningar,
räknas tiden alltid från stämplingskontrollen, och den bestäms då av
tidpunkten för stämplingskontrollen samt av uppgifterna från Emit-brickan, som visar
hur många sekunder som har gått från stämplingen i målet till stämplingskontrollen.
Det andra vanliga sättet bygger på stämpling på mållinjen, vilket här betyder
att tidpunkten för denna stämpling registreras omedelbart på en annan
dator som är reserverad för tidtagningen.

I vissa fall har även stämplingskoderna sparats när banorna
definierades. Programmet läser dessa uppgifter på begäran.

Sättet på vilket banans namn förekommer i filen som läses varierar, så
det kan krävas att man provar sig fram för att välja rätt alternativ.

På undersidan *Banor* kan du granska och redigera banuppgifter som lästs in på
det sätt som beskrivs ovan, eller definiera helt nya. På denna sida kan du
också läsa och skriva banuppgifter i det format som resultatprogrammet använder,
och då är filens namn i allmänhet antingen RADAT.LST eller
RADATn.LST, där n är numret på etappen i en tävling med
flera etapper.

Fler anvisningar finns i formulärets hjälpanvisningar.
