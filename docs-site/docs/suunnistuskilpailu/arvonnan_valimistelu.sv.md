# Förberedelse av lottningen

Innan lottningen genomförs måste du fastställa starttiderna för de första startande
i klasserna samt de nummer från vilka numreringen av deltagarna i varje klass börjar.
Detta görs i klassdefinitionerna, där redigering av uppgifterna
i klasstabellen är det lämpligaste alternativet. Programmet stöder bäst
följande förfarande:

1. Alla klasser ges startplatser, första nummer
   och första starttider så att ordningen blir den önskade, men uppgifterna behöver
   i övrigt inte alls vara i närheten av de slutliga.- I klasstabellen väljs *Etapp 1* som visade uppgifter och
     *Första nummer* som ordning. Då visar programmet klassvis
     antalet deltagare och, baserat på dessa, det sista numret i varje klass,
     förutsatt att första numret har definierats tidigare. Därefter
     kan du antingen redigera första numren manuellt med hjälp av de sista nummer som programmet
     räknat fram eller fastställa första numren automatiskt med ett menyval.
     Vid automatisk numrering måste du först välja hur många lediga nummer som ska lämnas mellan klasserna
     och sedan genomföra själva numreringen.- Ändra klasstabellens ordning till
       *Start/starttid*. Då visas klasserna i samma start
       efter varandra i ordning enligt de preliminära starttiderna. De sista starttiderna för varje klass som programmet
       räknat fram gör det nu lättare att fastställa starttiderna så att
       klasser som startar från samma fålla enkelt kan fås att starta med lämplig
       förskjutning. Eftersom det i allmänhet inte är ändamålsenligt att ange startplatsen
       med fållans noggrannhet lämpar sig det automatiserade förfarandet för starttider inte för vanliga orienteringstävlingar,
       men de beräknade sista starttiderna för klasserna är till hjälp. Naturligtvis måste du också säkerställa
       att startintervallen har definierats rätt.- Att nummerområdena inte överlappar kan du
         ännu kontrollera med knappen *Sök överlappande
         nummerområden* på lottningsformuläret
         .
