# 5.8  Comparing time queues

### 5.8  Comparing time queues

Through the menu of the timing form you can go to comparing two
timing queues. The queues can be selected from those used
for timing. The program uses colour coding to show the differences between the queues.
The selection criteria of the coding can be changed with a menu option.

The timing data can be browsed so that scrolling the left
table moves both tables equally, while scrolling
the right one moves only that table. The keys used for browsing
are Up, Down, PgUp, PgDn, Ctrl-PgUp and Ctrl-PgDn. Typing
numeric values and the scroll bar can also be used for
browsing.

The key combination Ctrl-PgUp returns both tables
to row 1.

Rows can be deleted and added on the form, but further handling of an added
row must be done on the normal
timing form.
