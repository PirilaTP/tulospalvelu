# 10.1 Common features of multi-stage competitions

### 10.1 Common features of multi-stage competitions

The program has versatile support for different kinds of
multi-stage competitions, such as cross-country sprint competitions, orienteering competitions
with a qualification and a final, and competitions where
times or points make up a combined result. Such a competition can also include
a pursuit stage.

When defining the basic properties of the competition, you must select
the number of stages and whether the competitors' classes or bib numbers
can change from one stage to another. In cross-country sprint competitions, for example, both
normally change, because each heat is handled as a class of its own. When a
stage is a pursuit, the numbers usually change when moving to it. If a change
occurs in even one class, the selection must reflect this.

If the timing precision changes from one stage to another, the
practice of each stage must be selected before that stage.

The method of calculating the combined result can be defined in the basic data
of the class. The options are:

- Sum of the times of the different stages, requiring that the class is
  the same in all stages
- Time from the first start time of the class. (Suitable for
  pursuit competitions when everybody starts in pursuit fashion.)
- Best of the results obtained in the different stages
- Sum of the times of the different stages, allowing the class
  to change from one stage to another. Suitable for competitions where the program uses
  classes to separate parallel heats from each other.
