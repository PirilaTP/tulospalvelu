# 5.9  Use as a start clock

### 5.9 Use as a start clock

The program can be used as a start clock as follows

- Open the status monitoring form

  - Select the class to be shown and as the point to be shown
    *Start*

    - Select the columns to be shown, the font size (the most
      suitable may be found through the option *Other font size*) and the column widths.

      - From the menu select *Follow starts* and,
        if desired, the number of beeps (e.g. 1: only at the moment of start, 4: three
        short beeps one second apart and a longer one at the moment of start)

The program always shows only the starters of the selected class or
class combination and gives beeps only for such
starters. All classes of the start location can be included by defining
a class combination containing all these classes (see [chapter 2.3](2.3_sarjayhdistelmat.md)
).
