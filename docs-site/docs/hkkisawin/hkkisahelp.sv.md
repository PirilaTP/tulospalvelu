# HkKisa Help

## Resultatprogrammen för individuella tävlingar HkKisaWin och HkMaali

### Version 5.20

### Pekka Pirilä, 19.4.2015

Programmet HkKisaWin, som har ett grafiskt Windows-gränssnitt,
lämpar sig för nästan alla uppgifter som hör till resultattjänsten
vid en tävling. HkMaali är ett enklare konsolprogram vars
tillförlitlighet har maximerats genom att undvika komplicerade
gränssnittsbibliotek och utvecklingsverktyg. Därför passar HkMaali
bättre för de mest kritiska realtidsuppgifterna vid betydande
tävlingsevenemang. Programmen fungerar tillsammans så att varje uppgift
under tävlingen kan skötas med det program som passar bäst för ändamålet.

Tyngdpunkten i dessa anvisningar ligger på programmet HkKisaWin.
Användningen av programmet HkMaali beskrivs bl.a. i ett separat dokument
som levereras som pdf-fil. De särdrag som endast finns i programmet
HkMaali behandlas ofta bara i pdf-anvisningarna för HkMaali.

Fler anvisningar om hur programmen används
finns på min webbplats. Där finns bl.a. anvisningar för installation av programmen
samt grenspecifika anvisningar för att sköta resultattjänsten med programmen.
