# 2.2.1 Changing class data

#### 2.2.1 Changing class data

Class data can be changed both in the table and
in the class-specific window.

Before starting to make changes in the table you must click
the button *Allow editing in table*. The changes
are saved only when you ask for them to be saved. As is typical in Windows,
editing in the table may additionally require a single click in the field concerned
or pressing the F2 key. You can make several changes in the table
before saving them, so it is particularly well suited to making changes affecting
many different classes.

In the table you move from one field to another with the arrow
and Tab keys.

In the class-specific window, the class shown is changed
by browsing or by clicking a new row in the table. The fields *Class sequence number* and *Class
name* are used for changing the data, not for selecting the class being handled.

A request to delete a class always applies to the most recently
selected class, even if the class sequence number has been changed.

A new class is added by first pressing the button *Add class to define* and then giving,
in the field *Class sequence number*, the position at which the class
is added when the data are saved. Thus, for example, sequence number 1 adds
the class as the first one and increases the sequence numbers of all previous classes.
If you want to add it at the end, enter 0 or the number following the last
class.

The position of a class in the table can be changed by giving a new
sequence number and saving the data. The sequence numbers of the other classes
then change as required by the change.

The class data are used as follows:

- The class sequence number is the program's internal identifier
  for the class, and it determines the order of many lists.- The class name is the primary identifier of the class, at most 10 characters
    long and consisting of capital letters and digits (many
    punctuation marks, such as the hyphen, are also allowed in the class name).- The class long name is written in many
      results lists if it has been given. Otherwise the class name is used.- The number of legs can be selected.- The first number tells from which number the program's
          team numbering starts. This value has no other effect.- The start time is the start time of the first leg of the class.
            In patrol and team competitions with interval starts it is the first start time
            of the class used in the draw.- Start
              is the identification number of the start location, best given in the range
              1-9. Among other things, start lists by start location are compiled based on this number.- The finish number tells which finish the competitor
                should arrive at. This can be used, for example, to split automatic results listings
                to be printed at several different points.- The Penalties item tells whether the class
                  uses time penalties or penalty loops.- A reduced fee can also be given,
                    for example for early entries.- The distance is given as a text string of at most 7
                      characters. It can therefore also contain letters. However, in some cases the program
                      adds the characters `km` after the distance, so you should check whether the result is as desired.- Split times is the number of split points on the leg.- The number of penalty places is information given for biathlon.
                          It can be selected once the class has been set to use penalties.- The penalty unit is the time in seconds corresponding to one penalty.
                            It is used when penalties are given as a count. If penalties are entered in seconds,
                            the unit must be set to 1. The setting applies both to the penalty for a miss in biathlon
                            (usually 0 in a relay) and to other penalties
                            determined by a count, such as the control route orienteering penalty.- The mass start time is the start time given for the leg,
                              which is either given to everyone before the competition
                              on the numbering form or defined to be assigned automatically during the relay.- The mass start
                                threshold is the threshold value for arrival at the previous leg's changeover, used when
                                the mass start is marked automatically.- Distances to split points
                                  are entered on this form.- Together with the split point distance, the
                                    publicity level of the split point is given, which can be used, among other things, in the online service. When
                                    the publicity level is set to *Hide* or level 0, this indicates that
                                    the point should not be shown. The publicity level can be Hide, Public or
                                    a numeric value 1, 2 or 3, which can be used to give more precise instructions.
                                    A larger value
                                    means greater publicity.- Instructions on the additional data and procedures needed in relays with parallel legs
                                      are given in the appendix.

The start time of a class can be changed on the class data form even while the competition is
in progress.
