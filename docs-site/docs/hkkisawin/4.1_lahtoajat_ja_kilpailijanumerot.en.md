# 4.1 Start times and bib numbers

### 4.1 Start times and bib numbers

Start times and bib numbers are assigned
in the program option *Preparation* / *Draw and
numbering* .

Each competitor must usually be given a start time
for every stage in which he or she takes part. This can be omitted only
in orienteering events where the start time is deduced afterwards
from the Emit card data, as is common practice in fitness orienteering. Start times
depending on earlier stages, such as pursuit start times, are given when this is
possible.

Each competitor must also have a number on every
competition day. This number is referred to below as the bib number. In addition,
each competitor has a base number common to the whole competition. When the bib number
does not change from one stage to another, all these numbers are the same. The basic
competition data defines whether the bib number changes or not.

Determining start times and assigning bib numbers
are usually done separately, because the relationship between them varies.
Assigning start times is referred to below as the draw, even though it is not always
based on drawing lots.

Start lists on paper and to a file are produced
in the program option *Outputs*.
