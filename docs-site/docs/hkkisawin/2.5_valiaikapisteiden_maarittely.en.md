# 2.5 Defining split points

### 2.5 Defining split points

Split points are defined via the class definitions.

Split points are defined one stage at a time, and the changes made must be saved before changing the stage. For split points
at least the location is defined, which the program stores as a string,
so the value can be in text form. The last split point defined for a class
determines how many points times can be taken for.

In addition to the necessary location data, the split time
definition form shows one other data item at a time, which can be either the time limit
or the control code of the split point. The second data row can also show
whether a formula has been defined for that split point. It is also possible
to mark that the point is not public, which information can be used, for example, by an online service when choosing
what data is shown. The data to be handled is selected
from the drop-down list above the table.

Five levels are available for the
publicity of a split point:

- Hide (numeric value 0)

  - Levels 1 - 3

    - Public (numeric value 10)

The options hide and public are selected with the keys P and J,
the other levels with a number key.

The time limits defined for split points
are used to determine the sequence number of a split time, for example in cross-country skiing competitions where the same loop is skied
several times. This feature is described in more detail
in the HkMaali pdf manuals.

On the basis of the control code of a split point, the location of the point can be fetched from the course data, if the leg lengths have been
stored in the course data. The control code can also be
useful for online services.

Split points can be written to a csv-format
text file and read back. The file stores the locations of the points,
their codes and time limits in seconds. Before the split points, the class distance
and the time limit for the finish are stored for each stage. However, the program does not take into account
a change in the class distance when reading the file. The distance must be changed
in the class data.

From the split point definition you can also move on to defining the calculation formulas of calculated times
handled like split times. The same function is also used to define
the formulas for calculating points that depend only on the competitor's own result. (See
section 5.2)

In biathlon you can also define how many
shooting positions' penalties are included in each split time.
