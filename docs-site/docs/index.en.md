# Pekka Pirilä's results software

User manuals for the results software that Pekka Pirilä (1945-2015) originally started
in 1986. This site brings together the instructions from the original [tulospalvelu.fi/pirila](https://www.tulospalvelu.fi/pirila/ohjeet/)
website in one place and keeps them easily available.

## The program family

**HkKisaWin** and **HkMaali** — software for individual competitions (hk =
henkilökilpailu, individual competition). Used for timing in orienteering, cross-country skiing, biathlon and
other individual sports.

**ViestiWin** and **JukMaali** — software for relay and team competitions.
Used in running and skiing relays, the Jukola relay and similar
events.

The programs were released under the GPLv3 licence by Pekka's family in 2016.
The source code is in the [PirilaTP/tulospalvelu repository](https://github.com/PirilaTP/tulospalvelu).

## Notes on the documentation

- The instructions were imported from the original HTML website by automatic conversion.
  The formatting may be incomplete in places. If you notice problems, you can
  edit the page directly on GitHub with the "Edit this page" button at the top of
  each page.
- The instructions were originally written in Finnish; this English version is a
  translation. The programs' user interface can be switched between Finnish, Swedish
  and English, but configuration parameters, file formats and internal naming
  are Finnish.
- The instructions date from 2012–2015 and relate to HkKisaWin
  version 5.x. Some details, especially file formats
  and hardware interfaces, may have changed in newer versions.
