# 2.2.5 Distributing class data changes over the network

#### 2.2.5 Distributing class data changes over the network

Class data must normally be copied to every computer
using it by other means. While the program is running it is,
however, possible to transfer updated class data to the other computers if
file transfer has been enabled (see [Appendix
2](hkliite2.md)). When this has been done on all computers taking part in the transfer,
the transfer can be started by saving the class data with the button *Save edited data* on the form
*Class data*
and accepting
the transfer when the program asks for confirmation.

The transferred data is not put into use until all
data is read again, which always happens when the program is started and with
the main form options *Files / Change stage* and
*Files / Re-read classes and other data again*. These options cause
the corresponding functions to start throughout the network, provided that no computer
has messages waiting to be sent in any data transfer queue. The functions are thus
available during a break in results service operation, provided that the program is in use
according to all defined connections.
