# 2.3 Klasskombinationer

### 2.3 Klasskombinationer

I vissa tävlingar, såsom
löpevenemang där resultat görs både för åldersklasser och för alla som
sprungit samma distans, behöver resultat tas fram inte bara för enskilda
klasser utan även för kombinationer av flera klasser. I programmet ViestiWin kan
flera sådana klasskombinationer hanteras (i grundversionen 10 kombinationer
åt gången). Klasskombinationerna definieras med filen `SARJAYHD.LST`, som består av rader
av följande slag

`YHD1 SRJ1 SRJ2 .. SRJN`

där först står det namn som kombinationen ges och
därefter en lista över de klasser som ska ingå i kombinationen. Antalet klasser
som ingår är inte begränsat.

Resultaten för en klasskombination som skapats på detta sätt kan följas
och skrivas ut på samma sätt som resultaten för vanliga klasser. För klasskombinationer
kan också poäng beräknas och de kan användas i lagtävlingar.

Om du vill använda ett långt klassnamn för en kombinationsklass,
måste det anges åtskilt med kolon efter kombinationsklassens namn
så att alla mellanslag har ersatts med understreck, till exempel så här:

`YHD1:Yhdistelmäsarja_ykkönen SRJ1 SRJ2 .. SRJN`
