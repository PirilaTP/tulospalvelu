# Preparing the draw

Before carrying out the draw, you must set the start times of the first
starters of the classes and the numbers from which the numbering of each class's competitors
begins. This is done in the class settings, where editing
the data in the class data table is the easiest option. The program best supports
the following procedure:

1. Give all classes first numbers so that the order
   is as desired, and give the first class the first start time of the whole competition. The data
   does not otherwise need to be anywhere near final.
   The first number and the first start time are given so that they include the free start times of the vacancy places
   preceding the first class.- In the class data table, select *Stage 1* as the data to show and
     *First number* as the order
     .- In the option *Automatic changes /
       Vacant numbers between classes*,
       select the number. The same number of numbers will also be
       left free at the beginning of the first class.- Select *Automatic changes /
         Ski competition base model*. The program then sets the first number
         and start time of each class so that the classes follow one another, leaving room
         for the selected number of vacancy places at the beginning of each class.

Another, somewhat more complex procedure offering more choices
is the following

1. Give all classes start locations, first numbers
   and first start times so that the order is as desired, but the data does not
   otherwise need to be anywhere near final.- In the class data table, select *Stage 1* as the data to show and
     *First number* as the order. The program then shows, per class, the
     number of competitors and the last numbers of each class determined from them,
     assuming the first number has been defined earlier. After this
     you can either edit the first numbers by hand, using the last numbers calculated
     by the program as an aid, or set the first numbers automatically with a menu option.
     In automatic numbering, first select the number of free numbers to leave between classes
     and then carry out the numbering itself.- Change the order of the class data table to
       *Start/start time*. The classes of the same start are then shown
       one after another in order of their preliminary start times. You can
       then ask the program to calculate the classes' start times by selecting the function
       from the menu. Alternatively, you can use the information shown by the program
       and enter the times by hand.- You can
         also check that the number ranges do not overlap with the button *Find overlapping number
         ranges* on the draw form
