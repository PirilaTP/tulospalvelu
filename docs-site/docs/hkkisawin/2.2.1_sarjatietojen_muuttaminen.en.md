# 2.2.1 Changing class data

#### 2.2.1 Changing class data

Class data can be changed both in the table and in the
class-specific window.

Before starting to make changes in the table, you must click
the button *Allow editing in table*. Changes
are saved only when you ask for them to be saved. As is typical in Windows,
editing in the table may also require a single click in the relevant
field or pressing the F2 key. You can make several changes in the table
before saving them, so it is particularly well suited to making changes concerning
many different classes.

In the table you move from one field to another with the arrow and
tab keys.

The class shown in the class-specific window is changed by
browsing or by clicking a new row in the table. The fields *Class sequence number* and *Class
name* are used for changing the data, not for selecting the class to be handled.

A request to delete a class always concerns the most recently
selected class, even if the class sequence number has been changed.

A new class is added by first pressing the button *Add class to define* and then giving,
in the field *Class sequence number*, the position at which the class
is added when the data is saved. For example, sequence number 1 adds
the class as the first one and increases the sequence number of all previous classes.
If you want to add it at the end, enter 0 or the number following
the last class.

The position of a class in the table can be changed by giving a new
sequence number and saving the data. The sequence numbers of the other classes
then change as required by the change.

The class data is used as follows:

- The class sequence number is the program's internal identifier
  for the class, and it determines the order of many lists.- The class name is the primary identifier of the class, at most 10 characters long, made up of capital
    letters and digits (many punctuation marks, such as the hyphen, are also
    allowed in the class name).- The long class name is written in many
      results lists if it has been given. Otherwise the class name is used.- The first and last competition day indicate which
        stages of the competition the class takes part in.- The handicaps/penalties item indicates, among other things,
          that the class is a control-route class. The option *Children's
          class* only affects some of the wording in the results list (the word *error* in place of *disqualified*
          and the word *missing* in place of *did not finish* ).- The first number common to all stages indicates where
            the assignment of base numbers to the entrants of the class begins. This is also
            the number used in all stages, unless the competition has been defined
            to use changing bib numbers.- Start is the identification number of the start location, which is best
              given between 1-9. Among other things, start lists by start location are compiled on the basis of this
              number.- Start queue is a refinement of the start location. It can
                be used, for example in an orienteering competition, to indicate classes whose start times are
                consecutive because of the load on the same course or start location- The finish number tells which finish the competitor should
                  come to. This can be used, for example, to divide automatic results listings
                  for printing at several different points.- Stage-specific first numbers are used to determine
                    bib numbers when they change from one stage to another.- The first start times are the times of the first starter of the class
                      used in the draw.- The first late-entry starts help give
                        late entrants times earlier than the drawn times.- The start interval is the interval in seconds between consecutive
                          start times used in the draw. The start interval must be set to a non-zero value when
                          the competition is not a mass start competition, even if the start times are determined in some way other than
                          in the program's Draw function. Otherwise it is not possible to make outputs
                          in start order.- The number of simultaneous starters is used when
                            more than one competitor from the class starts at the same time.- The number of shooting positions is information to be given
                              for biathlon.- The penalty per error applies both to the biathlon
                                penalty for a miss and to other penalties determined
                                by number, such as the control-route orienteering penalty.- The distance is expressed as a text string of at most 7
                                  characters. It can therefore also contain letters. However, the program
                                  in some cases appends the characters `km` to the distance
                                  , so you should
                                  check whether the result is as desired.- The stage type is *Indiv.* (independent) when the result of the stage
                                    is not combined with earlier stages, i.e. always for stage 1. For later
                                    stages you must select whether it is a *pursuit* or another kind of
                                    *continuation* (*Cont.*). The selection affects
                                    some functions of the program and is therefore important.- The fee can be given for the whole competition and for one
                                      day of participation. For the whole competition a reduced fee can also be given,
                                      for example for early entrants.- A class can be marked as a vacancy class by ticking the relevant
                                        box. It is usually advisable to include at least one vacancy class among the classes,
                                        and it is best placed last in the class list. A vacancy class is important
                                        in all orienteering competitions using the Emit system and in
                                        running events where entries are also accepted on site during the
                                        event.
