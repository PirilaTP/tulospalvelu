# 8.4 Background information on competitors

### 8.4 Background information on competitors

On the form showing an individual competitor's data you can
request background information to be displayed. This requires the information to be in a form
suitable for a web browser, either in a file on the computer used, on the local network or
on an internet server at an address that can be reached.

For this you must prepare a file `tietolista.txt` containing the links to each person's
information. The file must have the form:

`tiedosto   tietoa.html  
2345       #mattila_matti5657http://www.ssl.fi/SSL/sslwww.nsf/sp?Open&cid=UrheilijaProfiili-2&id=05C10B813E919FA8C22570B4003619E4  
56789      file:///c:/hakemisto/ali/tiedosto.html#kohta
  
nor00001234   #norjalainen`

The first line gives the file or URL link to the page where the subsequent short links are found. The numbers at the beginning of the lines are licence numbers or international (WRE or FIS) codes, which begin with a country code and must have eight digits. The other lines contain either these short links to the page on the first line or full links to the web or to other files.
A local HTML file can be very simple, of the form:

```
<html>
<body>
<h2>Tietoa kilpailijoista</h2>
<hr>
<h3><a name="mattila_matti">Matti Mattila</h3>
<p>Tietoa Matti Mattilasta
<hr>
<h3><a name="norjalainen">Norjalainen</h3>
<p>Tietoa Norjalaisesta
</body>
</html>
```

In marathon events, for example, participants often set
themselves targets or state their previous personal best. This data can
be stored in the competitor's stage-specific data
together with the entry data or in the additional data transfer function.
The data can also be handled on the single-entry form. The personal best and
target time can be selected for display on the latest events display and
on the standings display. The program highlights with colour when the personal best or target time
is beaten.
