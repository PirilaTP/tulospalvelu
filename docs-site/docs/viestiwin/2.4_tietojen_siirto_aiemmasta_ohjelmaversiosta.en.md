# 2.4 Transferring data from an earlier program version

### 2.4 Transferring data from an earlier program version

ViestiWin can read the class and competitor files
of an earlier program version. This requires the following steps:

- Select the folder you want to work in
  and copy the old KILP.SRJ into this folder.- The old file KILP.DAT must not be placed in this
    folder without renaming it to something else- Start ViestiWin and open the folder mentioned above
      with the button "Open competition for preparation".
      You need not worry about the missing file ilmoitt.cfg.- Exit the program and delete the new empty KILP.DAT created by the program, because
        its structure usually does not match your wishes.- Start the program, go to editing the basic data
          and read the KilpSrj.xml just created as the basis for the class data.
          Then change the definitions as desired and save the class data.- Go again to the function *Competition
            creation and preparation,* and the program then creates an empty
            KILP.DAT file in the correct format.- If you also want to transfer the old competitor data,
              - select *Entries / Get from file* from the main menu- select *Old KILP.DAT*- make sure that the numbers of legs and split
                    times match the old program version (these data should
                    be correct if the transfer is done in the same session in which the old
                    KILP.SRJ was read, but later the data may be wrong).- start the transfer with the button *Read from file*,
                      which lets you select the old KILP.DAT from the
                      directory and under the name it now has
                      (the KILP.DAT in the working directory is the new empty file).
