# Lottning och startlistor

Lottningen omfattar tre arbetsmoment

- Förberedelse av lottningen

  - Tilldelning av starttider

    - Numrering av de tävlande

Du kommer till alla arbetsmoment via valet *Förberedelse /
Lottning och numrering*, men det förstnämnda görs i
klasstabellen, dit du också kan gå direkt från huvudmenyn.

När alla dessa steg har genomförts är
tävlingsuppgifterna klara för utskrift av startlistor och för själva
tävlingen.
