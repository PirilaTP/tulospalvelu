# Chapter 15. Nordic combined

## 15. Nordic combined

The program supports converting Nordic combined ski jumping points
into cross-country start time differences, and converting the cross-country result
into ski jumping starting points. The other functions needed for handling the cross-country
part of a Nordic combined competition are included in the program's other features, such as
transferring additional data, forming a pursuit start, and the options
available for the results list.

On the Nordic combined form, the basic selection is the
order of the disciplines. When the jumping competition comes first, the competition must be defined as having two stages.
The jumping points and the corresponding
time differences are then entered in the first stage as "results". When the cross-country race comes first, the program does not use a second
stage, and the competition can be defined as single-stage. In both cases
the sport of the competition is cross-country skiing. When the cross-country part is run as a pursuit start, this stage must be marked as a pursuit
in the class data.

When the jumping comes first, the jumping points are read as the stage 1
stage points 1 in the function for transferring additional data, multiplied
by ten. The corresponding stage 1 "results" are calculated on the Nordic combined
form. The pursuit is formed from these results in the function [Create pursuit](10.3_takaa-ajolahto.md)
.

When the cross-country race comes first, the program handles only stage
1. The points difference is calculated from the results and stored as stage points 1
multiplied by ten.  The points difference can be written to a file in the function
for transferring additional data and included in the results list.
