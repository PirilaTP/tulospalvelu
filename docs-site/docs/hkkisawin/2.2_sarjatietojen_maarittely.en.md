# 2.2 Defining class data

### 2.2 Defining class data

Once the competition has been created, you can move on to editing
the class data. This can be done both before the competition is opened
for preparation and while the competition is open. Class data is added and
changed in the menu option *Preparation /
Class data* and class by class in the window that opens when
a class's data is double-clicked in the class list. In the table you can only
change data; additions, deletions and changes to the order of the classes
are made via the class-specific window.

Adding classes and changing their order can
become slow when done for a competition that already has many entrants.
It is therefore best to aim to define all the necessary
classes already at this stage. The classes appear in the menus in the order in which they occur in the class data. This order is
also used in many outputs. Classes without competitors
are skipped in most situations, so there is no great harm in leaving them between the classes in use.

The class data table has two basic forms. *Extended*
means a table that shows the data of all stages at once
and contains a large part of all the data that can be defined for a class.
The columns shown can be selected in the option *Show*
and the order from the drop-down list.

When one stage is selected as the data to be shown, the
program shows only the data relevant to numbering the competitors and
determining start times. This mode is described in more detail in chapter [4.2 Draw](4.2_arvonta.md)
.

In the option *Additional functions / Points calculation* you define the formula according to which the program calculates
the competitor's points when he or she gets a result on the basis of which points can be
calculated. (Calculating points when the formula is not based only on the competitor's
result is described in chapter [11 Calculating competitor
points](hkluku11.md)

The special features of cross-country sprint are described in [chapter 10.2](10.2_hiihdon_sprintti.md).
