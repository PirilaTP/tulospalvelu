# 2.6 Starting automatically in the desired mode

### 2.6 Starting automatically in the desired mode

The program can be made to start directly in a predefined
mode, i.e. either preparation or results service mode, by making
the corresponding selection in the main form option *Files /
Startup settings*. In this window you can edit the configuration file,
select the configuration file to be opened at automatic startup and
select the mode in which the program starts automatically.

The selections are stored in the file init.cfg , which is located in the startup folder
defined for HkKisaWin; this is usually not the same as the competition folder and does not
change when another competition is selected from within the program.

The selectable data is:

- whether the program starts in the main form, from which you can proceed to the desired competition,
  or directly in the preparation or results service mode of the selected competition

  - the configuration file used at automatic
    startup (does not apply when an event list is used)

    - use of the event list. If
      automatic startup has also been selected, it applies to that day's competition, in which case
      the configuration file is determined from the event list data. (see section 2.7)

      - use of the fitness orienteering restrictions. When
        this is selected, the competition can only be started in results service mode, and some other
        functions have minor restrictions or changed defaults

The form can also be used to edit the configuration file.

In the option *Files / Save windows*
you can save, to a large extent, the state of the forms in use, i.e.
the open forms and their positions as well as many other form-related
selections. The state saved in this way can be restored in the option
*Files / Load windows* or automatically by giving in the configuration file the parameter

ikkunat

or

ikkunat=<tiedosto>

where <tiedosto> is the name
of the file in which the state has been saved. If no file name is given,
the default name ikkunat.xml is used.

Saving the layout is particularly useful at the
announcer's station, which uses many forms, but automatic
startup in a predefined mode is also practical in all
functions where the mode does not vary and where the user of the program may not know
the program well.
