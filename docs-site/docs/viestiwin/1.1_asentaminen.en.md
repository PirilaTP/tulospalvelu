# 1.1 Installation

### 1.1 Installing ViestiWin

The program is installed with an installer that asks, during
installation, for the folder where the program itself is installed and
the folder where the program installs the startup file `init.cfg`. It is usually best
to install the program in the suggested folder, but the most suitable folder for the startup file may
depend on your needs. It is essential that the program can
write to the startup file. The startup file folder should usually not be the same as the folder where
the program is normally installed, because many Windows versions do not allow
writing to the program files directory tree.

The program suggests creating a folder `viestikisa` on the desktop. This folder is suitable
as the location of the startup control file `init.cfg` used by the program, but the competition data itself
should usually be placed in a separate working folder for each competition, which can be,
for example, a subfolder of `viestikisa`. This
folder can be created from within the program when you create a new competition. The
only purpose of the file `init.cfg` is to tell which
competition is being handled and in which operating mode the program should open
the next time it is started. These selections are made and saved through the
menu item *Files / Startup settings*.
If the program has been set to start in a way that fails because of faulty
data, it may be necessary to delete the file `init.cfg`, after which the startup selections can
be made freely.

If you want to use ViestiWin repeatedly
for handling more than one competition in turn, it may be worth using
several startup files `init.cfg`,
each in its own folder, and setting each of these folders as the
start-in folder of its own shortcut. Alternatively, the file init.cfg
can be given another name, which is given
as a command-line parameter in the shortcut.
