# 9.2 File output

### 9.2 File output

HTML output is the most complete. The
SSL orienteering file can also be written for the current day.
Many other formats may also work, but verification is still in progress.

Files can be written both as UTF-8 (Unicode)
files and as more traditional Ansi/ISO-8859-1/Windows files. Which one
works better depends on the intended use.

#### 9.2.1 File output for the Finnish Ski Association

The results are written
in results service mode of the competition stage being output, on the form of the selection Outputs. The file
name is defined as for other file output. As the file type, select SHL
output; the program selects ISO-8859-1 as the character set. Classes are selected in the normal
way. Other selections do not need to be changed unless a narrower selection is wanted.

For a skiing competition, the program asks,
when output starts, for the competition code and, for each
class, the distance and technique. The class-specific prompts can be skipped
with a tick in the corresponding field if you are sure the data is correct.
The program takes the distance and technique from the distance field of the class data, in which
the technique must be the last (or last two) characters and the distance
before it in kilometres with at least one decimal, according to the Finnish Ski Association's
instructions (see [chapter 2.2.3](2.2.3_matka_ja_hiihtotapa_hiihtokilpailussa.md)

#### 9.2.2 Additional features of HTML output

HTML results lists can use formatting controlled by a CSS
file. The name of the formatting file used is then tuloslue.css. The available codes become clear when
you produce a sample by ticking the box *Link to file
tuloslue.css*.

Text and also images can be added below the main heading of both results and start lists.
Adding text does not require
HTML commands, but HTML commands can also be added among the text
to format it, add links to images
or to other HTML documents, and use many other possibilities
of the HTML language. The program opens an editing window when the box *Add
text below the title* is ticked.
At the same time you also select any earlier file from which text
is taken and specify a new file for saving the edited text for
use. The program leaves everything else unchanged but replaces line breaks with the HTML codes <p> and
<br>.

The third box that can be ticked lets you see
immediately what the resulting HTML output looks like.

#### 9.2.3 Other text output

The program can also write results to a file
in CSV format, which is suitable e.g. for further processing in Excel. Because of the
nature of the results, this works best for leg-specific results.

All results can also be written to a file as continuous
text, so that each class is written with line breaks made
only on the basis of line length. For these results you can choose to include either
the times and/or places at the changeovers or those of individual legs.
