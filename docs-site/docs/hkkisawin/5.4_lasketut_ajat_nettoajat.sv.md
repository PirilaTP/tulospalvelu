# 5.4  Beräknade tider, nettotider

### 5.4  Beräknade tider, nettotider

I programmet är det möjligt att definiera beräkningsformler
med vilka nya beräknade mellantider räknas fram ur de mellantider som
tidtagningen ger. Detta förfarande lämpar sig för beräkning av de nettotider som används vid
löpevenemang, och med hjälp av förfarandet är det också möjligt att ta fram mer komplicerade
resultat, till exempel sammanlagda tider för sträckorna mellan vissa tidtagningspunkter
så att en del av avsnitten lämnas utanför totaltiden.

Beräkningen bygger på formeln

`laskettu tulos = kerroin x
(aika2 - aika1) / jakaja`

där `aika1` är
resultatet vid startpunkten för det aktuella tidsintervallet och `aika2` resultatet vid slutpunkten. Koefficienten (kerroin) och divisorn (jakaja) är
i regel 1, dvs. de påverkar inte resultatet (värdet 0 tolkas också som värdet 1). Denna
formel ger direkt en normal nettotid; mer komplicerade tillämpningar kräver
att formeln tillämpas på tidigare beräkningsresultat.

Beräkningsformeln definieras i tabellen för definition av
mellantidspunkter genom att skriva 'K' i det tidsgränsfält för den mellantid som
ska beräknas med formeln, eller genom att dubbelklicka på ett fält som redan innehåller 'K' eller
texten *Formel*. I fönstret som då öppnas anges
de koefficienter som definierar formeln, och dessutom anges om formeln tillämpas även om
`aika1` saknas (dvs. är 0); `aika2` krävs alltid. Dessutom kan en nedre och
en övre gräns anges för den beräknade tiden; dessa ges som värde om de annars
överskrids. När formelns koefficienter har registrerats kan de sparas antingen endast
för den aktuella klassen eller för alla klasser, och då är punktens nummer alltid detsamma.

När mellantider beräknas bör du försäkra dig om att
tidtagningen inte ger tider till samma punkt. Här kan tilläggsvariabler till parametern
VAVUOROT behövas (se anvisningarna för programmet HkMaali.)

Nettotider och andra beräknade mellantider kan skrivas ut
till en html-fil och till en textfil av csv-typ genom att välja
resultat och mellantider som uppgifter att skriva ut och därefter de önskade punkterna.
Placeringen tas med om den begärs.

Formeln kan också användas för att bestämma den egentliga prestationstiden
när resultatet innehåller straff. Detta görs genom att välja att `aika1`
är starten (anges med punktvärdet -1) och `aika2` den punkt fram till vilken tiden ska bestämmas. Dessutom måste du välja att
straffen lämnas utanför resultaten. Även
mellantider kan innehålla straff, och då kan motsvarande förfarande användas
för att bestämma den verkliga tiden mellan två mellantidspunkter.
