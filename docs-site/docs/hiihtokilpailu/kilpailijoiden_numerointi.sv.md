# Numrering av de tävlande

När starttiderna har lottats går du till undersidan *Tilldelning av nummer.*
Om detta görs direkt efter lottningen av starttider är klasserna redan
valda och du behöver inte göra annat än konstatera att valen är
de önskade, som de borde vara, och klicka på knappen *Utför
numrering*.
