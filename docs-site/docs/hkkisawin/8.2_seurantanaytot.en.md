# 8.2 Monitoring displays

### 8.2 Monitoring displays

#### 8.2.1 Class standings display

On the standings display you can follow the standings of a class
at a selected point (split or finish) and also view the start list.
(A display of the previous standings, useful in multi-stage competitions, has not yet been
implemented. You can bring it up by also opening the program in the previous day's
mode from another working folder).

The display options let you change how the club and the country abbreviation
are presented, as well as the font size. You can also view the list of disqualified and
did-not-finish competitors. It is likewise possible to enable start time
tracking so that a starting competitor disappears from the display once the start time has passed,
so that the next starter is always on the top row.

Clicking a competitor's data on the standings display opens
more detailed data about that competitor in a separate window,
in which it is also possible to put a competitor under tracking. The competitor display
that opens is always linked to the standings display from which it was opened.

On the standings display the program highlights the latest results
with a green background colour and slightly older ones with a yellow background colour. The time limits
are 60 s and 180 s by default and can be changed through the menu.

You can also choose to show all or
several split times and finish times in the same table, which
can also include the start times. Split points can be selected one by one
or according to the publicity level defined for them (see [chapter 2.5](2.5_valiaikapisteiden_maarittely.md) ). All
these additional options are made through the menu. From the menu you can also choose
whether full times or differences to the leader are shown for those other than the leader. Furthermore,
from the menu you can select *Options / Smart order* , in which case each competitor
appears on the row corresponding to his or her latest split time.
A competitor is thus shown ahead of every competitor whom he or she is ahead of at that split point.

Start times can be followed so that those waiting to start
are shown in start order, with the next starter of the class always on the top row
(from the menu *Options / Follow starts*). Using
a class combination ([chapter 2.3](2.3_sarjayhdistelmat.md)) you can
show the starters of several or even all classes. This function can also
be used at the start like a start clock ([chapter 5.9](5.9_kaytto_lahtokellona.md)
).

#### 8.2.2 Latest events display

On this display you can view the latest data received
during the session at a selected point. One possible use is
following the pre-warning control and selecting competitors for tracking by clicking
the corresponding row. The competitor display that opens is always linked to the
latest events display from which it was opened.

#### 8.2.3 Competitor data with online split times

This is the same form that opens when you click a competitor's
data on the standings display or the latest events display. Forms
opened in different ways behave differently in that clicking data affects the window that
was opened by clicking that same form.

Ticking the option *Show
tracking window* opens a tracking window that shows which place
the time of a competitor still on the course would give at the selected point, as well as
a time comparison with those who already have a time.

The competitor to be tracked can be selected e.g. by bib number
and by using the name search.

The form also has a button *Info*, which opens background information about the competitor
in a browser window, if the data about him or her and the link have been prepared before the competition
([chapter 8.4](8.4_taustatiedot_kilpailijoista.md)
).

#### 8.2.4 Competitor data with Emit split times

In this window you can view a competitor's
Emit split times after the punch check has been performed, if they are forwarded to that
computer. The form contains comparisons with the best leg time and with a reference time calculated from a few of
the best. The settings for calculating the reference time can be
changed in the main form option *Files / Emit analysis settings*
.

#### 8.2.5 Emit graphics

In this window you can view and compare graphically
the Emit split times of the competitors of a class after the punch check has been performed, if they
are forwarded to that computer.

#### 8.2.6 Emit summary

On this form you can view summary data on
Emit split times.
