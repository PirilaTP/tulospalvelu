# Chapter 5. Timing functions

## 5 Timing functions

ViestiWin includes the possibility of using
a finish clock or chip systems capable of timing, such as
Emit punch units, the emiTag system and some RFID devices, but
for now I recommend using the program mainly for tracking and, for
smooth operation, handling the actual timing with ViestiMaali.

In ViestiWin's timing functions, times can easily be linked to competitors, but
ViestiMaali includes many special recording functions that ViestiWin does not have.

ViestiWin does, however, make it easier to perform many special operations during the results service,
such as changing all start times of a class when this proves necessary during the competition.

There are separate instructions for using the emiTag system.

Additional instructions on the Alge Timy finish clock are in [appendix 3](liite_7._algen_timy_usb_portissa.md)
