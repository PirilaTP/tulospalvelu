#### 2.2.2 Handling class data in a csv file

Class data can be written to a csv file, which is easy
to view and also to edit in Excel. The edited file can be read back
into the program. In this case, however, the format of the file written by the program
must be carefully preserved. When reading the file, the program accepts both
the semicolon and the tab character as the separator. Not necessarily all data
is written and read, so this function is intended mainly for
editing data with other tools, such as Excel
