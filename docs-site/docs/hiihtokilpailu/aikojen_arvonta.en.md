# Drawing the start times

You get to the draw through the menu item *Preparation / Draw and numbering*. The start times
are drawn on the *Draw* tab of the form
*Draw and numbering.*

For an ordinary ski competition, after the preparation
described above you only need to

- select *Draw ignoring
  clubs* or *Draw by
  orienteering rules*

  - click the button *Add
    all* and finally

    - *Perform draw.*

Of the form's options, *Draw by
orienteering rules* means that the program prevents members of the same club
from starting at consecutive start times whenever possible.
When *Full
name* is selected as the club name to use, the
program uses the long club name in this check. The prevention does not necessarily work
if some competitors have a country code recorded and some do not.
