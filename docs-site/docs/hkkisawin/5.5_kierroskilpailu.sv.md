# 5.5  Varvtävling

### 5.5  Varvtävling

Med varvtävling avses en tävling där
rangordningen i första hand bestäms av ordningsnumret för den senaste mellantid som tagits för den tävlande
och i andra hand av tiden vid denna sista
punkt.

Det lönar sig att
hantera tävlingen som en varvtävling även när vinnarens antal varv
är känt på förhand, men de som ligger mer än ett varv efter avslutar
tävlingen efter ett mindre antal varv än vinnaren.

Tävlingen definieras som varvtävling genom grenspecificeringen på formuläret *Definition av grunduppgifter*.

I en varvtävling tas alla tider
som mellantider, och för dessa bör minst en plats mer reserveras än någon tävlande
kan få, så att programmet kan hantera resultaten på bästa
möjliga sätt. Den tävlandes sluttidsfält används som ett andra lagringsfält
för den senast tagna mellantiden, och antalet varv sparas
i fältet för dagspoäng. Båda uppgifterna visas på ställningsvyn,
och antalet varv kan tas med i resultaten genom att i formateringen välja
att poäng visas. I formateringen kan du också ändra rubriken
*Poäng* till exempel till *Varv*
, om
kolumnrubriker ska tas med för att göra resultatlistan tydligare.

Programmet visar antalet genomförda varv, om man inte
på formuläret för styrning av utskrift begär att antalet saknade varv ska visas; detta räknar programmet ut
genom att jämföra med antalet varv för klassens vinnare.

**Obs. Eftersom den tävlandes slutresultat bestäms utifrån
mellantiderna måste alla ändringar göras i mellantiderna, inte
i sluttiden.**
