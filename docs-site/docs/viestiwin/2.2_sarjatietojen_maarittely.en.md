# 2.2 Defining class data

### 2.2 Defining class data

Once the competition has been created, you can move on to editing
the class data. This can be done both before opening the competition
for preparation and while the competition is open. Class data are added and
changed in the menu option *Preparation /
Class data* and class by class in the window that opens when
you double-click the data of a class in the class list. In the table you can only
change data; additions, deletions and changes to the order of classes
are made through the class-specific window.

Adding classes and changing their order may
become slow when done for a competition that already has many entrants.
It is therefore best to aim to define all the classes needed already at this stage.
The classes appear in menus in the order in which they occur in the class data. This order is
also used in many outputs. Classes without competitors
are skipped in most situations, so leaving them between the classes in use
does no great harm.
