# 4.3 Assigning bib numbers

### 4.3 Assigning bib numbers

Entry order means the order in which the data was
entered or read from a file.

The start order differs from one stage to another. It is therefore
possible to choose which stage's start order is used.

Numbering can apply to one selected stage only or to
all stages, in which case it also applies to the base number (permanent number). It is a good idea
to number all stages first and then renumber those
stages and classes where there is variation.

For cross-country sprint competitions there is an option
in which stages other than the first are given the bib number increased
by a constant (default 2000), so that the numbers fall in a range that is not used in the
competition. Those who qualify for the heats get the numbers they use when the heats are formed. If bib numbers
are not changed when moving on to the heats, this option should not be used; instead give all stages
the same numbers.

Numbering can apply to all competitors or only to
those who do not yet have a number. In the latter case the program searches for
free numbers starting from the class's first number and uses them in order.

The program does not assign numbers if, judging by the
class data, they would overlap. With the button *Find overlapping number
ranges* you can check before numbering whether there are such overlaps.
The check compares the classes selected for processing with each other and also with the other
classes, but not overlaps between other classes.

The previous section covered
setting the first numbers of the classes and the program functions supporting this.
