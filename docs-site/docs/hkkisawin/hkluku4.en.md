# Chapter 4. Draw and assigning bib numbers

## 4 Draw and assigning bib numbers

The draw function is available in preparation mode
and, in a multi-stage competition, for determining the start times and numbers of stages
later than the one in progress.

There are three main functions:

- dividing participants into subclasses, such as qualification classes

  - drawing start times

    - assigning bib numbers

The labels on the form should explain the meaning of the various options. More
instructions can be found in the sport-specific results service instructions.
