# Konsistens

Formulärets knapp *Kontrollera definitioner* får programmet att gå igenom
de ban- och stämplingsenhetsuppgifter som sparats i datorns minne. Programmet kontrollerar
då i första hand att samma stämplingsenhet inte förekommer på någon bana
vid kontroller som följer direkt efter varandra. En sådan situation skulle leda till att ingen
stämpling alls fås från den senare kontrollen. Programmet påpekar också vissa
lindrigare fel som inte gör stämplingskontrollen helt omöjlig
men som kan försvåra den.

Kontrollens resultat kan läsas på undersidan *Kontrollens
resultat*.
