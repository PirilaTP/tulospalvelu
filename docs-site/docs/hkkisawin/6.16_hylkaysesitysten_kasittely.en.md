# 6.16 Handling disqualification proposals

### 6.16 Handling disqualification proposals

Through a button on the punch check form
you can open a form for handling, saving and
printing disqualification reports. On this form you can record the basic data of the disqualification proposal
as well as the decisions made and the competitor's response to the proposal.

All the most important
selections and entries made on the form, except the timestamps, are saved in the competitor data, but
the competitor data has room for only 17 characters for text fields. When the data
is saved, it is saved as far as possible in the competitor data and at the same time
also in an XML file whose name shows the competitor and stage numbers.

The XML files are saved
in a directory that can be selected from the form's menu or with the parameter

RAPORTTIHAK=hakemistopolku

If the directory path does not contain the character '\', ':' or '/' among its first three characters,
the program interprets it as relative to the competition data directory, otherwise as an absolute path. The character '.' as the first
character also leads to interpretation as a relative path regardless of the following characters. The path
can also refer to an accessible directory on the local network, which allows
the same directory to be used from several computers. When all check reports
are saved in the same directory, it is easy to check there whether a particular
competitor's performance has been subject to a disqualification proposal. Two timestamps
are also saved in the XML file: the moment when the disqualification proposal was first
handled and the time of the latest save.

When the report directory also contains the file
hylkrap.xsl with the correct content, disqualification reports can be viewed
not only on the program's form but also in web browsers.
