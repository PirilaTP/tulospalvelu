# 1.1 Installation

### 1.1 Installing HkKisaWin

The program is installed with a setup program, which during
installation asks for the folder where the program itself is installed and
the folder where the program installs its startup file `init.cfg`. It is
usually best to install the program in the suggested folder, but the most
suitable folder for the startup file may depend on how you intend to use the
program. It is essential that the program can write to the startup file. The
startup file folder should not be the folder where the program is normally
installed, because many Windows versions do not allow writing to the
program files directory tree.

The program suggests creating a folder `kisa` on the desktop. This folder is
suitable as the location of the startup control file `init.cfg` used by the
program, but the competition data itself is usually best kept in a separate
working folder for each competition, which can be, for example, a subfolder
of `kisa`. This folder can be created from within the program when a new
competition is created. The only purpose of the file
`init.cfg` is to tell which
competition is being handled and in which operating mode the program should open
the next time it is started. These choices are made and saved via the menu
item *Files / Startup settings*.
If the program has been set to start in a way that fails because of faulty
data, it may be necessary to delete the file `init.cfg`, after which the startup choices can
be made freely.

If you want to use WinKisaHk repeatedly,
alternating between more than one competition, it may be worth using
several different startup files `init.cfg`,
each in its own folder, and setting each of these folders as the start-in
folder of its own shortcut.
