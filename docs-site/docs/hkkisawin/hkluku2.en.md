# Chapter 2. Creating and defining the competition

## 2 Creating and defining the competition

Creating the competition includes

The button field Competition creation and basic properties
takes you to make the basic choices, such as

- selecting and, if necessary, creating the folder used for the competition data

  - entering the competition title and code

    - defining the basic competition data

      - sport and sport specification

        - number of stages

          - storage and output precision of times

            - use of chip and start gate

              - persistence of bib numbers and classes from one stage to the next- the space reservations for the number of stages
        and the number of split times affect the file format to be created. The default values 2 and 10 are suitable
        unless larger values are needed.

The basic choices are saved in the class file, and
therefore they cannot be saved unless at least one class has been defined.
The program automatically creates the requested number of classes unless classes have been fetched
as a basis from earlier data.

In addition to the definitions of the competition as a whole, you must
define the classes to be used, which is done with *Preparation / Class data*.
The number of classes and their definitions can be changed later.

Once the basic data have been defined, the program can be opened
for preparation, whereupon it creates a new competitor data file and,
in the case of an orienteering competition, normally places 20
vacancy records in it, which may be needed in running the results service.
