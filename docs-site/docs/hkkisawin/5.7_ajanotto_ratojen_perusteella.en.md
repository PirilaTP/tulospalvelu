# 5.7  Timing by lanes, heats

### 5.7  Timing by lanes, Heats

When timing is done with a finish clock that gives a signal per lane, as for example in swimming competitions,
the following method can be used:

- Each competitor is assigned a heat and a lane
  (both given as a number greater than 0)- Before the start of the heat, the heat is selected in the program HkKisaWin
    from the timing function menu and in the program HkMaali with the keys Ctrl-E
    on the timing screen.- When a time signal comes from the clock, it is
      automatically recorded for the competitors of the heat, whose maximum number n must be given with the parameter LÄHTÖRYHMÄ=n.- When a timing signal comes from the finish clock, it is recorded
        for the lane whose connection to the clock signals is defined
        with the parameter PISTEET. The time can either go to a fixed
        point or in order to the split points and finally to the finish.

The form of the parameter PISTEET used is typically the following:

PISTEET=M,M,M,L,100,200,300,400,500,600,700,800

when only finish times are taken. If only the times of split point
1 are taken, the numeric values are increased by one, etc.

If you want the point to be determined automatically, first
to all split times and finally to the finish, the parameters

```
PISTEET=A,A,A,L,98,198,298,398,498,598,698,798
VAVUOROT
```

are needed. Reducing the numeric values by two is based on the fact
that the letter A corresponds internally in the program to the value -2.

The program gives as the lane the number of full hundreds after
the number has first been increased by two.

Times can also be taken based on the start signal
when the start time is obtained in some other way. This makes it possible to take
times for 9 lanes with a Timy, for example (the Timy also needs
the interface unit Tido to get the signals from the lanes to the clock). In that case
the letter L in the examples above is replaced
with a suitable numeric value.

A time already taken can also be changed into the start time of a heat
by pressing the key *R* in the bib number field and entering the heat number. This method can be used, for example,
when there are 9 lanes.

The program also supports the use of more than one finish clock,
which may be necessary when there are more timing points than the number
of inputs of one device ([chapter 5.1.3](5.1_maalikellon_kaytto.md)
)
