# Defining the courses

The courses are defined on the *Courses* tab of the form
*Course data*.

Very often the courses have been planned on a computer using the Ocad or Condes
program. The data they produce can be read into the results software
on the tab *Transfer files*, where you specify what kind of file
it is and then open it for reading with the button *Read file*.
When reading, you can also select the results-service options
for the clearing lead time and the timing method. Further, when reading,
the control code of the finish control can be added to the courses if the finish has not been included
as a control in the course data. To ensure reliable timing, the finish punch should
be included as a control in the course data even when the times are taken by online timing
at the finish line.

The normal practice in national competitions is that the cards are cleared before
the start, which takes place at the time given by the draw. This means a
variable clearing lead time. At fitness orienteering events the most common procedure is that
the card is cleared at the clearing punch at the moment of starting, in which case the clearing lead time is
zero.

Two timing methods are commonly used in national competitions.
In the simpler one, which these instructions mainly cover,
the time is always calculated at punch checking, in which case it is determined by
the time of punch checking and the data obtained from the Emit card, which shows
how many seconds have passed from punching at the finish to the punch check.
The other common method is based on punching at the finish line, which here means
that the moment of that punch is registered immediately on another
computer reserved for timing.

In some cases the punch codes have also been saved when defining
the courses. The program reads this data on request.

The way the course name appears in the file being read varies, so
choosing the right option may require some experimenting.

On the *Courses* tab you can view and edit course data read
as described above, or define completely new courses. On this page you can
also read and write course data in the format used by the results software,
in which case the file name is usually either RADAT.LST or
RADATn.LST, where n is the number of the stage in a multi-stage
competition.

More instructions are available in the form's Help.
