# 13.3 Kontrollernas stämpelkoder

### 13.3 Kontrollernas stämpelkoder

På den här undersidan ändrar du koderna för
stämplingsenheterna vid kontrollerna. Varje kontrolls stämplingsenheter står på samma rad. För en
kontroll kan högst sex koder definieras.

Uppgifterna sparas genom att först spara dem i minnet och
sedan i en fil. Definitionernas konsistens kan kontrolleras när uppgifterna
har sparats i minnet.

Stämpelkoderna kan ingå i
samma XML-fil som banuppgifterna. I programmets resultattjänstläge måste de finnas i samma
fil, om inte en textfil av den gamla typen används även för banorna.

Alla stämpelkoder kan tas bort med knappen
*Töm tabellen*, varefter nya koder kan läsas in
från en enkel textfil där varje rad först har kontrollkoden
och sedan en stämpelkod. Samma kontrollkod kan upprepas på många
rader.
