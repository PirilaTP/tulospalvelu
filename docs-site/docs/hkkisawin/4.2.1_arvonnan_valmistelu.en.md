# 4.2.1 Preparing the draw

### 4.2.1 Preparing the draw

Note: For cross-country skiing in particular there is a more automated
option ([chapter 4.2.2](4.2.2_hiihdon_perusvaihtoehto.md)
).

The draw is preceded by selecting the bib number ranges to be given to the competitors
of the different classes and the first start times of the classes. This is best
done in the class data table, which can be opened from the draw form or
from the main form menu.

In the class data table it is advisable to

- Select the data of one stage to be shown or,
  when assigning numbers, alternatively *Basic data*, which offers
  the easiest way of numbering taking all entrants into account
  regardless of attendance on individual days.

  - Select *First number* as the order when planning numbering
    and *Start/start time* when planning start times.

    - Enter the first numbers and start times in the desired
      order. The order of magnitude given in advance also determines the final order. Otherwise
      only the first of the values given affects the values calculated by the program.
      You can select from the menu that the start location number
      also affects the order.

      - The start number and, within the same start, the queue number affect the order of the classes when start times are assigned.
        The program supports placing classes so that the classes of the same
        queue of the same start are placed one after another. In orienteering competitions, for example,
        at least the classes using the same course should therefore usually be placed in the same
        queue. The queue number also helps manage the load at the start location. The queue number
        does not affect first numbers.

When the preparations described above have been made, the
first numbers of the classes can be assigned with the least effort via the menu option *Automatic changes* as follows

- Select *First number* as the order

  - If you want the numbering of the classes of each start location
    to begin from its own given value, select this mode
    from the menu.

    - Define the number of unused numbers to be left
      between classes in the relevant menu option

      - Select *Assign
        classes' first numbers* from the menu. The program then edits the numbers, preserving their
        mutual order but so that the classes follow one another, leaving
        the requested number of numbers in between. If it has been selected that the start matters,
        this is done separately for each start. When basic data is handled, the start
        of the first stage is used.

        - The table column Last no. shows the largest of the numbers
          given to the entrants of each class. This field helps if you want to
          change numbers in a way that differs from the automatic function.

          - The table also shows the total number of entrants
            in the class and the number in the stage being viewed. Automatic numbering
            is based on the stage data when
            one stage has been selected for handling, and on the total number when
            basic data has been selected.

The first start times of the classes are determined
in a corresponding way

- By selecting *Start/start time* as the order. As stated above, the
  queue number also affects the operation as a refinement of the start number.

  - The free time between classes starting from the same start and queue
    is given in seconds in the relevant menu option. Note
    that this is the total time between two competitors, not extra
    time relative to the normal start interval. At a minimum you must therefore give
    a number of seconds equal to the start interval.

    - The automatic function can now be started
      from the menu.

      - The table shows the start time of the last starter of the class
        to make manual editing of the data easier.
