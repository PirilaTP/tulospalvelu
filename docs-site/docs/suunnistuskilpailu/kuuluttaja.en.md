# Announcer

The forms intended for the announcer are selected from the
program's main menu item *Monitoring.* The most commonly useful options are

- **Standings**, where you can view
  the standings of one class at a selected point, such as the finish or some
  split point. Up to six standings forms can be open.

  - **Latest events**, which shows
    the latest events at a given point, such as the finish, including all
    classes. If no point has been selected, finish and split point times are shown
    mixed together, in which case the point is given in the column *Point.* Up to six of these
    forms can also be open.

On both forms mentioned above you can open
a competitor's data by double-clicking a row. In the window that opens you can
select another competitor too, and in these windows you can put one competitor
under tracking, compared with the results of the other competitors in the class. This is done
by ticking *Show tracking window.*

Data on Emit split times may also interest
the announcer. They can be viewed only provided that their transfer
to the announcer's computer has been enabled in the configuration settings.

The option *Status* displays statistics on
the progress of the competition.

Since the same windows are often opened for the announcer,
starting the program at the competition can be made more efficient by saving a suitable
window layout with the menu item *Files / Save windows* and defining the parameter ikkunat in the configuration to open the saved
layout automatically when the program starts.
