# 2.5 Automatisk start i önskat läge

### 2.5 Automatisk start i önskat läge

Programmet kan ställas in att starta direkt i ett fördefinierat
läge, alltså antingen förberedelse- eller resultattjänstläget, genom att göra
det valet i huvudformulärets val
*Filer / Startinställningar*. I det här fönstret kan du redigera konfigurationsfilen,
välja den konfigurationsfil som öppnas vid automatisk start och
välja det läge som programmet startar i automatiskt.

Uppgifterna om valen sparas i filen init.cfg , som finns i den
startkatalog som definierats för programmet HkKisaWin, vilken i allmänhet inte är densamma som tävlingens katalog och
inte ändras när en annan tävling väljs inifrån programmet.

De uppgifter som kan väljas är:

- om programmet startar i huvudformuläret, varifrån du kan gå vidare till önskad tävling,
  eller direkt i den valda tävlingens förberedelse- eller resultattjänstläge- den konfigurationsfil som används vid automatisk start

I formuläret kan du också redigera konfigurationsfilen.

Med valet *Filer / Spara fönster* kan du
spara läget för de formulär som används till stor del, dvs. öppna
formulär och deras placering samt vissa andra val som hör till
formulären. Det läge som sparats på detta sätt kan återställas med valet
*Filer / Hämta fönster* samt automatiskt genom att ange
parametern

ikkunat

eller

ikkunat=<fil>

i konfigurationsfilen, där <fil> är namnet på den
fil där läget har sparats. Om inget filnamn anges
används standardnamnet oletus.ikk.

Att spara layouten är särskilt nyttigt för en speakerplats
som använder många formulär, men automatisk
start i ett fördefinierat läge är praktiskt också för alla
funktioner där läget inte varierar och där programmets användare kanske inte
känner till användningen av programmet så väl.
