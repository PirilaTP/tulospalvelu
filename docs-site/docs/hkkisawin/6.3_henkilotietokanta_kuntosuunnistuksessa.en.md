# 6.3 Using the person database in recreational orienteering

### 6.3 Using the person database in recreational orienteering

When recreational orienteering mode 1 or 2 is used,
opening the punch check form automatically also opens the participant list and
the club list, if these exist and handling of clubs has not been disabled
with the parameter SEURATIETO=EI. It is worth recording in the participant list the Emit card
an orienteer repeatedly uses, since the program searches the person list for
the participant by Emit code and shows all persons for whom
the code received from the reader has been recorded. If there are several, you can then
select the person by browsing with the arrow keys. Browsing those found by code
requires the cursor to be in the Emit code field.

If the person is not found among those selected by code,
you can move to the name search. Typing the beginning of the name starts a search
in the database, and selection is made with the Enter key, using the
arrow keys if desired. If the name is not found, type the full name.

The club can be searched for in the same way by typing the beginning
in the club field, if the club list is in use. When the class has also been confirmed or
selected, you can press "Ctrl-Enter" in any of the fields or click
the button "Save".

If you want to save an orienteer who does not have
an Emit card, use the button "No Emit card".

If the person database CSV file has the columns
*OsOttoLkm* and *ViimOsOtto*, the program stores in them
the number of participations and the date of the latest participation. This data
is updated when you request on the person database form that the
competitors are saved to the database. The program then adds a participation for all participants (those with
a result, disqualified and did not finish) and at the same time records
the participation date in the form it has in the stage-specific additional settings of the competition settings. If this date field
is empty, the program uses the date of saving.
