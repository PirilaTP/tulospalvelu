# 1.2 Getting started and operating modes

### 1.2 Getting started with the program and operating modes

When the program is started, its main form opens.
It contains a list of the other forms that are open, three buttons
for selecting the operating mode, and menus from which functions
are selected.

The program has three
operating modes:

- **basic mode**, in which no
  competition is selected and only functions that do not require
  access to a competition can be used- **preparation mode**, in which
    a competition can be handled before it has been prepared sufficiently
    for results service mode. In this mode the program does not keep
    connections open to other computers or program instances handling the
    same competition, but works on its own- **results service mode**, which
      requires that all essential things have been defined and, among other things, that
      all entrants have been given bib numbers. In this mode the
      data transfer connections to other program instances are available and,
      in a multi-stage competition, one of the stages has been selected as active.
      Some of the preparation functions are disabled, because they would cause problems
      in this mode or while data transfer is running.

The previous section uses the
term *program instance*. This refers to the fact that
the same competition can be handled both on several computers that communicate
over a local network and on the same computer, based on data kept consistent
in several different competition folders, so that
either HkKisaWin or HkMaali has been opened separately for each
folder. Two program instances can thus run either on different
computers or on the same computer. In the case of HkKisaWin, each
program instance can open several windows, so it is rarely
justified to open several HkKisaWin instances on the same computer, but it is sometimes
justified to start both HkKisaWin and HkMaali, or several instances of
HkMaali.
