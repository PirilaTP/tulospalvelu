# 9.8 Competitor-specific printouts

### 9.8 Competitor-specific printouts

In orienteering competitions, you can print
per-competitor control split time printouts ([chapter 6.8](6.8_rastivaliaikatulosteet.md) ) and
punch check printouts ([chapter
6.1](6.1_leimantarkastuskaavake.md)
).

The menu item *File / Competitor
page printout* on the output form opens a form on which you can define and select
a few competitor-specific data items to be printed on a printer page. This
function is intended for use with pre-printed forms,
for example
for printing certificates of participation.

For each of the available data items you can choose
its position on the page. The horizontal position is given in
thousandths of the page width and the vertical position in points, i.e. in units of 1/72 inch. An A4 sheet
holds about 1100 points. In addition to the position, you can define the maximum
number of characters of the text and the font size from the alternatives in the
formatting settings:

1: normal body font  
2: subheading
font  
3:
main heading font

You can also choose whether the text is aligned to the left
or to the right.

Printing
can be done

- for a single competitor, selected
  by number
- for all competitors
  of one class
- for all competitors
  marked as present
- automatically whenever a participant previously marked as vacant or
  did not start
  is changed to present.

Once the settings are made, you can save them
to a file whose default name is PgTulMaar.xml. If
a file with this name is found in the competition data directory when the form is opened
for the first time, the program reads
it automatically.
