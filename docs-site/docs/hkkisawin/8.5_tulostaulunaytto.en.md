# 8.5 Scoreboard display

### 8.5 Scoreboard display

The display opened with the option *Monitoring / Standings*
can be configured to be better suited for scoreboard use. Two
features of the display relate to this:

- The table of the display can be defined to cover the whole
  window, leaving visible only the menu and a title row showing
  the name of the class and the point being displayed.

  - The table can be defined to scroll
    automatically. Scrolling is started by specifying the time in milliseconds corresponding to
    a one-pixel shift (30 ms is often suitable, but the best value depends on
    the display resolution and other situation-specific factors).

    - In addition, you can define the time for which the program
      pauses after the last row has appeared before returning to the beginning or to a new
      class, as well as a minimum time for which the program shows even classes that
      fit on the display at once.

      - When scrolling is started without selecting classes,
        it applies to the data already on the display. It is also possible to select several
        classes (or even all classes) to be shown in turn.

        - Scrolling can be defined as smooth, which is the more pleasant
          alternative when it works well. This display may however flicker
          disturbingly, in which case a display stepping a row or a page at a time is better.

          - Scrolling can be defined separately for each
            monitoring window opened. Thus several scrolling panes, arranged as desired,
            can be shown on a large display.

In scoreboard use the normal colours of the display do not always
meet the requirements of the situation or the equipment. For such a situation
the program has a ready option to change the background colour to black and the text
to yellow. Using a file with 10 colour-defining
lines, a user-defined colour scheme can also be
taken into use. Each of the lines has the form

sss;vvv:ppp;  comment (not
required)

where  sss, vvv and ppp
are numbers between 0 .. 255 and give the brightness of
blue, green and red.

The lines define the following 10 colours

- title row background
- reserved
- table background
- table
  alternating background (every 3 rows)
- highlight of a fresh result (background)
- highlight
  of a personal best or target (background)
- title row text
- table text
- highlight related to the starts display (text)
- 2.  highlight related to the starts display (text)
