# 7.3 Monitoring the completion of the competition

### 7.3 Monitoring the completion of the competition

The completion of the competition can be monitored both on the table form
*Teams* and by using the results list options designed for this
purpose.

On the form *Teams*, filtering the data makes it possible
to pick out only those whose check marking on a given leg is
*Open*.

In the results list options, the selection *Open* means all
those whose result cannot be determined and who have not been marked as disqualified,
did not finish or did not start. These also include those who
took part in a mass start and have finished, but whose team is missing
the result of some earlier leg.

The menu item *Entries / Show competitors on course* opens
a table, by leg, of the competitors who have an Emit number and
a recorded start time but no finish time yet, and who have not been marked
as absent, did not start, vacant, did not finish or disqualified.
A closed earlier leg is not enough: the next leg is shown only if it has
both an Emit number and a start time. The table shows the start location, start time and
the split points in use. This live display does not replace the results list
selection *In forest*.

The results list option *In forest* means all those
whose chip code (Emit code) has been recorded but for whom no
time or check marking has been recorded.

The results list option *Unchecked* means those who have
a time but no check marking.

The selection *Problem cases* can also produce information that helps
in monitoring the final completion of the competition.
