# 5.4  Calculated times, net times

### 5.4  Calculated times, net times

The program lets you define calculation formulas
that compute new calculated split times from the split times produced by
timing. This method is suitable for calculating the net times used in running events,
and it also makes it possible to produce more complex
results, such as combined times from the times between certain timing points,
with some segments left out of the total time.

The calculation is based on the formula

`laskettu tulos = kerroin x
(aika2 - aika1) / jakaja`

(calculated result = multiplier x (time2 - time1) / divisor), where `aika1` is
the result at the start point of the interval in question and `aika2` the result at the end point. The multiplier and divisor are
usually 1, i.e. they do not affect the result (the value 0 is also interpreted as 1). This
formula gives a normal net time directly; more complex applications require
this formula to be applied to earlier calculated results.

A calculation formula is defined in the split point
definition table by writing 'K' in the time limit field of the split that
is to be calculated with a formula, or by double-clicking a field that already contains 'K' or
the text *Formula*. In the window that opens you give
the coefficients defining the formula and also state whether the formula is applied even if
`aika1` is missing (i.e. is 0); `aika2` is always required. In addition you can give the calculated
time a lower and an upper limit, which are used as the value if they would otherwise
be exceeded. Once the formula coefficients have been entered, they can be saved either only
for that class or for all classes, in which case the point number is always the same.

When split times are calculated, make sure that
timing does not produce times for the same point. This may require the
additional variables of the parameter VAVUOROT (see the instructions for the program HkMaali.)

Net times and other calculated split times can be output
to an HTML file and to a CSV-type text file by selecting
results and split times as the data to output and then the desired points.
The placing is included if requested.

The formula can also be used to determine the actual performance time
when the result includes penalties. This is done by choosing that `aika1`
is the start (marked with the point value -1) and `aika2` the point up to which the time is to be determined. You must also choose that
penalties are left out of the results. Split
times may also contain penalties, in which case a corresponding method can be used
to determine the actual time between two split points.
