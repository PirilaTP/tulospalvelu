# 7.4 Formulär: Överföring av tilläggsuppgifter

### 7.4 Formulär: Överföring av tilläggsuppgifter

I valet *Flytta tilläggsdata* kan du överföra
många olika slags uppgifter från en fil till de tävlande samt initiera eller
tömma fält. I de flesta fall identifieras de tävlande som behandlas
med en nummerkod, som kan vara startnumret eller något annat id-nummer som sparats
i uppgifterna. Identifieringen kan också baseras på sådana fält
som har samma värde i flera lags uppgifter. Då registreras uppgiften för alla som uppfyller detta villkor.

I tillämpliga fall kan du välja den sträcka som
överföringen gäller. När överföringen görs för alla sträckor får alla sträckor
samma värde, utom i valet *Alla banbeteckningar*, som överför
en egen kod till varje sträcka från en fil vars rader består av lagets nummer och de gafflingskoder som följer efter det på samma rad.
