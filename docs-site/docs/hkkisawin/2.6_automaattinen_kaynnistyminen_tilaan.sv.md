### 2.6 Automatisk start i önskat läge

Programmet kan fås att starta direkt i ett i förväg
definierat läge, alltså antingen förberedelse- eller resultattjänstläge, genom att
detta val görs i huvudformulärets val *Filer /
Startinställningar*. I detta fönster kan du redigera konfigurationsfilen,
välja den konfigurationsfil som öppnas vid automatisk start och
välja det läge som programmet startar i automatiskt.

Uppgiften om valen sparas i filen init.cfg , som finns i den startmapp som definierats
för programmet HkKisaWin, vilken i regel inte är densamma som tävlingens mapp och
inte ändras när en annan tävling väljs från programmet.

De uppgifter som kan väljas är:

- om programmet startar i huvudformuläret, varifrån du kan gå vidare till önskad tävling,
  eller direkt i förberedelse- eller resultattjänstläge för den valda tävlingen

  - den konfigurationsfil som används vid automatisk
    start (gäller inte fallet där evenemangslistan används)

    - användning av evenemangslistan. Om
      automatisk start samtidigt har valts sker den för dagens tävling, varvid
      konfigurationsfilen bestäms av uppgifterna i evenemangslistan. (se avsnitt 2.7)

      - användning av motionsorienteringens begränsningar. När
        detta är valt kan tävlingen endast startas i resultattjänstläge och i vissa andra
        funktioner finns små begränsningar eller ändrade standardvärden

I formuläret kan du också redigera konfigurationsfilen.

Med valet *Filer / Spara fönster*
kan läget för de formulär som används till stor del sparas, alltså
öppnade formulär och deras placering samt många andra val som hör till formulären.
Ett läge som sparats på detta sätt kan återställas med valet
*Filer / Hämta fönster* samt automatiskt genom att parametern

ikkunat

eller

ikkunat=<tiedosto>

anges i konfigurationsfilen, där <tiedosto> är namnet på den
fil där läget har sparats. Om inget filnamn har angetts
används standardnamnet ikkunat.xml.

Att spara layouten är särskilt användbart för
speakerns plats, där många formulär används, men automatisk
start i ett fördefinierat läge är praktiskt även i alla
funktioner där läget inte varierar och där programmets användare kanske inte känner
till programmet särskilt väl.
