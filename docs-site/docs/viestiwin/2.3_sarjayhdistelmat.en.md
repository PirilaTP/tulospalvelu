# 2.3 Class combinations

### 2.3 Class combinations

In some competitions, such as
running events where results are produced both for age classes and for everyone who
ran the same distance, it is necessary to compile results not only for individual
classes but also for combinations of several classes. ViestiWin can
handle several such class combinations (10 combinations at a time in the basic
version). Class combinations are defined using the file `SARJAYHD.LST`, which consists of
lines like the following

`YHD1 SRJ1 SRJ2 .. SRJN`

where the first item is the name given to the combination and
it is followed by a list of the classes to be included in the combination. The number of classes
included is not limited.

The results of a class combination created in this way can be monitored
and printed in the same way as the results of normal classes. Points can also
be calculated for class combinations, and they can be used in team competitions.

If you want to use a long
class name for a combined class, it must be given after the combined class name, separated by a colon,
with all spaces replaced by underscores, for example as follows:

`YHD1:Yhdistelmäsarja_ykkönen SRJ1 SRJ2 .. SRJN`
