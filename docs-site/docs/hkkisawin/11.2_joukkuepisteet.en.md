# 11.2 Team points

### 11.2 Team points

Team points are always calculated when results
are compiled. The program has two different basic options for team points:

1. points calculated for teams of a fixed size
   taking part in the same class or combined class

   - points calculated, for example, for a club,
     adding up points obtained in several different classes and including all
     sufficiently well placed entrants.

Points according to item 1 are calculated by selecting in the results list options

- Output restriction:
  *Team results*

  - Making the necessary selections in the area *Team
    definition*

    - The team result is then based on points both
      in the option *Points* and in the option
      *Position* .

      - In the option *Points*, the
        competitor-specific points previously calculated into the field *Points* are used.
        This field is the competitor's overall points field, not the stage-specific
        points field

        - In the option *Position*, the placing
          can be used directly as the score, in which case fewer points are better, or
          the points given by each placing can be read from the file sijapisteet.lst.
          The 1st line of the file gives the winner's
          points, the second line those of the runner-up, and so on. These points are used if
          the file is found in the competition folder.

Points according to item 2 are calculated when you select

- Output restriction:
  *Team results*

  - In the area concerning team results, select
    *New placing points*.

Teams
can be selected on the basis of the club name, club abbreviation, association field, team field or
district number.

In this case the program tries to read from the file pistesrj.lst
a list of the classes taken into account in calculating the club's overall points,
and information on how many of the best are given points. Each line of the file
then contains, separated by a space or tab character, first the class
name and then the number. If the file is not found, the program calculates points for all classes, using
the maximum placing given on the form as the number of competitors taken into account
from each class.

If the checkbox *Class size affects winner's
points*
is selected, the winner of a small class gets points according to the class size.
If it is not selected, the winner of every class gets the same
number of points.

Competitors
are given n - sj + 1 points, where n is the number of competitors receiving points (read from the file or the number of
competitors with results, whichever is smaller) and sj the placing. The class winner gets one more
extra point if *One extra point for the class winner* is selected
. In case of a shared placing, the score is the one corresponding to
that placing. The score of a club or otherwise defined team is the sum of the
points calculated in this way.
