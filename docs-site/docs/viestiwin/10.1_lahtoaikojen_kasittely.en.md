# 10.1 Handling start times

### 10.1 Handling start times

In team orienteering the whole team starts
at the same time, so all legs are always given a time according to the definitions
for the first leg. The start interval is given in seconds and it can also be zero. The start time given is calculated
from the defined first start, the start interval, the defined starting number of the team numbering and
the team's number. If the calculation results in gaps or earlier start times, the program records the times
calculated in this way in the data.
