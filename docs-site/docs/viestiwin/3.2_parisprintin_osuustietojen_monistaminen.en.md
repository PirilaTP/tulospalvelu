# 3.3 Duplicating leg data for a team sprint

### 3.3 Duplicating leg data for a team sprint

On the form *Copying leg data* you can copy the
entrant data recorded for one leg to one or more other legs.
The leg whose data are copied is the source leg. The legs to which data
are copied are listed in the field *Target legs* by typing the numbers of all
the desired legs separated by spaces. For example, in a relay where
both participants ski three legs, first select leg 1 as the source leg
and "3 5" as the target legs, and then leg 2 as the source leg and
"4 6" as the target legs.

The transfer can be done at once for all classes or only for selected
classes. If the number of legs varies, the target legs can be selected according to the largest
number of legs, because the program skips requests that exceed the number of legs of the competitor's
class.

Usually all personal data of the competitor can be copied,
even though not all data are used, as is selected by default on the form. The
course code, on the other hand, is usually not copied.
