# Banuppgifter under tävlingen

Banuppgifterna kan granskas och behandlas även under tävlingen. På så sätt kan du
till exempel göra ändringar som behövs när stämplingsenheter går sönder.
Under tävlingen finns knappen *Ta ändrade uppgifter
i bruk,* med vilken de ändringar som gjorts på detta
formulär aktiveras. Observera att uppgifterna först måste sparas
i fil och först därefter kan tas i bruk. De gjorda ändringarna påverkar inte
resultattjänsten förrän de har tagits i bruk på detta sätt.
