# Banuppgifter

I en tävling som bygger på Emit-stämplingssystemet behövs uppgifter om banorna
och de stämplingsenheter som används på dem. Dessa definieras i programmets val
*Förberedelse / Banuppgifter*. Till skillnad från övriga uppgifter kan banuppgifterna
behandlas redan innan hela tävlingen har skapats eller på en dator som inte har
tillgång till andra uppgifter om tävlingen, om det anses
vara till nytta.

På formuläret för banuppgifter behandlas
uppgifterna först så att de sparas i datorns minne, där även deras konsistens
kan kontrolleras, och först därefter, när det särskilt begärs,
till fil.
