# Timing

### Timing

Timing, too, is nowadays easiest to handle with the program
*HkKisaWin*, but *HkMaali* may be smoother to use once
you are used to
it.

If a finish clock is used, set it to give times according to local time
if at all possible. This avoids the need to define an
offset between the times. Even if it is possible to enter
competitors' numbers on the clock, this should generally be avoided, except in competitions
where getting the finishing order to the computer immediately in some other way
is difficult and the rate of finishers is such that entering them on the finish clock
is feasible.

The normal timing procedure is that the competitor's number is keyed into the computer either
a little before they finish or as soon as possible afterwards.
What matters is that the numbers are entered in finishing order, or that you otherwise
make sure that each number goes with the correct time.

When *Options / Allow predictive
number entry* has been selected,
you can
enter several bib numbers in advance to wait for the times given by the timing.

When the parameters described in the chapter on configuring
the results service are used, the program deduces the starter's number
from the time received from the start gate if the start took place within 3 s
of the start time in the start list. Starts outside this window
must be handled manually if necessary (a late start usually does not
require any action; the start time from the draw may
remain in force).

When the parameter lähaika1 has been given both on the finish computer and on the office computer
, the timing data can also be
viewed and handled on the office computer.

**Timing without a finish clock**

Times of day can be taken from the computer's clock
by pressing a key reserved for this on the computer keyboard. In the program
HkKisaWin the key is selected in the timing form's option *Options /
Timing key and point.* Whenever times are taken from only one point
(e.g. the finish), it is a good idea to select this point at the same time as the
timing key.
