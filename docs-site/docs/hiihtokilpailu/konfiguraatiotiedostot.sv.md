# Konfigurering av resultattjänsten

Skötseln av resultattjänsten förutsätter att en
konfigurationsfil upprättas, om dataöverföring mellan datorer
eller en målklocka används. När man arbetar med en dator och tar tiderna från
datorns klocka är en konfigurationsfil inte nödvändig.

För att upprätta konfigurationsfilen finns
en konfigurationseditor, som du får fram via programmets val *Filer /
Startinställningar* och därifrån vidare *Öppna konfigurationseditorn*.
