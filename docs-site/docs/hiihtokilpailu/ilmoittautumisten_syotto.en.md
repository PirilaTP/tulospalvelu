# Entering entries by hand

In a small event, all competitors are often entered directly into the results software by typing the data
one competitor at a time. This is done on the form *Entering and editing
competitor data,* which you open from the menu item *Entries /
Entries.*

The form may open showing the text
*Edit mode.* This mode is suitable when
vacancy places have been created in advance in the competitor data and are edited
into competitors. If you want to add new records, you have to switch to
*Add mode.* The mode is changed on the tab *Selection of functions
and data to process*, where you can also choose which fields are available
for editing and whether the program uses a list of possible
competitors or a club list as an aid when entering data. (There are several other
options as well.)

![](../images/ILmAset.png)

When the form is used to enter entries before
a later draw, there is no need to give a bib number or start time. If
competitors are added during the event,
at least the number must be given so that the program can save the data. Selecting the
class is always necessary for the program to work; other data
is entered as needed. Using the club list lets you select
the club easily and helps to get club names without errors. When you tick *Find club
in club list*, the
club list form opens, where you must select
the club list to open (e.g. Seurat.csv).
When you then type the club name and press Enter once the selection
has landed on the right entry in the club list, the club name is transferred as in the list, together with
the region code, even if that has not been selected for display on
the entry form.

The table at the top of the form mainly serves to show
the most recently saved record, which can be brought back from it for correction when
*Edit data* has been selected as the operating mode.
