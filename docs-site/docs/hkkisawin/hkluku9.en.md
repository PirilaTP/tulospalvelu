# Chapter 9. Output to printer and file

## 9 Output to printer and file

The *Outputs* menu
is used to produce printouts and files of both start lists
and results lists.

You can edit the formatting of outputs by selecting
the formatting from the menu. The formats ([chapter
9.3](9.3_tulosten_muotoilumaaritykset.md)
) are for the time being similar
to those in my earlier programs. Start list and results list formats are saved separately. Results list formats
are compatible with HkMaali.

Printing of course and control unit data is covered in [chapter 13.5](13.5_kirjoitintulosteet.md)
.

Information related to points-based output can
also be found in [chapter
11](luku_11._kilpailijoiden_ja_joukkueiden_pisteet.md) .
