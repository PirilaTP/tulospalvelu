# 6.4 Utskrifter av mellantider mellan kontroller

### 6.4 Utskrifter av mellantider mellan kontroller

Från stämplingskontrollformuläret i programmet ViestiWin kan du
starta utskrift av mellantiderna mellan kontrollerna för den tävlande som visas med
knappen *Mellantidsutskrift* eller menyvalet *Skrivarutskrifter /
Mellantidsutskrift*. Menyvalet kan också göras med tangenterna *Alt-K,
Alt-V.* För att utskriften ska lyckas måste den skrivare som används vara
vald, vilket kan göras i valet *Skrivarutskrifter / Välj
skrivare.*

Programmet kan också startas i ett läge där
avläsningen av en emit-bricka startar utskriften av den tävlandes mellantider.
Detta sker genom att ge programmet parametern

rastivatuloste

När denna parameter har angetts och du sedan väljer
*Resultattjänst / Emit-avläsning*, öppnar programmet ett förenklat
formulär där du kan mata in den tävlandes nummer, om avläsningen av brickan
av någon anledning inte lyckas. Normalt ger enbart avläsningen av brickan en utskrift.
Om användningen av skrivaren inte har aktiverats före avläsningen av den första brickan, antingen
med parametern lista
eller i valet *Skrivarutskrifter
/ Välj skrivare* på det formulär som används, kan du behöva välja skrivare
i samband med den första utskriften. Det gjorda valet gäller tills
det ändras via menyn.

För att det ska vara möjligt att göra mellantidsutskrifter
någon annanstans än vid stämplingskontrollen måste dataöverföringen konfigureras så att
stämplingsuppgifterna kommer till utskriftsdatorn.

Övergången direkt till det läge som tillåter utskrift kan automatiseras genom att ange
alla följande parametrar

```
lista
rastivatuloste     
ikkunat
```

genom att spara korrekt placerade fönsterpositioner
i huvudformulärets val *Filer / Spara fönster,* och genom att i valet
*Filer / Startinställningar* välja att programmet öppnas direkt i resultattjänstläge [(kapitel 2.5)](2.6_automaattinen_kaynnistyminen_tilaan.md)
.
