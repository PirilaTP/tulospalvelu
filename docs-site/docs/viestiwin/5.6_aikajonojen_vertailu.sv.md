# 5.8  Jämförelse av tidsköer

### 5.8  Jämförelse av tidsköer

Via tidtagningsformulärets meny kan du gå till en jämförelse av två
tidtagningsköer. Köerna kan väljas bland dem som används
för tidtagningen. Programmet visar avvikelser mellan köerna med färgkodning.
Urvalskriterierna för kodningen kan ändras med ett menyval.

Tidtagningsuppgifterna kan bläddras så att bläddring i den vänstra
tabellen flyttar båda tabellerna lika mycket, medan bläddring i den
högra bara flyttar den tabellen. Tangenterna som används för bläddring
är Upp, Ned, PgUp, PgDn, Ctrl-PgUp och Ctrl-PgDn. Även
inmatning av siffervärden samt rullningslisten kan användas för
bläddring.

Tangentkombinationen Ctrl-PgUp återställer båda tabellerna
till rad 1.

I formuläret kan du ta bort och lägga till rader, men den fortsatta behandlingen av en tillagd
rad måste göras i det vanliga
tidtagningsformuläret.
