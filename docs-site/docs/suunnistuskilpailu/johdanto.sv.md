# Beskrivning av exempeltävlingen

## Att ordna resultattjänsten vid en orienteringstävling

#### 2.5.2013

#### En mindre exempeltävling

Denna anvisning går igenom de arbetsmoment som hör till resultattjänsten vid en typisk nationell
orienteringstävling.

Innan dessa arbetsmoment påbörjas måste programvaran installeras, och det
antas ha skett enligt installationsanvisningen.

Den tävling som granskas som exempel väntas samla några hundra deltagare. Det finns ingen separat
tidtagning, utan tiderna fås från stämplingskontrollen. Stämplingskontrollens
dator sköter dessutom vissa andra uppgifter i bakgrunden. I själva
resultattjänsten används också en andra dator för att registrera olika
ändringar, för klagomurens verksamhet samt för alla resultattjänstens diverse
uppgifter. En tredje dator finns hos speakern för att följa tävlingen.
