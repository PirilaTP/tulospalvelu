# 1.1 Installation

### 1.1 Installera programmet ViestiWin

Programmet installeras med ett installationsprogram, som under
installationen frågar efter den katalog dit själva programmet installeras samt
den katalog dit programmet installerar startfilen `init.cfg`. Det lönar sig i allmänhet att
installera programmet i den föreslagna katalogen, men den lämpligaste katalogen för startfilen kan
bero på hur programmet ska användas. Det är väsentligt att programmet kan
skriva till startfilen. Startfilens katalog är i allmänhet inte densamma som den dit
programmet normalt installeras, eftersom många Windows-versioner inte tillåter
skrivning i programfilernas katalogträd.

Programmet föreslår att katalogen `viestikisa` skapas på skrivbordet. Den här katalogen lämpar sig
som plats för filen `init.cfg`, som styr programmets start, men själva tävlingsdata
lönar det sig i allmänhet att placera i en egen arbetskatalog för varje tävling, som kan vara
till exempel en underkatalog till katalogen `viestikisa`. Den här
katalogen kan skapas inifrån programmet när en ny tävling skapas. Filen
`init.cfg` har som enda uppgift att ange vilken
tävling som behandlas och i vilket driftläge programmet ska öppnas
vid nästa start. Dessa val görs och sparas via programmets
menyval *Filer / Startinställningar*.
Om programmet har ställts in att starta på ett sätt som inte lyckas på grund av felaktiga
uppgifter, kan det vara nödvändigt att radera filen `init.cfg`, varefter startvalen kan
göras fritt.

Om du vill använda programmet ViestiWin upprepade gånger
omväxlande för att behandla mer än en tävling, kan det löna sig att använda
flera olika startfiler `init.cfg`,
var och en i sin egen katalog, och ange var och en av dessa kataloger som
startkatalog för en egen genväg. Alternativt kan filen init.cfg
, ges ett annat namn, som anges
som kommandoradsparameter i genvägen.
