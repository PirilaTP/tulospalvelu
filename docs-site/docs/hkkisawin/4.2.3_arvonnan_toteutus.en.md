# 4.2.3 Performing the draw

### 4.2.3 Performing the draw

The program offers the following options for the draw.

- A draw under orienteering rules means that
  the program prevents competitors from the same club from starting
  consecutively whenever this is at all possible. With this method you must choose
  whether the club is identified by its full name or by its abbreviation.- Start times can also be drawn ignoring the club
    completely.- Start times can be assigned without a draw
      from the bib numbers- Start times can be assigned by ranking
        in descending or ascending order- In connection with the draw, competitors can also be divided
          into several parallel classes, e.g. several qualification classes. This can be done
          - completely at random,- trying to distribute the clubs almost evenly across the
              classes,- keeping each club in the same parallel class, or- by ranking so that the classes are made
                  as equal in strength as possible- by ranking, picking the best into one class,
                    the next ones into the next class, etc.- The draw can be repeated for part of a class, which makes it
            possible first to use the ranking to place the best at the beginning or end and
            then to draw the best and/or the others separately.- There is currently no actual support for start groups,
              but the same result can be achieved by drawing the start groups
              into different classes and moving them into the same class after the draw.

In a multi-stage competition you can choose
whether the draw is made for all stages or for one stage only.

In a two-stage competition (but not with more than
two stages) you can choose how the start times of the second day are
formed, from four alternatives

- Independent draw- Reversed order, i.e. exactly the opposite
    order to day 1.- Reversed and shuffled, where consecutive starters
      have been swapped at random. The order is then not completely
      reversed, but close to it, especially in classes with many
      competitors.- Halved, where the first and second halves
        are swapped and then shuffled as in the previous
        alternative

When more than two stages are drawn at once,
the program tries to give competitors start times so that each one gets times
evenly from different parts of the start order, while keeping competitors from the same club
apart. If you want a completely random draw, the stages must be drawn
one at a time.

In a competition with two or more stages you can also choose
whether start times are given to everyone or whether competitors marked as absent are left without
a start time.

The classes included in the draw are selected by moving them
to the right-hand list by double-clicking the class name or by using the
buttons.
