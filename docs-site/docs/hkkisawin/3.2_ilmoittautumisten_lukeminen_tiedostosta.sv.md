# 3.2 Läsa anmälningar från fil

### 3.2 Läsa anmälningar från fil

#### 3.2.1 Överföring från orienteringens IRMA-system och skidåkningens Kilmo-system

Programmet stöder överföring av anmälningar från filer som skapats av orienteringens IRMA-system
och skidåkningens Kilmo-system. En fil i ett format som stöds
kan läsas under valet *Deltagare / Hämta från fil* genom att du väljer *Anmälningsfil för orientering* eller *Skidåkningens Kilmo-anmälningsfil*. Därefter ber programmet
dig välja filen och börjar läsa den.

Om anmälningsfilen för orientering innehåller
extra rader som programmet inte tolkar som deltagare, kan dessa hoppas över
genom att du väljer att fortsätta läsningen. Om programmet klagar på en rad som du vill
läsa in, kan du antingen avbryta läsningen, varvid de föregående raderna har lästs, eller
fortsätta och anteckna vilka rader som inte lästes in.

Läsningen av Kilmo-filen för skidåkning avbryts vid den första
felaktiga uppgiften, till exempel en anmälan till en klass som saknas i tävlingen.
Då måste du antingen radera KILP.DAT före nästa läsförsök eller
ta bort de rader som redan lästs in korrekt från anmälningsfilen, så att
tävlande inte sparas två gånger. Före ett nytt läsförsök måste
även anmälningsfilen eller klassdefinitionerna rättas så att uppgiften inte
längre strider mot tävlingens krav.

För orientering måste du även sköta
hanteringen av klubbnamn, som beskrivs i kapitel 3.3.

#### 3.2.2 Överföring från csv-fil och från data som skapats med Excel

Programmet innehåller flera sätt att läsa uppgifter från
csv-filer. Det nyaste och i de flesta fall mest praktiska bygger på att
de fält som ska läsas definieras på filens första rad med
beteckningar av följande slag, som förhoppningsvis kan tolkas utan ytterligare förklaringar:

No;KilpId;IntId;Piiri;Sukunimi;Etunimi;Arvo;Seura;Seuralyh;Yhdistys;Joukkue;Maa;Sarja;Sukup;Synt;Ikäsrj;ArvRyhmä;IlmLista;Piste1;Piste2;Piste3;Bib-1;Sarja-1;Badge-1;Laina-1;Badge2-1;Laina2-1;ArvLahto-1;TotLahto-1;Tulos-1;Tark-1;Sija-1;AmpSakko-1;Sakko-1;Rata-1;Selitys-1;PvPiste1-1;PvPiste2-1;Ennätys-1;Tavoite-1;Bib-2;Sarja-2;Badge-2;Laina-2;Badge2-2;Laina2-2;ArvLahto-2;TotLahto-2;Tulos-2;Tark-2;Sija-2;AmpSakko-2;Sakko-2;Rata-2;Selitys-2;PvPiste1-2;PvPiste2-2;Ennätys-2;Tavoite-2;VaTulos-1-1;VaTulos-1-2;VaTulos-2-1;VaTulos-2-2

Beteckningarna ovan motsvarar en tävling med 2 etapper
där två mellantider tas i båda etapperna. Beteckningarna måste
skrivas exakt rätt för att programmet ska förstå dem. En lista över beteckningarna
kan skapas genom att uppgifterna skrivs från programmet till en fil. Detta kan göras när tävlingen
har definierats och öppnats i förberedelseläge, även om inga tävlande har registrerats alls.

Kolumnerna ovan motsvarar direkt de filfält som programmet
använder. Dessutom kan kolumnrubriken "Nimi" användas, för vilken programmet delar
fältet i efternamn och förnamn under förutsättning att uppgiften är i formen "Sukunimi Etunimi" (efternamn förnamn).

När nya poster läses in i programmet är klassuppgiften
den enda obligatoriska kolumnen. I övrigt behöver endast kolumner som innehåller uppgifter tas med.

I stort sett samma funktion finns också för att komplettera och ändra
tidigare skapade poster. Då är den tävlandes
grundnummer (kolumnen "No") ett obligatoriskt fält, som används för att identifiera
deltagaren. Utöver detta behövs de kolumner vars uppgifter ändras.
När uppgifter kompletteras behöver inga andra tävlande tas med än de vars uppgifter kompletteras eller ändras.
