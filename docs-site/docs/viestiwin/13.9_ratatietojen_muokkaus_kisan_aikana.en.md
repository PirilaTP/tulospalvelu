# 13.9 Editing course data during the competition

### 13.9 Editing course data during the competition

When the competition is in progress, the program
automatically loads the data in use for handling.

Editing the courses does not affect the results service until
the courses have first been written to a file and then separately put into use,
which can be done both from the course data form and from the menu of the punch checking form.

Course data can also be read from another file and
saved under a name other than the one used by the results service. In that case
handling the courses does not affect the results service in any way.
