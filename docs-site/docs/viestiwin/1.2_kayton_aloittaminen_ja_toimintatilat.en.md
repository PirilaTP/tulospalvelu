# 1.2 Getting started and operating modes

### 1.2 Getting started with the program and its operating modes

When the program is started, its main form opens.
It contains a list of the other forms that are open, three buttons
for selecting the operating mode, and menus for selecting
functions.

The program has three
operating modes:

- **basic mode**, in which no
  competition is selected and only functions that
  do not require a connection to a competition can be performed- **preparation mode**, in which
    a competition can be handled even before
    it has been prepared sufficiently for results service mode. In this mode
    the program does not keep connections open to other computers
    or program instances handling the same competition, but works independently. Results service functions
    cannot be selected in preparation mode.- **results service mode**
      , which requires
      that all essential things have been defined and, among other things,
      that all entrants have been given
      bib numbers. In this mode the data transfer connections to other program instances are available.
      Some of the preparation functions are disabled, because they would cause problems
      in this mode or while data transfer is running.

The previous section uses the
term *program instance* . This refers to the fact
that the same competition can be handled both on several computers that
communicate over a local network and on the same computer, based on data kept consistent
in several different competition folders,
so that ViestiWin, ViestiMaali or ViestiLuenta has been opened separately for each
folder. Two program instances can thus run either on different
computers or on the same computer. In the case of ViestiWin, each
program instance can open several windows, so it is rarely
justified to open several ViestiWin instances on the same computer, but sometimes it is
justified to start both ViestiWin and ViestiMaali, or several instances of
ViestiMaali.
