# 13.7 Putting the course definitions into use

### 13.7 Putting the course definitions into use

Changes made to the course data are put into use
during the competition by writing the data to a file and reading it again into the punch checking functions.

The button *Apply changed data* leads to the following actions

- the program asks you to confirm that you want to put the data into use

  - the program checks whether unsaved changes have been made to the course or punching unit data
    and asks you to save them if there are changes

    - the program checks the consistency of the data as described in chapter 13.6

      - the program writes the data to the file

        - the program reads the data from the file for use by the punch checking functions

If the changes are to be put into use on another
computer, the saved course data file (usually radat1.xml) must be copied
to that computer's working folder and then put into use with the punch checking
menu command *Files / Reload course data*. The same
procedure can also be used on the computer that produced the changes if
you want to postpone putting them into use. In that case the data must be saved to the file either
with a menu command or using the save button that can be brought up.
