# 6.7 Handling control route penalties

### 6.7 Handling control route penalties

Control route penalties are handled in HkKisaWin
by entering their number either in the function *Emit reading* [(chapter 6.1)](6.1_leimantarkastuskaavake.md) in the field *Penalties (RR)* or on the competitor data
editing form [(chapter
7)](hkluku7.md)
 in the column *Penalty* of the table area.
The corresponding options are also available in the program HkMaali.

The size of the penalty in seconds must be given in the data of each
control route class. To make this easiest, the default penalty unit
defined in the competition's basic properties [(chapter
2.1)](2.1_uuden_kilpailun_luominen.md) must equal the desired penalty.
When this value is as desired and you then select, on the definition form of an individual class's data
[(chapter
2.2)](2.2_sarjatietojen_maarittely.md)
 under *Handicaps, penalties*,
the option *Control route penalties*, the program changes the value of the field *Penalty per
error* to that number of seconds (normally 600). This value can be
changed class by class, but visiting *Handicaps, penalties*
takes the default value into use again.

The program stores the size of the penalties in seconds.
The number of seconds can be shown by changing the size of one penalty
in the class data to 1 sec. The penalties are also shown as a count in the results lists,
provided that the size of one penalty has been defined normally.
