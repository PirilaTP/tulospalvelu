# 2.4 Transferring data from an earlier program version

#### 2.4 Transferring data from an earlier program version

##### 2.4.1 Correcting version 5.0 times

In the option  *Preparation / Reset or multiply results and
version conversion* the menu command *Special functions / Multiply
all times by ten* is available. This command converts all times of version 5.0 given in
hundredths of a second into the thousandths of a second used by later versions.

The same form can also be used to reset all results and to change
the way surnames are written to use an initial capital letter or all capital
letters.

##### 2.4.2 Transferring version 4 data

HkKisaWin can read the class and
competitor files of an earlier program version. This requires the following steps:

- Select the directory folder you want to work in
  and copy the old KILP.SRJ to this folder.- The old file KILP.DAT must not be placed in this
    folder without renaming it to something else- Start HkKisaWin and open the above folder
      with the button "Open competition for preparation". You do not need to worry about the missing
      file ilmoitt.cfg.- Go to the function *Competition creation and preparation*, where
        - Select 2 stages and 10 split times as the space reservations of the file format,
          unless more are needed.- Make any other necessary changes,
            such as editing the competition title line and the sport and number of stages,
            which is often one even though the space reservation is 2.- Exit accepting the selections made. The class data has now been created
              and saved in the format of the new program version with the name KilpSrj.xml  
        - If you also want to transfer the old competitor data,
          - select *Entries / Get from file* from the main menu- select *Old KILP.DAT*- make sure that the numbers of days and split times
                correspond to the old program version (this data should
                be correct if the transfer is made in the same session in which the old
                KILP.SRJ was read, but later the data may be wrong).- start the transfer with the button *Read from file*, which lets you select
                  the old KILP.DAT from the directory and under the name it now has
                  (KILP.DAT in the working directory is a new empty file).
